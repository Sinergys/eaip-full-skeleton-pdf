## 🧪 Тестирование Phase 1

### Что можно протестировать СЕЙЧАС:

**1. Запуск сервиса:**
```bash
cd C:\eaip\eaip_full_skeleton\services\validate
python main.py
```
**Ожидаемый результат:** ✅ Сервис запускается на порту 8003

**2. Health checks:**
```bash
curl http://localhost:8003/health
curl http://localhost:8003/api/v1/health
```
**Ожидаемый результат:** ✅ Статус "ok"

**3. Swagger docs:**
```
http://localhost:8003/docs
```
**Ожидаемый результат:** ✅ Документация отображается

**4. Валидация файлов:**
```bash
curl -X POST "http://localhost:8003/api/v1/check-report/" \
  -F "file=@invalid.txt"
```
**Ожидаемый результат:** ✅ Ошибка 400 "формат не поддерживается"

**5. NotImplementedError (ожидаемо):**
```bash
curl -X POST "http://localhost:8003/api/v1/check-report/" \
  -F "file=@test.docx"
```
**Ожидаемый результат:** ✅ Ошибка 500 с сообщением "будет реализован в Phase 2"
