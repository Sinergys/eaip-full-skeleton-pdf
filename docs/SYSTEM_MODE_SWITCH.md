# 🔧 Переключатель режимов работы системы

## Описание

Система поддерживает два режима работы для обработки дубликатов файлов:

### 🔧 Режим "DEBUG" (Отладка)
- **Назначение:** Разработка, тестирование, отладка
- **Поведение:** Всегда переобрабатывать файлы, даже если они уже загружены
- **Использование:** При разработке новых функций, тестировании Intelligent Router

### 🚀 Режим "PRODUCTION" (Работа)
- **Назначение:** Рабочий режим системы
- **Поведение:** Пропускать файлы без изменений, переобрабатывать только обновленные
- **Использование:** В production окружении для экономии ресурсов

## Настройка

### Переменная окружения:
```bash
SYSTEM_MODE=debug      # Режим отладки
SYSTEM_MODE=production # Режим работы (по умолчанию)
```

### В коде:
```python
SYSTEM_MODE = os.getenv("SYSTEM_MODE", "production").lower()
```

## Логика работы

### Режим DEBUG:
1. Найден дубликат → удалить старую запись
2. Всегда переобработать файл
3. Сохранить новые данные

### Режим PRODUCTION:
1. Найден дубликат → сравнить hash файла
2. Hash совпадает → пропустить (файл не изменился)
3. Hash отличается → переобработать (файл обновлен)

## Примеры использования

### Для разработки:
```bash
export SYSTEM_MODE=debug
# или в .env файле
SYSTEM_MODE=debug
```

### Для production:
```bash
export SYSTEM_MODE=production
# или не указывать (по умолчанию)
```

## Преимущества

✅ **Простота:** Один переключатель  
✅ **Гибкость:** Легко переключаться между режимами  
✅ **Эффективность:** В production не тратит ресурсы на одинаковые файлы  
✅ **Удобство:** В debug всегда свежие данные
