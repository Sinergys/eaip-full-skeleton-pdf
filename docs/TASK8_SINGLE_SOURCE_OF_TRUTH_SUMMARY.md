# Task 8: Один источник правды + CI проверки

## Обзор

Обеспечен единый источник правды для всех числовых данных в Excel-паспорте и Word-отчёте через централизованные модули `energy_passport_calculations.py` и `energy_units.py`.

## Выполненные задачи

### 1. Проверка использования централизованных функций

✅ **Все вычисления в Word-генераторе используют централизованные функции:**
- `calculate_total_consumption_by_resource()` - для общего потребления по ресурсам
- `calculate_total_costs()` - для общих затрат
- `calculate_average_payback_period()` - для срока окупаемости мероприятий
- `extract_equipment_data()` - для данных оборудования

✅ **Fallback на локальные вычисления** используется только при недоступности модуля расчётов (для обратной совместимости).

### 2. Удаление дублирующих формул

✅ **Проверено:** В Word-генераторе нет дублирующих формул, которые не используют централизованные функции.

Все локальные вычисления находятся только в fallback-блоках и выполняются только если `HAS_CALCULATIONS = False`.

### 3. Тест согласованности Excel/Word

✅ **Создан скрипт `scripts/test_excel_word_consistency.py`:**
- Извлекает КПИ из ReportData (единый источник правды)
- Сравнивает с Excel-паспортом (если доступен)
- Проверяет согласованность для всех эталонных предприятий

### 4. Обновление CI/CD

✅ **Обновлён `.github/workflows/tests.yml`:**
- Добавлены тесты Word-отчётов (`test_reference_word_reports.py`)
- Добавлен тест согласованности Excel/Word (`test_excel_word_consistency.py`)
- Триггеры на изменения в:
  - `word_report_generator.py`

  - `energy_units.py`

## Структура единого источника правды

```
energy_passport_calculations.py (формулы)
    ↓
ReportData (агрегация КПИ)
    ↓
    ├─→ fill_energy_passport.py (Excel)
    └─→ word_report_generator.py (Word)
```

**Все числовые данные проходят через:**
1. `energy_passport_calculations.py` - вычисление КПИ
2. `energy_units.py` - нормализация единиц измерения
3. `ReportData` - агрегация всех показателей
4. Генераторы (Excel/Word) - использование готовых данных
