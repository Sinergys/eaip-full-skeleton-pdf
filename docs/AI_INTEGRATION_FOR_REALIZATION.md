# План интеграции ИИ для файлов "Реализация"

## Дата: 2025-11-30

## Проблема

Согласно ТЗ, система должна использовать ИИ для определения, распознавания и понимания загруженных файлов. 

**Текущая ситуация:**
- ✅ ИИ интегрирован в систему (`ai_content_classifier.py`)
- ✅ ИИ используется в `ResourceClassifier`, но только если правила не определили тип
- ⚠️ Для файлов "Реализация" правила определяют тип как `electricity` (из-за ключевых слов), поэтому ИИ **не вызывается**
- ❌ ИИ не используется для определения типа данных (`realization` vs `consumption`)
- ❌ ИИ не используется для анализа структуры листов "Баланс"

## Что нужно сделать

### 1. Использовать ИИ для определения типа данных

**Проблема:** Файлы "Реализация" классифицируются как `electricity`, но это не отражает тип данных:
- "Реализация" = произведенная и реализованная (проданная) электроэнергия
- Тип данных: `realization` (не `consumption`)

**Решение:**
- Использовать ИИ для анализа содержимого файла "Реализация"
- ИИ должен определить:
  - Это акт баланса? (да/нет)
  - Это данные по реализации? (да/нет)
  - Тип данных: `consumption`, `production`, `realization`?

### 2. Улучшить промпт для ИИ классификатора

**Текущий промпт** (`ai_content_classifier.py`):
- Определяет только тип ресурса (electricity, gas, water и т.д.)
- Не определяет подтип данных (consumption, production, realization)

**Нужно добавить:**
- Определение типа данных: `consumption`, `production`, `realization`
- Определение типа документа: акт баланса, отчет, справка и т.д.
- Анализ структуры листов для Excel файлов

### 3. Использовать ИИ для анализа структуры листов "Баланс"

**Проблема:** Листы "Баланс 04" и "Баланс 00" имеют разную структуру, и алгоритм поиска колонок не всегда работает.

**Решение:**
- Использовать ИИ для анализа структуры листа "Баланс"
- ИИ должен определить:
  - Где находится заголовок таблицы?
  - Какие колонки содержат названия узлов?
  - Какие колонки содержат активную/реактивную энергию?
  - Какие колонки содержат стоимость?

## План реализации

### Этап 1: Улучшить промпт для ИИ классификатора

**Файл:** `eaip_full_skeleton/services/ingest/utils/ai_content_classifier.py`

**Изменения:**
1. Добавить в промпт определение типа данных (`consumption`, `production`, `realization`)
2. Добавить определение типа документа (акт баланса, отчет и т.д.)
3. Добавить анализ структуры листов для Excel файлов

**Пример промпта:**
```
Определи:
1. Тип ресурса: electricity, gas, water, heat, fuel, coal, equipment, envelope, nodes, other
2. Тип данных: consumption (потребление), production (производство), realization (реализация)
3. Тип документа: акт баланса, отчет, справка, другое
4. Для Excel файлов: какие листы содержат данные? (например, "Реал 04", "Баланс 04")
```

4. Использовать результат ИИ как дополнение к алгоритму поиска колонок
