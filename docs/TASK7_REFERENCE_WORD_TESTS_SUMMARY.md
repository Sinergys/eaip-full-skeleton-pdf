# Task 7: Интеграция с эталонными предприятиями и тестами

## Обзор

Создан параметризованный тест для генерации Word-отчётов на всех эталонных предприятиях (`reference_enterprise_1...4`) с проверкой корректности генерации и сравнением ключевых показателей.

## Созданные файлы

1. **`scripts/test_reference_word_reports.py`**
   - Параметризованный тест для всех эталонных предприятий
   - Генерация Word-отчётов
   - Проверка готовности данных
   - Сравнение ключевых показателей с эталонными значениями
   - Сравнение с Excel-паспортом (если доступен)

## Функциональность

### Основной тест

```python
python scripts/test_reference_word_reports.py
```

Тест выполняет:
1. Загрузку эталонных данных для каждого предприятия
2. Создание ReportData с вычислением всех КПИ
3. Проверку готовности данных через `validate_word_report_readiness()`
4. Генерацию Word-отчёта через `WordReportGenerator`
5. Извлечение ключевых показателей из ReportData
6. Сравнение с эталонными значениями и Excel-паспортом

### Результаты тестирования

Для каждого предприятия генерируется:
- Word-отчёт в формате DOCX
- JSON-отчёт с результатами тестирования
- Сравнение ключевых показателей

**Ключевые показатели для сравнения:**
- `electricity_total` - общее потребление электроэнергии, кВт·ч
- `gas_total` - общее потребление газа, м³
- `water_total` - общее потребление воды, м³
- `total_energy_cost` - общие затраты, сум
- `equipment_power` - установленная мощность оборудования, кВт
- `measures_count` - количество мероприятий

### Структура результатов

```json
{
  "timestamp": "2025-01-15T...",
  "total_tests": 4,
  "successful": 4,
  "failed": 0,

    }
  ]
}
```

## Исправленные проблемы

1. **Ошибка "cannot access local variable 'electricity_data'"**
   - Исправлено: переменные `electricity_data`, `gas_data`, `water_data` теперь определяются до условного блока

2. **Ошибка "unhashable type: 'slice'"**
   - Исправлено: добавлена проверка типа `nodes_data` перед использованием среза

3. **Проверка enterprise.name и enterprise.address**
   - Исправлено: добавлена специальная проверка для раздела 2 в `word_readiness_validator`

## Интеграция с Excel-паспортом

Тест автоматически ищет сгенерированные Excel-паспорта в `test_output/{enterprise_name}/` и сравнивает ключевые показатели. Если Excel-паспорт не найден, сравнение выполняется только с эталонными значениями из JSON.

## Использование

### Запуск всех тестов

```bash

```
