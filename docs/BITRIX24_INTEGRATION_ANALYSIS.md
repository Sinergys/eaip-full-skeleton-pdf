  ```
  1. Пользователь загружает файл в Bitrix24
  2. Webhook → Python-сервис EAIP
  3. Python-сервис: Парсинг + AI-анализ
  4. Результаты → Bitrix24 (через API)
  5. Bitrix24: Отображение правил в карточке
  ```

**Почему так:**
- AI требует Python-окружение и библиотеки
- Bitrix24 не может напрямую запускать AI
- Лучше использовать специализированный сервис

**Архитектура:**
```
EAIP (SQLite) → Синхронизация → Bitrix24
     ↑                                    ↓
     └─────────── Webhook ←────────────────┘
```

**Код:**
```python
# bitrix24_sync.py
def sync_normative_to_bitrix24(document_id: int):
    """Синхронизировать нормативный документ в Bitrix24"""
    doc = database.get_normative_document(document_id)
    rules = database.get_normative_rules_by_document(document_id)
    
    # Создать карточку в Bitrix24
    bitrix24.create_deal(
        title=f"Норматив: {doc['title']}",
        fields={
            "UF_NORMATIVE_TYPE": doc["document_type"],
            "UF_FORMULAS_COUNT": len([r for r in rules if r["rule_type"] == "formula"]),
            "UF_NORMATIVES_COUNT": len([r for r in rules if r["rule_type"] == "normative"]),
        }
    )
```
