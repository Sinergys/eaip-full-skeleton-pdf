# Отчет: Поддержка листов "Реализация" в агрегаторе электроэнергии

## Дата: 2025-11-30

## Проблема

Согласно анализу логов, система не могла найти листы с электроэнергией в файлах "Реализация":

```
⚠️ [DIAG] Лист с электроэнергией не найден. Доступные листы: ['Реал 04', 'Реал 00', 'Баланс 04', 'Баланс 00']
```

**Результат:** 0 кварталов данных для всех ресурсов (electricity, gas, water, fuel, coal, heat, production)

## Причина

В `energy_aggregator.py` система искала листы с электроэнергией по стандартным названиям:
- "ЭЛЕКТР", "электр", "Электроэнергия", "Электричество", "ТП", "Electricity", "Sheet1"

Но в файлах "Реализация" листы называются по-другому:
- "Реал 04", "Реал 00", "Баланс 04", "Баланс 00"

Система не учитывала эти названия при поиске листов с электроэнергией.

## Решение

Добавлена поддержка листов из файлов "Реализация" в поиск листов с электроэнергией.

## Внесенные изменения

### 1. Обновлена функция `aggregate_energy_data` (`energy_aggregator.py`)

**Первое место поиска (строка ~528):**
- Добавлены ключевые слова "реал", "баланс", "реализация" в частичный поиск листов
- Теперь система ищет листы с электроэнергией по расширенному списку ключевых слов

**Второе место поиска (строка ~1980):**
- Добавлены конкретные названия листов из файлов "Реализация":
  - "Реал 04", "Реал 00", "Реал 01", "Реал 02", "Реал 03"
  - "Баланс 04", "Баланс 00", "Баланс 01", "Баланс 02", "Баланс 03"
- Добавлены ключевые слова "реал", "баланс", "реализация" в частичный поиск

## Примеры работы

### До исправления:

```
⚠️ [DIAG] Лист с электроэнергией не найден. Доступные листы: ['Реал 04', 'Реал 00', 'Баланс 04', 'Баланс 00']
```

### После исправления:

```
✅ [DIAG] Найден лист электроэнергии по частичному совпадению: 'Реал 04'
🔍 [DIAG] Найден лист электроэнергии 'Реал 04': N строк
```

## Важные замечания

1. **Тип данных**: Файлы "Реализация" содержат данные о **реализации (продаже) электроэнергии**, а не потреблении. Эти данные сохраняются в БД с `data_type = "realization"`.

2. **Агрегация**: Данные из файлов "Реализация" теперь могут быть найдены агрегатором, но важно понимать, что это данные о реализации, а не потреблении.

3. **Структура листов**: Листы "Реал" и "Баланс" могут иметь другую структуру, чем стандартные листы с электроэнергией. Возможно, потребуется дополнительная адаптация логики парсинга.

## Преимущества

1. **Расширенный поиск**: Система теперь находит листы с электроэнергией в файлах "Реализация"
2. **Гибкость**: Поддержка различных названий листов
3. **Обратная совместимость**: Стандартные названия листов по-прежнему поддерживаются

## Тестирование

Рекомендуется протестировать на файлах "Реализация":
- Убедиться, что листы "Реал 04", "Реал 00", "Баланс 04", "Баланс 00" теперь находятся
- Проверить, что данные из этих листов корректно обрабатываются
- Убедиться, что данные попадают в агрегацию (если это необходимо)

## Следующие шаги

1. Протестировать на реальных файлах "Реализация"
2. Проверить, что данные из листов "Реал" и "Баланс" корректно парсятся
3. При необходимости адаптировать логику парсинга под структуру этих листов
4. Убедиться, что данные о реализации правильно отличаются от данных о потреблении

## Связанные проблемы

- **Проблема с агрегацией**: Даже после исправления, данные из файлов "Реализация" могут не подходить для стандартной агрегации электроэнергии как потребления, так как это данные о реализации
- **Структура данных**: Возможно, потребуется дополнительная адаптация логики парсинга для корректной обработки структуры листов "Реал" и "Баланс"
