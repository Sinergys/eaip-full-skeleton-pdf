# 🔧 ИСПРАВЛЕНИЕ АГРЕГАЦИИ ФАЙЛОВ ОДНОГО РЕСУРСА

**Дата:** 2025-01-15  
**Статус:** ✅ ЗАВЕРШЕНО

## 🔍 Выявленная проблема

**Проблема:** Функция `aggregate_from_db_json()` была рассчитана только на многоресурсные файлы (например, `pererashod.xlsx` с листами "ЭЛЕКТР", "ГАЗ", "СУВ"), но не обрабатывала файлы одного ресурса (например, `gaz.xlsx`, `voda.xlsx`).

**Симптомы:**
- После загрузки `gaz.xlsx` агрегированные данные были пустыми: `Доступные ресурсы для заполнения: []`
- Все ресурсы инициализированы, но пустые: `['electricity', 'gas', 'water', 'fuel', 'coal', 'heat', 'production']`

**Причина:**
- `aggregate_from_db_json()` искала только листы "ЭЛЕКТР", "ГАЗ", "СУВ"
- Файлы одного ресурса имеют другую структуру (один лист с данными)
- Не было логики для определения и обработки файлов одного ресурса

## ✅ Решение

### 1. Создана функция `_aggregate_single_resource_from_db()`
- **Файл:** `eaip_full_skeleton/services/ingest/utils/energy_aggregator.py`
- **Назначение:** Агрегация файлов одного ресурса из структуры БД
- **Поддерживаемые типы:**
  - `gaz.xlsx` → `gas`
  - `voda.xlsx` → `water`
  - `otoplenie.xlsx` → `heat`
  - `kotel.xlsx` → `production`
  - `electricity.xlsx` → `electricity`

### 2. Обновлена функция `aggregate_from_db_json()`
- Добавлено определение типа файла по имени
- Автоматическое переключение между многоресурсным и одноресурсным режимами
- Логирование для отладки

### 3. Добавлено расширенное логирование
- **Файл:** `eaip_full_skeleton/services/ingest/main.py`
- Логирование структуры `parsing.data`
- Информация о листах и строках
- Детали агрегированных ресурсов

## 📋 Логика обработки

### Для файла `gaz.xlsx`:
1. Определение типа ресурса: `gas`
2. Поиск годов в заголовках (первые 3 строки)
3. Определение позиций колонок: год → сумма → объем
4. Агрегация данных по месяцам и кварталам
5. Вычисление квартальных итогов

### Для файла `voda.xlsx`:
1. Определение типа ресурса: `water`
2. Поиск годов в структуре данных
3. Извлечение объемов по месяцам
4. Агрегация по кварталам
5. Вычисление квартальных итогов

## 🛠️ Измененные файлы

   - Обновлена функция `aggregate_from_db_json()` с определением типа файла
   - Улучшена логика поиска годов в заголовках

2. **`eaip_full_skeleton/services/ingest/main.py`**

   - Логирование результата агрегации с деталями по ресурсам
