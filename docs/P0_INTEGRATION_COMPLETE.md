### 2. Интеграция в `fill_dinamika_sheet`

**Файл:** `tools/fill_energy_passport.py`

**Изменения:**
- ✅ Добавлена проверка нормативов для поля "Удельный расход"
- ✅ Комментарии в Excel ячейках с результатами проверки
- ✅ Логирование нарушений в консоль

**Как работает:**
1. После вычисления удельного расхода вызывается `validate_and_log_critical_field()`
2. Проверяется соответствие нормативу
3. Если есть нарушение - добавляется комментарий в ячейку Excel
4. Нарушение логируется в консоль

**Пример комментария в Excel:**
```
⚠️ ПРЕВЫШЕНИЕ НОРМАТИВА
Факт: 0.18
Норматив: 0.15
Отклонение: 20.0%
⚠️ Превышение норматива на 20.0%. Факт: 0.18, Норматив: 0.15
```

## 🔧 Использование

### В коде заполнения паспорта:

```python
from normative_integration import validate_and_log_critical_field

# После вычисления значения
specific = calculate_specific_consumption(...)
specific_cell = ws.cell(row=current_row, column=7)
specific_cell.value = specific

# Проверка нормативов
validation_result = validate_and_log_critical_field(
    field_name="Удельный расход",
    actual_value=specific,
    sheet_name="Динамика ср",
    cell=specific_cell,
    enterprise_id=enterprise_id,  # если доступен
    batch_id=batch_id,  # если доступен
    tolerance_percent=10.0,
    add_comment=True,
)

if validation_result.is_violation():
    logger.warning(f"Нарушение: {validation_result.message}")
```

## 📊 Результаты проверки

### Статусы:
- `compliant` - соответствует нормативу ✅

- `below_norm` - ниже норматива ✅
- `unknown` - норматив не найден ℹ️
