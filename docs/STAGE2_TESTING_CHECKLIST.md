## 🔢 ПРОВЕРКА ФОРМУЛ И СВЯЗЕЙ

### 14. Общие проверки формул

#### 14.1. Проверка ошибок формул
- [ ] Нет ошибок `#REF!` (неверные ссылки на ячейки/листы)
  - [ ] Проверить все листы на наличие `#REF!`
  - [ ] Если найдены, проверить логи восстановления формул (AIFormulaRestorer)
  - [ ] Убедиться, что восстановленные формулы корректны
- [ ] Нет ошибок `#VALUE!` (неверные типы данных)
  - [ ] Проверить ячейки с формулами на наличие текста вместо чисел
  - [ ] Проверить корректность преобразования типов данных
- [ ] Нет ошибок `#DIV/0!` (деление на ноль)
  - [ ] Проверить формулы деления (особенно удельные показатели)
  - [ ] Убедиться, что есть проверки на ноль (IF, IFERROR)
- [ ] Нет ошибок `#NAME?` (неверные имена функций)
  - [ ] Проверить использование функций Excel (SUM, IF, и т.д.)
  - [ ] Убедиться, что функции написаны на правильном языке (русский/английский)

#### 14.2. Проверка циклических ссылок
- [ ] Нет циклических ссылок в формулах
  - [ ] Проверить формулы типа `=SUM(F4:F5)` в ячейке F4
  - [ ] Убедиться, что функция `_fix_circular_references()` исправила все циклические ссылки
  - [ ] Проверить логи на наличие предупреждений о циклических ссылках

#### 14.3. Проверка сохранения формул
- [ ] Формулы в шаблоне сохранены при заполнении данных
  - [ ] Проверить, что функция `_safe_set_cell_value()` не перезаписывает формулы
  - [ ] Убедиться, что ячейки с формулами не были перезаписаны значениями
  - [ ] Проверить итоговые строки (ИТОГО) - формулы должны быть сохранены

#### 14.4. Проверка использования централизованных функций
- [ ] Используются централизованные функции расчётов (если HAS_CALCULATIONS = True)

## 📝 ЗАМЕТКИ И РЕКОМЕНДАЦИИ

### Порядок проверки:
1. **Общие проверки файла** (разделы 1-2)
   - Существование и доступность файла
   - Структура рабочей книги
2. **Проверка каждого листа** (разделы 3-13)
   - Проверить каждый лист по порядку
   - Убедиться, что все данные заполнены
   - Проверить структуру и заголовки
3. **Проверка формул и связей** (разделы 14-15)
   - Проверить все формулы на ошибки
   - Проверить связи между листами
   - Убедиться в согласованности данных
4. **Валидация данных** (разделы 16-17)
   - Соответствие исходным данным
   - Логическая согласованность
5. **Дополнительные проверки** (разделы 18-19)
   - Форматирование и визуализация
   - Обработка edge-кейсов
6. **Автоматические тесты** (раздел 20)
   - Запустить скрипты проверки
   - Проверить логи генерации

### При обнаружении ошибок:
1. **Ошибки формул (#REF!, #VALUE!, и т.д.)**:
   - Проверить логи восстановления формул
   - Проверить корректность ссылок на ячейки/листы
   - Убедиться, что шаблон не был изменён некорректно
2. **Несоответствие данных**:
   - Проверить исходные данные в БД (`aggregated_data`)
   - Проверить корректность агрегации данных
   - Проверить соответствие периодов (кварталы, годы)
3. **Проблемы со связями между листами**:
   - Проверить названия листов (могут отличаться: "Баланс", "04_Баланс", "Balans")
   - Проверить координаты ячеек в ссылках
   - Проверить логи восстановления формул (AIFormulaRestorer)
4. **Отсутствующие данные**:
