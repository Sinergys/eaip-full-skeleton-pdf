## 📊 Структура проекта

### Архитектура
- **Тип:** Микросервисная архитектура (FastAPI)
- **Количество сервисов:** 7
  - `ingest` (порт 8001) - загрузка и парсинг файлов
  - `validate` (порт 8002) - валидация данных
  - `analytics` (порт 8003) - аналитика и прогнозы
  - `recommend` (порт 8004) - рекомендации
  - `reports` (порт 8005) - генерация отчетов (PDF/Excel/Word)
  - `management` (порт 8006) - управление
  - `gateway-auth` (порт 8000) - аутентификация

### Инфраструктура
- **База данных:** PostgreSQL 15 + SQLite (для ingest сервиса)
- **Кеш:** Redis 7
- **Хранилище:** MinIO
- **Контейнеризация:** Docker Compose
