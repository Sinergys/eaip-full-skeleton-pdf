# ✅ ЧЕКЛИСТ ПРОВЕРКИ ЛИСТА "БАЛАНС" В ЭНЕРГОПАСПОРТЕ

**Дата создания:** 2025-11-30  
**Версия:** 1.0  
**Назначение:** Проверка корректности расчётов балансов в сгенерированном Excel-паспорте

---

## 📋 ОБЩИЕ ПРОВЕРКИ

### 1. Существование файла
- [ ] Файл паспорта существует и доступен для чтения
- [ ] Файл имеет расширение `.xlsx`
- [ ] Файл не повреждён (открывается без ошибок)

### 2. Наличие листа "Баланс"
- [ ] Лист с названием "04_Баланс", "Баланс", "Balans" или "04_Balans" существует
- [ ] Лист не пустой (содержит данные)

---

## 📊 СТРУКТУРА ЛИСТА

### 3. Заголовки (строка 2)
- [ ] Колонка A: "Квартал"
- [ ] Колонка B: "Технологические, кВт·ч"
- [ ] Колонка C: "Собственные нужды, кВт·ч"
- [ ] Колонка D: "Производственные, кВт·ч"
- [ ] Колонка E: "Хоз-бытовые, кВт·ч"
- [ ] Колонка F: "Итого, кВт·ч"

### 4. Данные
- [ ] Есть хотя бы одна строка с данными (начиная со строки 3)
- [ ] В колонке A указаны кварталы (например, "2022-Q1")
- [ ] В колонках B-E указаны числовые значения (кВт·ч)
- [ ] Значения не отрицательные (или обработаны корректно)

---

## 🔢 ФОРМУЛЫ И РАСЧЁТЫ

### 5. Формулы в колонке "Итого" (F)
- [ ] Каждая строка с данными содержит формулу в колонке F
- [ ] Формула имеет вид: `=SUM(B<row>:E<row>)`
- [ ] Формула суммирует колонки B, C, D, E для соответствующей строки
- [ ] Результат формулы соответствует сумме значений в колонках B-E

### 6. Строка "ИТОГО"
- [ ] Строка с подписью "ИТОГО" существует (после данных)
- [ ] В колонке A указано "ИТОГО"
- [ ] В колонках B-F содержатся формулы суммирования
- [ ] Формулы имеют вид: `=SUM(B<start>:B<end>)` для каждой колонки

### 7. Корректность сумм
- [ ] Сумма в колонке F (Итого) = сумма колонок B+C+D+E для каждой строки
- [ ] Сумма в строке "ИТОГО" = сумма всех строк данных для каждой колонки
- [ ] Итоговая сумма в F (строка "ИТОГО") = сумма всех итогов по строкам

---

## 🧮 ВАЛИДАЦИЯ ДАННЫХ

### 8. Значения категорий
- [ ] Технологические (B) ≥ 0
- [ ] Собственные нужды (C) ≥ 0
- [ ] Производственные (D) ≥ 0
- [ ] Хоз-бытовые (E) ≥ 0
- [ ] Все значения имеют разумный порядок величин

### 9. Соответствие агрегированным данным
- [ ] Значения соответствуют данным из `aggregated_data` в БД
- [ ] Кварталы соответствуют периодам в исходных данных
- [ ] Суммы по категориям соответствуют общему потреблению

---

## 🔍 ДОПОЛНИТЕЛЬНЫЕ ПРОВЕРКИ

### 10. Форматирование
- [ ] Числовые значения отформатированы корректно (без лишних знаков)
- [ ] Заголовки выделены (жирный шрифт, если применимо)
- [ ] Колонки имеют достаточную ширину для отображения данных

### 11. Обработка edge-кейсов
- [ ] Пустые значения обработаны корректно (0 или пусто)
- [ ] Отрицательные значения нормализованы (если были)
- [ ] Отсутствующие кварталы не вызывают ошибок

## 🛠️ ИСПОЛЬЗОВАНИЕ АВТОМАТИЧЕСКОГО ТЕСТА

Для автоматической проверки используйте скрипт:

```bash
python tools/test_full_passport_cycle.py <путь_к_паспорту.xlsx>
```

Скрипт проверит:
- ✅ Существование файла
- ✅ Наличие листа "Баланс"
- ✅ Корректность заголовков
- ✅ Наличие формул в колонке "Итого"
- ✅ Наличие строки "ИТОГО"
- ✅ Корректность формул суммирования
