# Отчет: Улучшение обработки листов "Баланс 04" и "Баланс 00"

## Дата: 2025-11-30

## Проблема

Листы "Баланс 04" и "Баланс 00" в файлах "Реализация" не обрабатывались из-за ошибки:
```
Не найдена колонка с названиями узлов в листе Баланс 04
Не найдена колонка с названиями узлов в листе Баланс 00
```

**Причина:** Структура листов "Баланс" отличается от листов "Реал", и стандартный алгоритм поиска колонок не находил нужные колонки.

## Рекомендации экспертов

Согласно рекомендациям экспертов в коде:
- **Software Engineer:** "Использовать OCR для извлечения из PDF актов"
- **ML Engineer:** "Использовать Gemini Vision (95% confidence)"

Для Excel файлов применена рекомендация QA Engineer: **"Тестировать на нескольких файлах сначала"** - улучшен алгоритм для работы с разными структурами.

## Решение

### 1. Улучшена функция `_find_column_indices`

**Добавлено:**
- Параметр `sheet_name` для определения типа листа
- Параметр `rows_data` для анализа структуры данных
- Специальная логика для листов "Баланс" с расширенным набором ключевых слов
- Функция `_analyze_balance_sheet_structure` для анализа структуры данных

**Расширенные ключевые слова для листов "Баланс":**
- **Название узла:** добавлены "потребитель", "потребители", "объект", "объекты"
- **Активная энергия:** добавлены варианты "активная мощность", "активная, квт", "p, квт"
- **Реактивная энергия:** добавлены варианты "реактивная мощность", "реактивная, квар", "q, квар"
- **Стоимость:** добавлены варианты "стоимость, сум.", "сумма к оплате"

### 2. Добавлена функция `_analyze_balance_sheet_structure`

**Функциональность:**
- Анализирует первые 5 строк данных для определения структуры
- Ищет колонку с текстовыми значениями (названия узлов)
- Ищет колонки с числовыми значениями (энергия, стоимость)
- Автоматически определяет колонки на основе анализа данных

**Алгоритм:**
1. Ищет первую колонку с текстовыми значениями (не числа) → название узла
2. Ищет колонки с числовыми значениями → энергия и стоимость
3. Сортирует числовые колонки по количеству значений
4. Присваивает: первая → активная энергия, вторая → реактивная, третья → стоимость

### 3. Улучшена обработка листов "Баланс"

**Добавлено:**
- Fallback: если колонка с названиями не найдена, используется первая колонка
- Передача данных для анализа структуры в функцию поиска колонок
- Логирование процесса поиска колонок
