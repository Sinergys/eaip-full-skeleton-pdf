# ИСПРАВЛЕНИЕ ОШИБКИ: name 'DATA_DIR' is not defined

## Проблема
При отправке документа на валидацию возникает ошибка:
```
NameError: name 'DATA_DIR' is not defined
```

## Причина
В эндпоинте `/api/validate-word-document` используется переменная `DATA_DIR`, которая не определена в `main.py`.

## Решение

### Шаг 1: Проверка текущего состояния
```powershell
cd C:\eaip
.\check_data_dir.ps1
```

### Шаг 2: Применение исправления
```powershell
cd C:\eaip
.\fix_data_dir_error.ps1
```

Скрипт автоматически:
- ✅ Создаст резервную копию `main.py.backup_TIMESTAMP`
- ✅ Добавит определение `DATA_DIR` после `AGGREGATED_DIR`
- ✅ Создаст директорию для временных файлов

### Шаг 3: Перезапуск сервиса
**КРИТИЧНО**: После исправления обязательно перезапустите сервис!

1. В терминале с `uvicorn` нажмите **Ctrl+C**
2. Запустите заново:

## Что добавляется в код

```python
# Временная директория для обработки файлов (для Word валидации и т.д.)
DATA_DIR = Path(os.getenv("DATA_DIR", os.path.join(INBOX_DIR, "temp")))
DATA_DIR.mkdir(parents=True, exist_ok=True)
```

Эта директория будет использоваться для:
- Временного хранения загруженных Word документов
- Обработки файлов перед AI-анализом
- Других промежуточных операций

## По поводу постраничной обработки больших документов

### Текущая реализация
Сейчас документ обрабатывается целиком:
- Извлекается весь текст (до 15000 символов)
- Извлекаются первые 5 таблиц
- Отправляется на AI-анализ одним запросом

### Рекомендации для больших документов (>10 МБ)

#### Вариант 1: Увеличение лимитов (простое решение)
Модифицировать эндпоинт для обработки больших файлов:
```python
# Увеличить лимиты извлечения
text_content = text[:50000]  # вместо 15000
tables_data = tables[:20]     # вместо 5
```

#### Вариант 2: Постраничная обработка (продвинутое)
Для документов >20 МБ можно разбить на страницы:
1. Извлекать по 5-10 страниц за раз
2. Анализировать каждую часть отдельно
3. Агрегировать результаты

**Преимущества:**
- ✅ Меньше нагрузка на память
- ✅ Возможность обработки очень больших файлов
- ✅ Параллельная обработка частей

**Недостатки:**
- ❌ Сложнее реализация
- ❌ Возможна потеря контекста между частями
- ❌ Больше API-запросов к AI
