📋 ОБЯЗАТЕЛЬНО ОЗНАКОМЬСЯ:

1. **Единый файл задач:** `docs/AGENT_TASKS_UNIFIED.json`
   - Это **единственный источник правды** для всех задач проекта.
   - Все решения и история выполнения фиксируются только в этом файле.
   - Для удобного просмотра используйте `docs/AGENT_TASKS_UNIFIED.md`.

2. **Утилита для работы с задачами:** `tools/unified_tasks_manager.py`
   - Это **основной инструмент** для взаимодействия с файлом задач. Используйте его для загрузки, блокировки и обновления задач.

---

⚡ КАК НАЧАТЬ РАБОТУ:

```python
# ШАГ 1: Импорт необходимых утилит
from tools.unified_tasks_manager import (
    load_tasks, get_available_tasks_unified,
    lock_task_unified, unlock_task_unified,
    update_task, add_solution, add_execution
)

# ШАГ 2: Загрузить и проверить доступные задачи
tasks_data = load_tasks()
print(f"✅ Единый файл задач загружен. Всего задач: {tasks_data['metadata']['total_tasks']}")

# ШАГ 3: Выбрать задачу с наивысшим приоритетом (сначала P0, потом P1)
available = get_available_tasks_unified(priority="P0")
if not available:
    print("✅ Задач P0 нет, ищу задачи P1...")
    available = get_available_tasks_unified(priority="P1")

if available:
    task = available[0]
    task_id = task["id"]
    print(f"🚀 Выбрана задача: {task_id} - {task['name']}")
    
    # ШАГ 4: Заблокировать задачу и обновить ее статус
    if lock_task_unified(task_id, "agent_2", duration_minutes=15):
        update_task(task_id, {"status": "in_progress"}, "agent_2")
        print(f"✅ Задача {task_id} заблокирована. Можно приступать к работе.")
        
        # ШАГ 5: РАБОТАТЬ НАД ЗАДАЧЕЙ (максимум 10 минут!)
        # ... здесь выполняется основная логика ...
        
        # ШАГ 6: После завершения блока — зафиксировать результат
        add_execution(task_id, {
            "block_number": 1,
            "status": "in_progress", # или "completed", если задача полностью решена
            "completed": ["Что сделано в блоке"],
            "next_step": "Что планируется сделать в следующем блоке",
            "files_changed": ["path/to/file.py"],
            "time_spent_minutes": 10
        }, "agent_2")
        
        # ШАГ 7: Снять блокировку
        unlock_task_unified(task_id, "agent_2")
        print(f"✅ Блок работы завершен, блокировка с задачи {task_id} снята.")
        
        # ШАГ 8: Предоставить краткий отчет (TLDV)
        print("""
        ## БЛОК 1: [Название задачи]
        
        **Выполнено:**
        - [Краткое описание проделанной работы]
        
        **Следующий шаг:**
        - [План на следующий блок]
        
        **Ожидание:** Ожидаю ваших указаний для продолжения.
        """)
    else:
        print(f"⚠️ Не удалось заблокировать задачу {task_id}. Возможно, она уже занята.")
else:
    print("✅ Нет доступных задач для выполнения.")
```

📝 ВАЖНЫЕ ПРАВИЛА:

1. **ВСЕГДА работай с единым файлом задач:**
   - Читай задачи из `AGENT_TASKS_UNIFIED.json`
   - Фиксируй решения через `add_solution()`
   - Фиксируй выполнение через `add_execution()`
   - Обновляй статус через `update_task()`

2. **Блокировки:**
   - Блокируй в едином файле (`lock_task_unified`)
   - Блокируй в системе синхронизации (`lock_task`)
   - Всегда снимай блокировки после работы
   - Используй `lock_task_unified()` перед началом работы.
   - Используй `unlock_task_unified()` после завершения блока.

3. **Время работы:**
   - Максимум 10 минут в блоке
   - Блокировка на 15 минут
   - После блока - TLDV отчёт

4. **Приоритеты:**
   - P0 (критично) - сначала
   - P1 (важно) - потом
   - P2 (рекомендуется) - в конце
