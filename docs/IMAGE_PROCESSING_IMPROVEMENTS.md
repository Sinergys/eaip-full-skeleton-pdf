# 🖼️ Улучшения обработки изображений в Intelligent Router

## ✅ Что было исправлено

### Проблема
При загрузке изображения "т-3а.jpg" Intelligent Router определял:
- `document_type`: "unknown"
- `resource_type`: "unknown"  
- `confidence`: 0.48 (низкая)

### Решение

1. **Улучшена обработка OCR-текста**
   - Router теперь извлекает текст из OCR результатов
   - Анализирует содержимое изображения, а не только имя файла

2. **Определение типа документа для изображений**
   - **Показания счетчиков**: файлы с "т-3", "счетчик", "показания" → `meter_readings`
   - **Термограммы**: файлы с "термограмм", "теплов" → `photo_thermogram`
   - **Акты баланса**: отсканированные акты → `balance_act`

3. **Определение типа ресурса из OCR-текста**
   - Анализирует OCR-текст на наличие ключевых слов (квтч, м³, гкал и т.д.)
   - Определяет тип ресурса по содержимому изображения

4. **Повышение уверенности**
   - Для `meter_readings` и `photo_thermogram` добавляется бонус к уверенности
   - Если есть структурированные данные (таблицы, страницы), уверенность повышается

5. **Маршрутизация для изображений**
   - `meter_readings` → `file_parser` + `ocr_data_adapter`
   - `photo_thermogram` → `file_parser` (низкий приоритет)

## 📊 Ожидаемые результаты

```json
{
  "document_type": "unknown",
  "resource_type": "unknown",
  "data_type": "meter_readings",

```

**После улучшений:**

```json
  "resource_type": "electricity",  // если в OCR-тексте есть "квтч" или "квт"

  "confidence": 0.7+  // выше благодаря определению типа
}
```

## ⚠️ Важное замечание

**Изображения vs Excel файлы:**

Изображения (JPG, PNG) с показаниями счетчиков:
- ✅ Могут быть загружены и обработаны через OCR
- ✅ Intelligent Router определит тип документа
- ⚠️ **НО** для генерации энергетического паспорта нужны **Excel файлы** с структурированными данными

**Для проекта "Навои ТЭС" нужны:**
- `gaz.xlsx` - данные по газу
- `ograjdayuschie.xlsx` - ограждающие конструкции  
- `uzly_ucheta.xlsx` - узлы учета

Изображения могут быть **дополнительными материалами**, но не заменяют Excel файлы с данными.

## 📝 Технические детали

### Извлечение OCR-текста

Router теперь ищет OCR-текст в следующих местах:
- `raw_json["parsing"]["data"]["text"]`
- `raw_json["parsing"]["data"]["ocr_text"]`
- `raw_json["data"]["text"]`
- `raw_json["data"]["ocr_text"]`

### Ключевые слова для определения

**Показания счетчиков:**
- "т-3", "т3", "т-3а", "счетчик", "meter", "показания"

**Термограммы:**
- "термограмм", "thermogram", "теплов", "инфракрас"

**Ресурсы:**
- Электроэнергия: "квтч", "квт", "электр"
- Газ: "м³", "м3", "газ", "куб"
- Тепло: "гкал", "тепло", "отопление"
