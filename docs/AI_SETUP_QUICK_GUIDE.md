## 🚀 Способ 1: Через PowerShell скрипт (самый простой)

### Шаг 1: Запустите скрипт

Откройте PowerShell в директории проекта:

```powershell

```

1. Выберите провайдера (1 - DeepSeek, 2 - OpenAI, 3 - Anthropic)

### Шаг 1: Создайте файл `.env`

**Вариант А: Скопируйте пример файла**
```powershell
cd C:\eaip\eaip_full_skeleton\services\ingest

```

**Вариант Б: Создайте вручную**

Создайте файл `.env` в директории `eaip_full_skeleton/services/ingest/`:

**Путь:** `C:\eaip\eaip_full_skeleton\services\ingest\.env`

### Шаг 2: Добавьте настройки

**Для DeepSeek (рекомендуется, дешевле):**
```env

```

**Для OpenAI:**
```env

```

**Для Anthropic:**
```env
AI_ENABLED=true
AI_PROVIDER=anthropic
ANTHROPIC_API_KEY=sk-ant-ваш-ключ-здесь
```

### Шаг 3: Установите python-dotenv

Если еще не установлен:

```bash
pip install python-dotenv
```

### Шаг 4: Обновите код для загрузки .env

Убедитесь, что в начале `main.py` есть загрузка .env:

```python
from dotenv import load_dotenv
load_dotenv()  # Загружает переменные из .env файла
```

### Шаг 5: Перезапустите сервер

```bash
uvicorn main:app --reload --port 8001
```

## 🔑 Способ 3: Системные переменные окружения Windows (постоянно)

### Шаг 1: Откройте настройки системы

1. Нажмите `Win + R`
2. Введите `sysdm.cpl` и нажмите Enter
3. Перейдите на вкладку **"Дополнительно"**
4. Нажмите **"Переменные среды"**

### Шаг 2: Добавьте переменные

**Для пользователя (только для вас):**
- Нажмите **"Создать"** в разделе "Переменные среды пользователя"
- Добавьте:
  - `AI_ENABLED` = `true`
  - `AI_PROVIDER` = `deepseek` (или `openai`, `anthropic`)
  - `DEEPSEEK_API_KEY` = `sk-ваш-ключ` (или `OPENAI_API_KEY`, `ANTHROPIC_API_KEY`)

**Для системы (для всех пользователей):**
- Нажмите **"Создать"** в разделе "Системные переменные"
- Добавьте те же переменные

### Шаг 3: Перезапустите терминал и сервер

1. Закройте все окна PowerShell/CMD
2. Откройте новое окно
3. Запустите сервер:
   ```bash
   cd C:\eaip\eaip_full_skeleton\services\ingest
   uvicorn main:app --reload --port 8001
   ```

## ⚠️ Устранение проблем

### Проблема: "AI не настроен" после настройки

**Решение:**
1. Убедитесь, что переменные окружения установлены правильно
2. Перезапустите сервер (закройте и откройте заново)
3. Проверьте, что `.env` файл находится в правильной директории
4. Проверьте логи сервера на наличие ошибок

### Проблема: "DEEPSEEK_API_KEY не установлен"

**Решение:**
1. Проверьте, что ключ скопирован полностью (включая `sk-`)
2. Убедитесь, что нет лишних пробелов в начале/конце
3. Проверьте имя переменной (должно быть `DEEPSEEK_API_KEY`, не `DEEPSEEK_API`)

### Проблема: Переменные окружения не загружаются из .env

**Решение:**
1. Убедитесь, что установлен `python-dotenv`: `pip install python-dotenv`
2. Проверьте, что в `main.py` есть `load_dotenv()`
3. Убедитесь, что `.env` файл находится в той же директории, что и `main.py`
