## 📄 Поддержка PDF

**Да, PDF можно загружать!**

Система поддерживает:
- ✅ PDF с текстом (извлекается напрямую)
- ✅ PDF со сканами (используется OCR)
- ✅ PDF с таблицами (распознаются автоматически)

**Что происходит с PDF:**
1. Система пытается извлечь текст напрямую
2. Если текст не найден → используется OCR (Tesseract)
3. Если OCR не установлен → файл обрабатывается как есть (может быть пустым)

**Рекомендация:** Для PDF со сканами убедитесь, что установлен Tesseract OCR.

### Ошибка импорта:
```

```

### Нет данных для импорта:
```
⚠️ Данные ресурсов отсутствуют в агрегированных данных
```

## 🎯 Ожидаемый результат

После успешной загрузки файла:

1. **В логах:**
   - Видны сообщения о начале импорта
   - Видны детали каждой записи
   - Видно сообщение об успешном завершении

2. **В базе данных:**
   - Появляются записи в таблице `aggregated_data`
   - Каждая запись = один ресурс + один период

3. **При проверке:**
   - `check_import_status.py` показывает количество записей > 0
   - Видны импортированные ресурсы и периоды

## ❓ Если что-то пошло не так

### Сервис не запустился:
```powershell
cd C:\eaip\eaip_full_skeleton\services\ingest
.\start_service.ps1
```

### Ошибка при импорте:
- Проверьте логи в консоли
- Ошибки будут с префиксом `❌ ОШИБКА ПРИ ИМПОРТЕ`
- Детали ошибки будут в логах

### Данные не импортировались:
- Проверьте, что агрегация прошла успешно
- Проверьте, что в файле есть данные ресурсов
- Запустите `check_import_status.py` для диагностики
