- `Sheet1` - служебный
- `Узел учета` - узлы учета
- `Структура пр 2` - **основной лист** с данными по ресурсам

- Трубы ХВС: **630 кВт**

## 📊 Структура данных для передачи

```python
from pathlib import Path
from services.reports.energy_passport import generate_energy_passport

# Пути
template_path = Path("data/source_files/audit_sinergys/Энергопаспорт Метин Ирода_с_объемами_и_месяцами.xlsx")
output_path = Path("output/generated_passport.xlsx")

# Данные предприятия
enterprise_data = {
    "id": "metin-iroda",
    "name": "Метин Ирода",
    "inn": "123456789",
}

# Данные о здании
building_data = {
    "area_m2": 5000.0,
}

# Агрегированные данные
aggregated_data = {
    "resources": {
        "gas": {
            "2023-Q1": {
                "year": 2023,
                "quarter": 1,
                "months": [
                    {"month": "Январь", "values": {"volume_m3": 4800.0}},
                    {"month": "Февраль", "values": {"volume_m3": 5100.0}},
                    {"month": "Март", "values": {"volume_m3": 4919.0}},
                ],
            },
            # ... другие кварталы
        },
        "electricity": {
            "2023-Q1": {
                "year": 2023,
                "quarter": 1,
                "quarter_totals": {
                    "active_kwh": 100000.0,
                    "reactive_kvarh": 50000.0,
                },
            },
        },
        "production": {
            # ... данные по производству
        },
    }
}

# Генерация
result = generate_energy_passport(
    enterprise_id="metin-iroda",
    year=2023,

    output_path=output_path,

    enterprise_data=enterprise_data,
    building_data=building_data,

```

## ✅ Что заполняется автоматически

1. **Лист "Структура пр 2":**
   - ✅ Газ по кварталам (из помесячных данных, в тысячах м³)
   - ✅ Разбивка газа: собственные нужды и хоз-быт
   - ✅ Электроэнергия активная/реактивная
   - ✅ Электроэнергия по видам продукции (норма, факт, перерасход)

2. **Лист "Удельный расход газа":**
   - ✅ Удельный расход на 1 м² здания
   - ✅ Удельный расход на условную единицу продукции
   - ✅ Отклонения от нормативов

3. **Другие листы:**
   - ✅ Узлы учета (если предоставлен `nodes_json_path`)
   - ✅ Оборудование (если предоставлен `equipment_json_path`)
   - ✅ Ограждающие конструкции (если предоставлен `envelope_json_path`)
   - ✅ Потери (если указаны `loss_active_month` и т.д.)

---

## ⚠️ Важные замечания

1. **Газ должен быть в помесячных данных** - это гарантирует правильность квартальных и годовых сумм
2. **Значения газа записываются в тысячах м³** - автоматически делится на 1000
3. **Формулы в шаблоне сохраняются** - не перезаписываются
4. **E32 (2023 Q1 газ) будет исправлено** - рассчитывается из месячных данных (4800+5100+4919 = 14819 м³ = 14.819 тыс. м³)
