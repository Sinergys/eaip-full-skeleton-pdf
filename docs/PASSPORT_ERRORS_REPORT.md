### ❌ Обнаруженные ошибки

#### 1. Неправильное значение в ячейке E32

**Лист:** `Структура пр 2`  
**Ячейка:** E32  
**Строка:** 32  
**Описание:** Значение газа за 2023 Q1

**Проблема:**
- **Текущее значение:** 14.0819 (тыс. м³)
- **Ожидаемое значение:** 14.819 (тыс. м³)
- **Разница:** 0.7371 (тыс. м³) = 737.1 м³

**Причина:**
Значение введено вручную с ошибкой. Правильное значение должно рассчитываться из помесячных данных:
- Январь 2023: 4800 м³
- Февраль 2023: 5100 м³
- Март 2023: 4919 м³
- **Итого:** 14819 м³ = **14.819 тыс. м³**

**Решение:**
✅ **Исправлено в коде генерации** - функция `fill_struktura_pr2()` теперь рассчитывает газ из помесячных данных, что гарантирует правильность значения.

## 🔧 Рекомендации

### 1. Использовать автоматическую генерацию

**Проблема:** Ручной ввод данных приводит к ошибкам (как в E32)

**Решение:** Использовать функцию `generate_energy_passport()`, которая:
- ✅ Рассчитывает газ из помесячных данных
- ✅ Автоматически заполняет все необходимые поля
- ✅ Гарантирует правильность расчетов
- ✅ Сохраняет формулы в шаблоне

### 2. Проверка данных перед генерацией

Перед генерацией убедиться, что:
- ✅ Данные по газу предоставлены помесячно
- ✅ Данные по электроэнергии предоставлены по кварталам
- ✅ Данные по производству предоставлены по видам продукции
- ✅ Площадь здания указана

### 3. Валидация после генерации

После генерации рекомендуется проверить:
- ✅ Значения газа в ячейках E32, E70, E108 и т.д. (должны быть в тысячах м³)
- ✅ Суммы кварталов = сумме месяцев
- ✅ Годовые суммы = сумме кварталов
- ✅ Разбивка газа: собственные нужды + хоз-быт = общее потребление
