**Агент:** Agent-1 (Auto)

---

## 🎯 ЦЕЛЬ ТЕСТИРОВАНИЯ

Проверить полный цикл генерации энергопаспорта от загрузки файла до проверки листа "Баланс" в сгенерированном Excel.

---

## 📋 ЭТАПЫ ТЕСТИРОВАНИЯ

### Этап 1: Подготовка окружения

**Время:** ~5 минут

1. ✅ Проверить наличие ingest service
2. ✅ Проверить наличие тестовых данных
3. ✅ Проверить наличие шаблона паспорта
4. ✅ Убедиться, что все зависимости установлены

**Команды:**
```bash
# Проверка сервиса
curl http://localhost:8001/health

# Или запуск сервиса
cd eaip_full_skeleton/services/ingest
uvicorn main:app --reload --port 8001
```

---

### Этап 2: Загрузка тестовых данных

**Время:** ~2 минуты

1. Открыть веб-интерфейс: `http://localhost:8001/web/upload`
2. Выбрать тестовый Excel файл с энергоданными
3. Загрузить файл
4. Получить `batch_id`

**Ожидаемый результат:**
- Файл успешно загружен
- Получен `batch_id`
- Статус обработки: `success`

---

### Этап 3: Генерация паспорта

**Время:** ~3 минуты

1. Перейти на страницу результатов: `http://localhost:8001/web/results/{batch_id}`
2. Нажать кнопку "📊 Сгенерировать энергопаспорт"
3. Дождаться завершения генерации
4. Скачать сгенерированный файл

**Ожидаемый результат:**
- Паспорт успешно сгенерирован
- Файл скачивается без ошибок
- Файл имеет расширение `.xlsx`

**API endpoint:**
```bash
POST /api/generate-passport/{batch_id}
```

---

### Этап 4: Проверка листа "Баланс"

**Время:** ~5 минут

1. Открыть сгенерированный Excel файл
2. Найти лист "04_Баланс" или "Баланс"
3. Запустить автоматическую проверку:
   ```bash
   python tools/test_full_passport_cycle.py <путь_к_паспорту.xlsx>
   ```
4. Проверить вручную по чеклисту: `docs/BALANCE_SHEET_CHECKLIST.md`

**Ожидаемый результат:**
- Лист "Баланс" существует
- Заголовки корректны
- Формулы в колонке "Итого" работают
- Строка "ИТОГО" содержит формулы суммирования
- Все проверки пройдены

---

## ✅ ЧЕКЛИСТ ПРОВЕРКИ

### Общие проверки:
- [ ] Файл паспорта существует и открывается
- [ ] Лист "Баланс" найден
- [ ] Заголовки корректны (6 колонок)

### Проверка данных:
- [ ] Есть строки с данными (кварталы)
- [ ] Значения в колонках B-E неотрицательные
- [ ] Кварталы указаны корректно (формат: "2022-Q1")

### Проверка формул:
- [ ] Колонка F содержит формулы `=SUM(B<row>:E<row>)`
- [ ] Строка "ИТОГО" содержит формулы суммирования
- [ ] Формулы работают корректно (нет ошибок #REF!, #VALUE!)

### Проверка расчётов:
- [ ] Сумма в колонке F = сумма колонок B+C+D+E для каждой строки
- [ ] Сумма в строке "ИТОГО" = сумма всех строк для каждой колонки
- [ ] Итоговая сумма корректна

## ⚠️ ВОЗМОЖНЫЕ ПРОБЛЕМЫ

### Проблема 1: Сервис не запущен
**Решение:** Запустить `uvicorn main:app --reload --port 8001`

### Проблема 2: Нет тестовых данных
**Решение:** Использовать существующие файлы из `C:\AUDIT\OBJECTS\` или создать тестовые данные

### Проблема 3: Паспорт не генерируется
**Решение:** Проверить логи сервиса, убедиться, что данные в БД корректны

### Проблема 4: Лист "Баланс" не заполнен
**Решение:** Проверить, что в агрегированных данных есть данные по электроэнергии с категориями потребления
