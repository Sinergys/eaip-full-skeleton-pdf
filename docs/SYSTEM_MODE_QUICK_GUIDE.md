# 🔧 Переключатель режимов - Краткая инструкция

## Режимы работы

### 🔧 DEBUG (Отладка)
**Всегда переобрабатывать файлы**

```bash
export SYSTEM_MODE=debug
```

### 🚀 PRODUCTION (Работа) - по умолчанию
**Пропускать файлы без изменений**

```bash
export SYSTEM_MODE=production
# или не указывать
```

## Как работает

### DEBUG режим:
- Найден дубликат → удалить старую запись → переобработать

### PRODUCTION режим:
- Найден дубликат → сравнить hash:
  - Совпадает → пропустить (файл не изменился)
  - Отличается → переобработать (файл обновлен)

## Использование

### Для разработки/тестирования:
```bash
SYSTEM_MODE=debug python -m uvicorn main:app
```

### Для production:
```bash
# По умолчанию production
python -m uvicorn main:app
```

## Логи

При старте системы:
```
🔧 Режим работы системы: DEBUG (для изменения установите SYSTEM_MODE=debug или SYSTEM_MODE=production)
```

При обнаружении дубликата:
- DEBUG: `🔧 [DEBUG MODE] Дубликат найден, переобрабатываем файл`
- PRODUCTION (hash совпадает): `✅ Найден дубликат. Файл не изменился, пропускаем`
- PRODUCTION (hash отличается): `🔄 Дубликат найден, но файл обновлен. Переобрабатываем`
