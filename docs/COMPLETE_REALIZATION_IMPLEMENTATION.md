## 🔧 Технические улучшения

### 1. Улучшенный алгоритм поиска колонок

**Функция `_find_column_indices`:**
- Добавлен параметр `sheet_name` для определения типа листа
- Добавлен параметр `rows_data` для анализа структуры данных
- Специальная логика для листов "Баланс"

**Расширенные ключевые слова:**
- **Название узла:** "потребитель", "потребители", "объект", "объекты"
- **Активная энергия:** "активная мощность", "активная, квт", "p, квт"
- **Реактивная энергия:** "реактивная мощность", "реактивная, квар", "q, квар"
- **Стоимость:** "стоимость, сум.", "сумма к оплате"

### 2. Функция анализа структуры

**`_analyze_balance_sheet_structure`:**
- Анализирует первые 5 строк данных
- Ищет колонку с текстовыми значениями (названия узлов)
- Ищет колонки с числовыми значениями (энергия, стоимость)
- Автоматически определяет колонки на основе анализа

### 3. Fallback механизм

- Если колонка с названиями не найдена, используется первая колонка
- Для листов "Баланс" применяется специальная логика
