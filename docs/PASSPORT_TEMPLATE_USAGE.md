# Использование шаблона энергетического паспорта

## Назначение

Эталонный шаблон энергетического паспорта используется для генерации паспортов по ПКМ №690. Шаблон содержит все необходимые листы, формулы и связи между листами. Генератор заполняет шаблон данными из агрегированных JSON и CanonicalSourceData, сохраняя при этом все формулы из эталонного файла.

**Важно:** Генератор всегда работает с **копией** эталонного шаблона, чтобы защитить оригинальный файл от изменений.

---

## Путь к шаблону

### Конфигурация шаблонов

Пути к шаблонам определены в файле `templates/pcm690/templates_config.py`.

### Доступные шаблоны

| Имя шаблона | Путь к файлу | Описание |
|-------------|--------------|----------|
| `default` | `templates/pcm690/energy_passport_template.xlsx` | Дефолтный шаблон (основной) |
| `metin` | `templates/pcm690/template_metin.xlsx` | Шаблон для Metin IRODA |
| `new_energy_passport` | `templates/pcm690/new_energy_passport.xlsx` | Новый шаблон |

### Получение пути к шаблону

```python
from templates.pcm690.templates_config import get_template_path

# Получить путь к дефолтному шаблону
template_path = get_template_path("default")

# Получить путь к шаблону Metin
template_path = get_template_path("metin")
```

## Основные листы и их роль

### 1. **02_Структура** / **Struktura pr2**

**Назначение:** Квартальное распределение потребления по видам энергоресурсов.

**Заполняется из:**
- Агрегированные данные (`aggregated.json`)
- Ресурсы: `electricity`, `gas`, `water`, `fuel`, `coal`, `heat`

**Данные:**
- Активная электроэнергия (кВт·ч) по кварталам
- Реактивная электроэнергия (кВАр·ч) по кварталам
- Газ (м³) по кварталам
- Вода (м³) по кварталам
- Потери трансформатора (если указаны)

**Функция заполнения:** `fill_struktura_pr2()` в `tools/fill_energy_passport.py`

---

### 2. **01_Узлы учета**

**Назначение:** Перечень узлов учета электроэнергии.

**Заполняется из:**
- CanonicalSourceData (если режим `assist` или `strict`)
- JSON файл `{batch_id}_nodes.json`
- Данные по умолчанию (если нет других источников)

**Данные:**
- Пункты учёта
- Вид учёта мощности (P, Q, TT, КT)
- Место установки
- Коэффициент учёта
- Даты пломбировки

**Функция заполнения:** `fill_nodes_sheet()` в `tools/fill_energy_passport.py`

---

### 3. **03_Оборудование** / **Equipment**

**Назначение:** Перечень основного оборудования и анализ эффективности.

**Заполняется из:**
- CanonicalSourceData (если режим `assist` или `strict`)
- JSON файл `{batch_id}_equipment.json`
- Парсер файла "ОБОРУДОВАНИЕ"

**Таблицы:**
- **ПЕРЕЧЕНЬ ОСНОВНОГО ОБОРУДОВАНИЯ:**
  - Наименование
  - Тип
  - Мощность (кВт)
  - Год установки
  - Коэффициент использования
  - Годовое потребление (кВт·ч)

- **АНАЛИЗ ЭФФЕКТИВНОСТИ ОБОРУДОВАНИЯ:**
  - Показатели эффективности (формулы из шаблона сохраняются)

**Функция заполнения:** `fill_equipment_sheet()` в `tools/fill_energy_passport.py`

**Особенности:**
- Автоматическое исправление циклических ссылок в формулах
- Защита формул от перезаписи
- Поддержка двух структур таблицы (старая и новая)

---

### 4. **04_Баланс**

**Назначение:** Сводный баланс потребления с распределением по категориям использования.

**Заполняется из:**
- Агрегированные данные по кварталам
- CanonicalSourceData (by_usage распределение)
- JSON файл `{batch_id}_usage.json` (если есть)

**Данные:**
- Распределение по категориям использования:
  - Технологические нужды
  - Производственные нужды
  - Собственные нужды
  - Хозяйственные нужды
- Поквартальные данные по ресурсам

**Функция заполнения:** `fill_balans_sheet()` в `tools/fill_energy_passport.py`

**Особенности:**
- Автоматическое вычисление `by_usage` для всех кварталов (даже без оборудования)
- Стандартное распределение: 50% technological, 30% production, 15% own_needs, 5% household

---

### 5. **05_Динамика**

**Назначение:** Динамика потребления по кварталам.

**Заполняется из:**
- Агрегированные данные по кварталам

**Функция заполнения:** `fill_dinamika_sheet()` в `tools/fill_energy_passport.py`

---

### 6. **06_Мероприятия**

**Назначение:** Перечень энергосберегающих мероприятий.

**Заполняется из:**
- JSON файл `{batch_id}_measures.json` (если есть)

**Функция заполнения:** `fill_meropriyatiya_sheet()` в `tools/fill_energy_passport.py`

---

### 7. Дополнительные листы

- **Потери электроэнергии:** Расчет потерь трансформатора
- **Удельное потребление:** Показатели удельного расхода
- **Топливо (мазут, уголь):** Динамика потребления топлива
- **Ограждающие конструкции:** Данные о здании (если есть envelope JSON)

## Процесс генерации

### Шаг 1: Копирование шаблона

**Критически важно:** Генератор всегда работает с копией шаблона, а не с оригиналом.

```python
import shutil
from pathlib import Path

# Определяем путь к эталонному шаблону
template_path = get_template_path("default")

# Создаем временную копию
output_dir = Path("/tmp/passports")
temp_template_path = output_dir / f"{batch_id}_passport_template_copy.xlsx"
shutil.copyfile(template_path, temp_template_path)

# Загружаем копию для работы
workbook = load_workbook(temp_template_path, data_only=False)
```

**Где реализовано:**
- `eaip_full_skeleton/services/ingest/main.py` (строка 1690-1695)
- `tools/fill_energy_passport.py` (строка 2067-2076)

---

### Шаг 2: Загрузка данных

**Источники данных:**
1. **Агрегированные данные:** `{batch_id}_aggregated.json` или из БД
2. **CanonicalSourceData:** Из парсера Excel файлов (если режим `assist`/`strict`)
3. **JSON файлы:**
   - `{batch_id}_nodes.json` - узлы учета
   - `{batch_id}_equipment.json` - оборудование
   - `{batch_id}_envelope.json` - ограждающие конструкции
   - `{batch_id}_usage.json` - категории использования
   - `{batch_id}_measures.json` - мероприятия

---

### Шаг 3: Заполнение листов

**Порядок заполнения:**
1. **02_Структура** - квартальные данные по ресурсам
2. **01_Узлы учета** - узлы учета
3. **03_Оборудование** - перечень оборудования
4. **04_Баланс** - баланс с by_usage
5. **05_Динамика** - динамика потребления
6. **06_Мероприятия** - мероприятия (если есть)
7. Дополнительные листы (потери, удельное потребление и т.д.)

**Важно:** Все функции заполнения используют `_safe_set_cell_value()`, которая защищает формулы от перезаписи.

---

### Шаг 4: Сохранение результата

```python
# Сохраняем заполненный паспорт
output_file = output_dir / f"{batch_id}_energy_passport.xlsx"
workbook.save(output_file)
```

**Результат:** Файл паспорта с заполненными данными, но с сохраненными формулами из шаблона.

## Как обновлять шаблон

### Если меняется форма паспорта

1. **Обновить эталонный шаблон:**
   - Открыть `templates/pcm690/energy_passport_template.xlsx` в Excel
   - Внести изменения в структуру листов
   - Добавить/изменить формулы
   - Сохранить файл

2. **Проверить структуру диапазонов:**
   - Убедиться, что диапазоны формул (строки/колонки) соответствуют ожиданиям заполняющих функций
   - Проверить названия листов (они должны совпадать с именами в коде)

3. **Перепроверить лист Equipment:**
   - Убедиться, что таблицы "ПЕРЕЧЕНЬ ОСНОВНОГО ОБОРУДОВАНИЯ" и "АНАЛИЗ ЭФФЕКТИВНОСТИ ОБОРУДОВАНИЯ" имеют правильную структуру
   - Проверить, что формулы в итоговых строках работают корректно

4. **Перепроверить лист Баланс:**
   - Убедиться, что формулы для суммирования квартальных данных работают
   - Проверить структуру by_usage распределения

5. **Тестирование:**
   - Прогнать генерацию на тестовом batch (например, METIN IRODA)
   - Проверить, что все листы заполняются корректно
   - Убедиться, что формулы работают и не появляются ошибки #ДЕЛ/0!

## Связь с CanonicalSourceData

### Режимы работы

**Режим `off`:**
- CanonicalSourceData не используется
- Данные берутся только из JSON файлов
- `by_usage` вычисляется принудительно с стандартным распределением

**Режим `assist` или `strict`:**
- CanonicalSourceData собирается из загруженных Excel файлов
- Используется для заполнения:
  - Узлов учета (`canonical.nodes`)
  - Оборудования (`canonical.equipment`)
  - Годовых итогов (`canonical.resources[].series.annual`)
  - Распределения by_usage (`canonical.resources[].series.by_usage`)

### Листы, использующие CanonicalSourceData

1. **01_Узлы учета:**
   - Источник: `canonical_payload["nodes"]`
   - Функция: `fill_nodes_sheet()`

2. **03_Оборудование:**
   - Источник: `canonical_payload["equipment"]`
   - Функция: `fill_equipment_sheet()`

3. **04_Баланс:**
   - Источник: `canonical_payload["balance"]["annual_totals"]` и `by_usage`
   - Функция: `fill_balans_sheet()`
   - Распределение: `_distribute_canonical_by_usage_to_quarters()` в `readiness_validator.py`

## Проверка корректности

### Тестовый batch

**Рекомендуемый batch для тестирования:** METIN IRODA

**Проверка:**
1. Все листы эталонного шаблона присутствуют в результирующем файле
2. Формулы и связи в расчётных листах работают
3. Оригинальный шаблон (в `templates/`) не меняется по дате/размеру после генерации
4. Нет ошибок #ДЕЛ/0! (кроме тех, что были в шаблоне)
5. Данные по оборудованию заполнены корректно
6. by_usage вычисляется для всех кварталов

### Команда для проверки

```bash
# Генерация паспорта через API
curl -X POST "http://localhost:8000/api/generate-passport/{batch_id}?template_name=default"

# Или через CLI
python tools/fill_energy_passport.py \
  --template-name default \
  --aggregated data/aggregated/{batch_id}_aggregated.json \
  --output /tmp/{batch_id}_energy_passport.xlsx \
  --equipment-json data/aggregated/{batch_id}_equipment.json
```

## Защита формул

### Механизм защиты

Все функции заполнения используют `_safe_set_cell_value()`, которая:
1. Проверяет наличие формулы в ячейке перед записью
2. Если формула есть - пропускает запись
3. Если формулы нет - записывает значение

**Реализация:**
```python
def _safe_set_cell_value(ws, row, col, value, preserve_formula=True):
    """Безопасно устанавливает значение ячейки, сохраняя формулы если нужно"""
    cell = ws.cell(row=row, column=col)
    if preserve_formula and cell.data_type == 'f' and cell.value:
        # Если в ячейке есть формула, не перезаписываем её
        return False
    cell.value = value
    return True
```

### Автоматическое исправление циклических ссылок

Перед заполнением листа Equipment автоматически вызывается `_fix_circular_references()`, которая:
- Находит формулы, ссылающиеся на сами себя
- Исправляет диапазоны, исключая текущую ячейку
- Логирует все исправления
