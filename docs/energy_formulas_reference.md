## Общие принципы

### Базовые единицы измерения

- **Электроэнергия:** кВт·ч (киловатт-час)
- **Реактивная энергия:** кВАр·ч (киловар-час)
- **Мощность:** кВт (киловатт)
- **Газ:** м³ (кубический метр)
- **Вода:** м³ (кубический метр)
- **Топливо/Уголь:** т (тонна)
- **Тепло:** Гкал (гигакалория)
- **Производство:** кг (килограмм)

### Правила расчётов

1. Все входные данные нормализуются к базовым единицам перед расчётами
2. Защита от деления на ноль во всех формулах
3. Проверка на отрицательные и нереалистичные значения
4. Логирование предупреждений при некорректных данных

## Формулы по листам

### 1. Лист "Struktura pr2" (Структура потребления)

**Назначение:** Отображение потребления энергоресурсов по кварталам

**Показатели:**
- Активная электроэнергия (кВт·ч)
- Реактивная электроэнергия (кВАр·ч)
- Газ (м³)
- Вода (м³)
- Потери активной энергии (кВт·ч)
- Потери реактивной энергии (кВАр·ч)

**Формулы:**
- Потери за квартал = Потери за месяц × 3

**Единицы:**
- Электроэнергия: кВт·ч
- Реактивная: кВАр·ч
- Газ: м³
- Вода: м³

**Источник данных:**
- `agg_data.resources.electricity[quarter].quarter_totals.active_kwh`
- `agg_data.resources.electricity[quarter].quarter_totals.reactive_kvarh`
- `agg_data.resources.gas[quarter].quarter_totals.volume_m3`
- `agg_data.resources.water[quarter].quarter_totals.volume_m3`

---

### 2. Лист "04_Баланс" (Энергетический баланс)

**Назначение:** Распределение потребления электроэнергии по категориям

**Показатели:**
- Технологические нужды (кВт·ч)
- Собственные нужды (кВт·ч)
- Производственные нужды (кВт·ч)
- Хоз-бытовые нужды (кВт·ч)
- Итого (кВт·ч)

**Формула:**
```
Итого = Технологические + Собственные_нужды + Производственные + Хоз-бытовые
```

**Единицы:** кВт·ч

**Источник данных:**
- `agg_data.resources.electricity[quarter].by_usage.technological`
- `agg_data.resources.electricity[quarter].by_usage.own_needs`
- `agg_data.resources.electricity[quarter].by_usage.production`
- `agg_data.resources.electricity[quarter].by_usage.household`

**Fallback:** Если `by_usage` отсутствует, используется пропорциональное распределение из `usage_data.years[year]`

---

### 3. Лист "05_Динамика" (Динамика потребления)

**Назначение:** Динамика потребления и удельные показатели

**Показатели:**
- Электроэнергия (кВт·ч)
- Газ (м³)
- Вода (м³)
- Производство (кг)
- Удельный расход (кВт·ч/кг)

**Формула удельного расхода:**
```
Удельный_расход = Электроэнергия / Производство
```

**Единицы:**
- Электроэнергия: кВт·ч
- Газ: м³
- Вода: м³
- Производство: кг
- Удельный расход: кВт·ч/кг

**Edge-кейсы:**
- Если производство = 0, удельный расход = 0
- Если производство < 0.001 кг, удельный расход = 0 (защита от деления на очень малое число)

**Источник данных:**
- `agg_data.resources.electricity[quarter].quarter_totals.active_kwh`
- `agg_data.resources.gas[quarter].quarter_totals.volume_m3`
- `agg_data.resources.water[quarter].quarter_totals.volume_m3`
- `agg_data.resources.production[quarter].quarter_totals.production_kg`

---

### 4. Лист "Equipment" (Оборудование)

**Назначение:** Перечень оборудования и анализ эффективности

**Показатели:**
- Установленная мощность (кВт)
- Используемая мощность (кВт)
- Потребленная мощность (кВт)
- Коэффициент использования (безразмерный, 0-1)
- Годовое потребление (кВт·ч)
- Мощность на единицу (кВт)
- Количество единиц (шт.)

**Формулы:**

1. **Используемая мощность:**
```
Используемая_мощность = Установленная_мощность × 0.8
```
(Коэффициент 0.8 = 80% - стандартное значение)

2. **Коэффициент использования:**
```
Коэффициент_использования = Используемая_мощность / Установленная_мощность
```
Ограничивается максимумом 1.0

3. **Годовое потребление:**
```
Годовое_потребление = Используемая_мощность × 8760
```
(8760 часов в году)

4. **Мощность на единицу:**
```
Мощность_на_единицу = Общая_мощность / Количество_единиц
```

**Единицы:**
- Мощность: кВт
- Потребление: кВт·ч
- Количество: шт.

**Edge-кейсы:**
- Если установленная мощность = 0, коэффициент использования = 0
- Если количество единиц = 0, мощность на единицу = 0

**Источник данных:**
- `equipment_data.summary.total_power_kw`
- `equipment_data.summary.total_items`
- `equipment_data.sheets[].sections[].items[].total_power_kw`

---

### 5. Лист "08_Потери_электроэнергии" (Потери)

**Назначение:** Расчёт потерь в трансформаторе

**Показатели:**
- Мощность трансформатора (кВА)
- Потери активной энергии за месяц (кВт·ч)
- Потери реактивной энергии за месяц (кВАр·ч)
- Количество часов в месяце (ч)
- Процент потерь активной энергии (%)
- Процент потерь реактивной энергии (%)
- Потери активной энергии за квартал (кВт·ч)
- Потери реактивной энергии за квартал (кВАр·ч)

**Формулы:**

1. **Процент потерь активной энергии:**
```
Процент_потерь = (Потери_месяц / (Мощность_кВА × 0.9 × Часы)) × 100
```
(Коэффициент 0.9 = cos φ для конвертации кВА → кВт)

2. **Процент потерь реактивной энергии:**
```
Процент_потерь_реакт = (Потери_реакт_месяц / (Мощность_кВА × 0.9 × Часы)) × 100
```

3. **Потери за квартал:**
```
Потери_квартал = Потери_месяц × 3
```

**Единицы:**
- Мощность: кВА
- Потери: кВт·ч, кВАр·ч
- Процент: %
- Время: ч

**Edge-кейсы:**
- Если мощность или часы = 0, процент потерь = 0
- Процент ограничивается диапазоном 0-100%

**Источник данных:**
- Параметры функции: `loss_active_month`, `loss_reactive_month`, `transformer_power_kva`, `hours_per_month`

---

### 6. Лист "Расход на ед.п" (Удельный расход)

**Назначение:** Расход энергоресурсов на единицу продукции

**Показатели:**
- Удельный расход электроэнергии (кВт·ч/кг)

**Формула:**
```
Удельный_расход = Электроэнергия_квартал / Производство_квартал
```

**Единицы:** кВт·ч/кг

**Edge-кейсы:**
- Если производство = 0, удельный расход = 0
- Если производство < 0.001 кг, удельный расход = 0
- Если результат > 1,000,000 кВт·ч/кг, считается нереалистичным и возвращается 0

**Источник данных:**
- `agg_data.resources.electricity[quarter].quarter_totals.active_kwh`
- `agg_data.resources.production[quarter].quarter_totals.production_kg`

## Единицы измерения

### Константы преобразования

**Электроэнергия:**
- 1 МВт·ч = 1000 кВт·ч
- 1 ГВт·ч = 1,000,000 кВт·ч

**Реактивная энергия:**
- 1 МВАр·ч = 1000 кВАр·ч

**Мощность:**
- 1 МВт = 1000 кВт

**Объём:**
- 1 тыс. м³ = 1000 м³
- 1 л = 0.001 м³

**Масса:**
- 1 т = 1000 кг

**Тепло:**
- 1 Гкал = 4.1868 ГДж (приблизительно)
- 1 Гкал = 1.163 МВт·ч (приблизительно)

**Время:**
- 1 год = 8760 часов
- 1 квартал = 2160 часов (3 месяца × 720 часов)
- 1 месяц = 720 часов (30 дней × 24 часа)
- 1 сутки = 24 часа

## Обработка edge-кейсов

### 1. Нулевые значения

**Правило:** Все формулы защищены от деления на ноль

**Примеры:**
- Удельный расход при производстве = 0 → возвращает 0
- Коэффициент использования при мощности = 0 → возвращает 0
- Процент потерь при мощности = 0 → возвращает 0

### 2. Отрицательные значения

**Правило:** Отрицательные значения нормализуются до 0 с предупреждением

**Примеры:**
- Отрицательное потребление → используется 0, логируется предупреждение
- Отрицательное производство → используется 0, логируется предупреждение

### 3. Нереалистично большие значения

**Правило:** Проверка на разумность результата

**Примеры:**
- Удельный расход > 1,000,000 кВт·ч/кг → считается ошибкой, возвращается 0
- Потребление > 100,000,000 кВт·ч → логируется предупреждение

### 4. Очень малые значения

**Правило:** Порог для защиты от деления на очень малое число

**Примеры:**
- Производство < 0.001 кг → считается нулевым для расчёта удельного расхода

### 5. Неполные данные

**Правило:** Использование доступных данных, логирование отсутствующих

**Примеры:**
- Отсутствие данных по категориям → используется пропорциональное распределение из годовых данных
- Отсутствие данных по кварталу → используется 0 с предупреждением

## Справочная таблица формул

| Лист | Показатель | Формула | Единицы | Edge-кейсы |
|------|-----------|---------|---------|------------|
| Struktura pr2 | Потери за квартал | `Потери_месяц × 3` | кВт·ч | - |
| 04_Баланс | Итого | `Σ(категории)` | кВт·ч | Отрицательные → 0 |
| 05_Динамика | Удельный расход | `Энергия / Производство` | кВт·ч/кг | Производство = 0 → 0 |

| Equipment | Годовое потребление | `Мощность × 8760` | кВт·ч | - |
| Equipment | Мощность на единицу | `Общая / Количество` | кВт | Количество = 0 → 0 |
| 08_Потери | Процент потерь | `(Потери / (Мощность × Часы)) × 100` | % | Мощность/Часы = 0 → 0 |
| Расход на ед.п | Удельный расход | `Энергия / Производство` | кВт·ч/кг | Производство = 0 → 0 |
