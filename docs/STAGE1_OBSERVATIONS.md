# Stage 1 – Smoke Test Notes (2025‑11‑09)

## Summary
- Последовательность «загрузить → распознать → при необходимости исправить → сохранить» работает через сервис `ingest` и SQLite.
- Страница `/web/results?batchId=...` теперь корректно отображает метаданные и данные парсинга: устранена ошибка экранирования кавычек в JS.
- Редактирование и сохранение текста подтверждено автоматическим Playwright-скриптом и ручной проверкой.

## Smoke Test Steps
1. Запуск `uvicorn services.ingest.main:app --reload --port 8001`.
2. Загрузка XLSX-файла через `http://localhost:8001/web/upload` с привязкой к предприятию.
3. Перенаправление на `/web/results?batchId=...`, проверка отображения карточек и JSON превью.
4. Внесение правок в текстовое поле «Редактирование данных», сохранение и повторная загрузка страницы — изменения сохраняются.
5. Повторная загрузка (`Обновить данные`) корректно подтягивает свежие данные с сервера.

## Known Behaviour / Suggestions
- Кнопку «Сохранить» требуется нажимать только при изменении текста; без правок запрос к API не отправляется.
- Кнопка «Обновить данные» полезна для ручного сравнения с сервером, но может быть скрыта или переименована («Перечитать») в финальном UI.
- При сохранении отображается сообщение с временной отметкой; стоит унифицировать формат даты/времени (локаль).
- Рекомендуется добавить подсветку отличий между `editable_text` и исходным JSON в будущих версиях.
- Дополнительно: логировать ошибки fetch в Sentry/общее хранилище, если появится централизованная система мониторинга.
