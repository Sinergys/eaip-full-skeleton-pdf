# Руководство по обновлению Cursor IDE

## 🎯 Рекомендуемый способ обновления

### Вариант 1: Автоматическое обновление (РЕКОМЕНДУЕТСЯ)

1. **Через меню IDE:**
   - Откройте Cursor IDE
   - Перейдите в меню: `Help` → `Check for Updates`
   - Если есть обновление, IDE предложит его установить
   - Следуйте инструкциям на экране

2. **Автоматическая проверка:**
   - Cursor обычно проверяет обновления автоматически
   - При наличии обновления появится уведомление
   - Нажмите "Update" в уведомлении

**Преимущества:**
- ✅ Сохраняются все настройки
- ✅ Сохраняются расширения
- ✅ Быстро и просто
- ✅ Не нужно вручную скачивать

---

### Вариант 2: Ручное обновление (если автоматическое не работает)

#### Шаг 1: Скачать новую версию

1. Перейдите на официальный сайт:
   - https://cursor.sh/
   - Или https://www.cursor.com/

2. Скачайте установщик для Windows:
   - Выберите версию для Windows
   - Обычно это `.exe` файл

#### Шаг 2: Установка поверх существующей версии

**Рекомендуется:** Установить новую версию поверх старой

1. Закройте Cursor IDE (если открыт)
2. Запустите скачанный установщик
3. Следуйте инструкциям установщика
4. Обычно установщик автоматически:
   - Обновит существующую версию
   - Сохранит настройки
   - Сохранит расширения

**Преимущества:**
- ✅ Сохраняются настройки
- ✅ Сохраняются расширения
- ✅ Не нужно удалять старую версию

---

### Вариант 3: Полная переустановка (если есть проблемы)

⚠️ **Используйте только если:**
- Автоматическое обновление не работает
- Установка поверх не работает
- Есть серьезные проблемы с IDE

#### Шаг 1: Сохранить настройки (ВАЖНО!)

1. **Экспорт настроек:**
   - Откройте Cursor
   - `File` → `Preferences` → `Settings`
   - Нажмите на иконку `...` (три точки) в правом верхнем углу
   - Выберите `Export Settings` или скопируйте настройки вручную

2. **Список расширений:**
   - Запишите список установленных расширений
   - Или сделайте скриншот

3. **Рабочие пространства:**
   - Убедитесь, что все проекты сохранены
   - Запомните пути к открытым папкам

#### Шаг 2: Удаление старой версии

1. **Через Панель управления:**
   - Откройте `Панель управления` → `Программы и компоненты`
   - Найдите "Cursor"
   - Нажмите "Удалить"
   - Следуйте инструкциям

2. **Или через Параметры Windows:**
   - `Параметры` → `Приложения` → `Установленные приложения`
   - Найдите "Cursor"
   - Нажмите "Удалить"

3. **Очистка остатков (опционально):**
   - Удалите папку: `%APPDATA%\Cursor`
   - Удалите папку: `%LOCALAPPDATA%\Cursor`
   - ⚠️ **ВНИМАНИЕ:** Это удалит все настройки!

#### Шаг 3: Установка новой версии

1. Скачайте последнюю версию с официального сайта
2. Запустите установщик
3. Следуйте инструкциям установщика
4. После установки:
   - Восстановите настройки (если экспортировали)
   - Установите расширения заново
   - Откройте рабочие пространства

## 📋 Проверка версии

### Как узнать текущую версию:

1. В Cursor IDE:
   - `Help` → `About`
   - Или `Ctrl+Shift+P` → введите "About"

2. В меню:
   - Обычно версия отображается в нижнем правом углу
   - Или в заголовке окна

---

## 🔧 Рекомендации

### Перед обновлением:

1. ✅ **Сохраните все файлы** - `Ctrl+S` или `File` → `Save All`
2. ✅ **Закройте все проекты** - чтобы избежать конфликтов
3. ✅ **Сделайте бэкап настроек** (если используете полную переустановку)
4. ✅ **Закройте Cursor** перед установкой новой версии

### После обновления:

1. ✅ Проверьте, что все расширения работают
2. ✅ Проверьте настройки
3. ✅ Откройте проект и проверьте работоспособность

---

## 🆘 Решение проблем

### Проблема: Обновление не устанавливается

**Решение:**
1. Закройте все процессы Cursor через Диспетчер задач
2. Запустите установщик от имени администратора
3. Попробуйте вариант 2 (ручное обновление)

### Проблема: Потерялись настройки

**Решение:**
1. Проверьте папки:
   - `%APPDATA%\Cursor`
   - `%LOCALAPPDATA%\Cursor`
2. Если папки существуют, настройки должны быть сохранены
3. Если нет - восстановите из бэкапа (если делали)

### Проблема: Расширения не работают

**Решение:**
1. Переустановите расширения:
   - `Ctrl+Shift+X` → найдите расширение → `Reinstall`
2. Проверьте совместимость с новой версией
3. Обновите расширения до последних версий
