# Руководство по загрузке нормативных документов

## Статус
✅ **Система готова к загрузке нормативных документов**

## Что готово
1. ✅ Таблицы БД для хранения нормативных документов и правил
2. ✅ Endpoint для загрузки документов с AI-анализом
3. ✅ Модуль импорта с извлечением формул и нормативов
4. ✅ Интеграция с БД нормативных документов

## Как загрузить нормативные документы

### Вариант 1: Через API endpoint

```bash
# Загрузка документа ПКМ 690
curl -X POST "http://localhost:8001/api/normative/upload" \
  -F "file=@path/to/PKM690.pdf" \
  -F "title=ПКМ №690" \
  -F "document_type=PKM690"
```

**Параметры:**
- `file` (обязательный) - файл документа (PDF, Word, Excel)
- `title` (опционально) - название документа. Если не указано, берется из имени файла
- `document_type` (опционально) - тип документа:
  - `PKM690` - Постановление Кабинета Министров №690
  - `GOST` - ГОСТ
  - `SNiP` - СНиП
  - `SanPiN` - СанПиН
  - `PUE` - ПУЭ
  - `PTEEP` - ПТЭЭП
  - `normative` - общий нормативный документ

### Вариант 2: Через веб-интерфейс (если есть)

1. Откройте страницу загрузки нормативных документов
2. Выберите файл (PDF, Word, Excel)
3. Укажите название и тип документа
4. Нажмите "Загрузить"

### Вариант 3: Через Python скрипт

```python
from eaip_full_skeleton.services.ingest.domain.normative_importer import get_normative_importer

importer = get_normative_importer()

result = importer.import_normative_document(
    file_path="path/to/PKM690.pdf",
    title="ПКМ №690",
    document_type="PKM690"
)

print(f"Обработано правил: {result['rules_extracted']}")
```

## Что происходит при загрузке

1. **Парсинг документа** - файл парсится через `file_parser`
2. **AI-анализ** - AI извлекает формулы, нормативы и требования
3. **Сохранение в БД**:
   - Документ сохраняется в таблицу `normative_documents`
   - Правила сохраняются в таблицу `normative_rules`
   - Связи с полями паспорта сохраняются в `normative_references`

## Проверка загруженных документов

### Список всех документов

```bash
curl "http://localhost:8001/api/normative/documents"
```

### Правила определенного типа

```bash
curl "http://localhost:8001/api/normative/rules/formula"
curl "http://localhost:8001/api/normative/rules/normative"
```

### Правила для конкретного поля паспорта

```bash
curl "http://localhost:8001/api/normative/rules/for-field/Удельный%20расход?sheet_name=Динамика%20ср"
```

## Требования

### 1. AI должен быть включен

Убедитесь, что в `.env` установлено:
```
AI_ENABLED=true
AI_PROVIDER=deepseek  # или openai, anthropic
DEEPSEEK_API_KEY=your_api_key  # или OPENAI_API_KEY, ANTHROPIC_API_KEY
```

### 2. База данных инициализирована

Таблицы создаются автоматически при первом запуске приложения через `database.init_db()`

### 3. Форматы файлов

Поддерживаются:
- **PDF** - документы с текстом или сканированные (с OCR)
- **Word** (.docx) - документы Microsoft Word
- **Excel** (.xlsx) - таблицы Excel

## Примеры документов для загрузки

1. **ПКМ №690** - основной нормативный документ
   - Тип: `PKM690`
   - Содержит: формулы расчета, нормативы, требования к энергопаспорту

2. **ГОСТ 31427-2010** - энергетические показатели
   - Тип: `GOST`
   - Содержит: нормативы удельных показателей

3. **СНиП 23-02-2003** - тепловая защита зданий
   - Тип: `SNiP`
   - Содержит: формулы расчета теплопотерь

4. **ПУЭ** - правила устройства электроустановок
   - Тип: `PUE`
   - Содержит: нормативы по электроэнергии

## Использование нормативов в расчетах

После загрузки документов, нормативы автоматически доступны в модуле расчетов:

```python
from eaip_full_skeleton.services.ingest.domain.energy_passport_calculations import get_normative_value

# Получить нормативное значение для поля
normative = get_normative_value("Удельный расход электроэнергии", document_type="PKM690")
if normative:
    print(f"Норматив: {normative}")
```

## Устранение проблем

### Ошибка: "AI парсер недоступен"
**Решение:** Проверьте настройки AI в `.env` и убедитесь, что API ключ корректный

### Ошибка: "database модуль недоступен"
**Решение:** Убедитесь, что вы запускаете из правильной директории и модуль `database.py` существует

### Документ загружен, но правила не извлечены
**Решение:**
1. Проверьте логи приложения на наличие ошибок AI-анализа
2. Убедитесь, что документ содержит текст (не только изображения)
3. Попробуйте включить verbose режим: `ENERGY_PASSPORT_DEBUG=true`

### Документ не распознается
**Решение:** 
1. Убедитесь, что формат файла поддерживается (PDF, Word, Excel)
2. Проверьте размер файла (максимум 50 МБ)
3. Для PDF используйте текстовые PDF, а не только сканированные
