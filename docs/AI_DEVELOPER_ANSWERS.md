### 5. Приоритет ошибок

**Ответ:** Предлагаю следующую **классификацию ошибок**:

#### 🔴 **Критическая ошибка (Critical)**

**Определение:** Ошибка, делающая весь отчет недействительным или невозможным для дальнейшей обработки.

**Примеры:**
- ❌ Ошибка в формуле расчета энергобаланса (сумма не сходится)
- ❌ Отсутствует обязательный раздел "Balans" в энергопаспорте
- ❌ Некорректные единицы измерения (кВт·ч вместо кВар·ч)
- ❌ Отрицательные значения потребления (физически невозможно)
- ❌ Несоответствие итоговых сумм (активная энергия ≠ сумме по узлам)

**Действие:** Блокировать дальнейшую обработку, требовать исправления.

#### 🟠 **Существенная ошибка (Major)**

**Определение:** Отсутствует обязательный раздел или данные, но отчет можно частично обработать.

**Примеры:**
- ⚠️ Отсутствует раздел "Meropriyatiya" (мероприятия)
- ⚠️ Отсутствуют данные за один из кварталов
- ⚠️ Отсутствует информация о предприятии
- ⚠️ Нет данных по одному из энергоресурсов (газ, вода)
- ⚠️ Отсутствуют удельные показатели

**Действие:** Продолжить обработку, но пометить как неполный, показать предупреждения.

#### 🟡 **Предупреждение (Warning)**

**Определение:** Описательная часть содержит неопределенность или отклонение от стандарта.

**Примеры:**
- ⚠️ Использование неопределенных формулировок ("примерно", "порядка", "около")
- ⚠️ Отклонение от стандартного формата дат
- ⚠️ Использование нестандартных единиц измерения (требуется пересчет)
- ⚠️ Низкая уверенность OCR (< 80%)
- ⚠️ Подозрительные значения (слишком большие/маленькие, но физически возможные)

**Действие:** Показать предупреждение, предложить проверить вручную.

#### 🔵 **Информация (Info)**

**Определение:** Отклонение от шаблона оформления, не влияющее на данные.

**Примеры:**
- ℹ️ Отклонение от стандартного оформления таблиц
- ℹ️ Использование других шрифтов/цветов
- ℹ️ Дополнительные листы, не предусмотренные шаблоном
- ℹ️ Нестандартный порядок листов

**Действие:** Зафиксировать в метаданных, не блокировать обработку.

#### 📊 **Структура ответа ИИ:**

```json
{
  "errors": [
    {
      "severity": "critical|major|warning|info",
      "type": "calculation_error|missing_data|format_deviation|...",
      "location": "sheet_name!A1:B10",
      "message": "Описание ошибки",
      "suggestion": "Рекомендация по исправлению",
      "confidence": 0.95
    }
  ],
  "summary": {
    "critical_count": 0,
    "major_count": 2,
    "warning_count": 5,
    "info_count": 3
  }
}
```

### 6. Интеграция с экспертом

**Ответ:** Предлагаю следующий **рабочий процесс аудитора**:

#### 🔄 **Процесс работы:**

```
1. Загрузка файлов
   ↓
2. Автоматический ИИ-анализ
   ↓
3. Отчет ИИ с найденными ошибками и рекомендациями
   ↓
4. Интерфейс верификации (аудитор проверяет/исправляет)
   ↓

   ↓

   ↓
```

**Компоненты:**

   - Возможность исправить данные вручную

   - Требование ТЗ: до 30 секунд для файла до 50 МБ

   - OCR: 10 минут (для больших PDF)

#### 🎯 **Рекомендации для ИИ-анализа:**

1. **Быстрый анализ (обязательно для всех файлов):**
   - Время: < 5 секунд
   - Объем данных: Первые 3-5 листов Excel, первые 2-3 страницы PDF
   - Цель: Определение типа документа, базовые проверки

2. **Детальный анализ (для сложных файлов):**
   - Время: < 30 секунд
   - Объем данных: Все листы/страницы
   - Цель: Полная проверка логики, выявление всех ошибок

3. **Глубокий анализ (опционально):**
   - Время: < 2 минут
   - Объем данных: Полный файл + сравнение с эталонами
   - Цель: Семантический анализ, генерация рекомендаций

#### 💡 **Оптимизация:**

1. **Кэширование результатов ИИ** - для одинаковых файлов
2. **Асинхронная обработка** - не блокировать основной процесс
3. **Приоритизация** - быстрый анализ для всех, детальный только при необходимости
4. **Пакетная обработка** - для нескольких файлов одновременно
