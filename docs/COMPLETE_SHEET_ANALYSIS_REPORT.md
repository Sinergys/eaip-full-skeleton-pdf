## 🔗 Связи между листами

### Потоки данных (Data Flow)

1. **Структура пр 2 → Баланс**
   - Тип: `consumption_data`
   - Описание: Данные о потреблении передаются из структуры в баланс

2. **Структура пр 2 → Динамика ср**
   - Тип: `time_series_data`
   - Описание: Квартальные данные используются для анализа динамики

3. **Баланс → Динамика ср**
   - Тип: `aggregated_data`
   - Описание: Сводные данные баланса используются в динамике

4. **Структура пр 2 → Расход на ед.п**
   - Тип: `specific_consumption`
   - Описание: Данные потребления используются для расчета удельных показателей

### Зависимости (Dependencies)

1. **Узел учета → Структура пр 2**
   - Причина: Информация об узлах учета необходима для правильного распределения потребления

2. **Структура пр 2 → Баланс**
   - Причина: Баланс формируется на основе данных структуры потребления

3. **Баланс → Динамика ср**
   - Причина: Динамика строится на основе данных баланса
