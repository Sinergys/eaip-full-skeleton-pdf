## Обнаруженные проблемы

### 1. ⚠️ Тип данных сохраняется как 'consumption' вместо 'realization'

**Проблема:** Данные из файлов "Реализация" сохраняются с типом `consumption` вместо `realization`.

**Причина:** Функция `extract_nodes_from_raw_json` определяет тип данных по имени файла, но возможно, что при сохранении тип не передается правильно.

**Статус:** Требуется исправление

### 2. ⚠️ Листы "Баланс 04" и "Баланс 00" не обрабатываются

**Проблема:** Для некоторых файлов листы "Баланс 04" и "Баланс 00" не обрабатываются из-за ошибки "Не найдена колонка с названиями узлов".

**Причина:** Структура листов "Баланс" может отличаться от листов "Реал", и алгоритм поиска колонок не находит нужные колонки.

**Статус:** Требуется доработка алгоритма поиска колонок

### 3. ⚠️ Период определяется как 'unknown'

**Проблема:** Для всех записей период определяется как 'unknown'.

**Причина:** Функция `_extract_period_from_text` не может извлечь период из названий листов "Реал 04", "Реал 00" и т.д.

**Статус:** Требуется улучшение извлечения периода
