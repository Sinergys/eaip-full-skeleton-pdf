**Обновлено:** 2025‑11‑09

## 1. Оглавление листов и назначение

- `Struktura pr2` — квартальное распределение по видам энергоресурсов (электроэнергия актив/реактив, газ, мазут, вода и т.д.). Требует восстановить ссылки для строк «Общее потребление по предприятию» на итоги листа `Balans`.
- `Balans` — сводный баланс с расшифровкой «на технологические / собственные / производственные» и т.п. Формулы должны суммировать квартальные данные по каждому ресурсу.
- `Dinamika sr`, `mazut 5`, `Rashod na ed prod` — таблицы динамики и удельных показателей (поквартально за три года).
- `Meropriyatiya` — перечень мероприятий (единицы измерения: тыс.кВт·ч, тыс.м³, т.у.т.).
- `Sheet1`, `Uzel ucheta` — методическая и паспортная информация (незаполненные формулы).

## 2. Сопоставление квартальных данных

- **Электроэнергия:** `JSON["electricity"][year-quarter]["quarter_totals"]`  
  - `active_kwh` → активное потребление, кВт·ч  
  - `reactive_kvarh` → реактивная энергия  
  - `cost_sum` → стоимость, сум  
  - `active_other` → дополнительный показатель (свериться с оригинальными формулами)

- **Газ:** `JSON["gas"][…]["quarter_totals"]`  
  - `volume_m3` — объём, м³  
  - `cost_sum` — стоимость, сум  
  - `extra` — дополнительная колонка (надо уточнить назначение, в исходном шаблоне отображалась в правой части таблицы)

- **Вода:** `JSON["water"][…]["quarter_totals"]`  
  - `volume_m3`, `cost_sum` — в `Struktura pr2` колонка «Вода», в `Balans` → раздел «Вода».

- **Производство:** `JSON["production"][…]["quarter_totals"]`  
  - `Жами` — итог по всей продукции; использовать в динамике `Rashod na ed prod`.  
  - Остальные поля (`Труба хвс`, `Канал труба`, `Канал фитинг`, `Фит хвс и гвс`, `Теплый пол`) — по видам продукции.
