# Task 5: Связка структуры ПКМ-690 с содержанием по образцу

## Обзор

Создан маппинг между структурой ПКМ-690 и содержанием образцового отчёта "МЕТИН ИРОДА ОТЧЕТ 1107.docx".

## Созданные файлы

1. **`eaip_full_skeleton/services/ingest/domain/pkm690_sections.py`**
   - Определяет структуру разделов ПКМ-690
   - Маппинг на разделы образцового отчёта
   - Требования к данным для каждого раздела
   - Текстовые шаблоны для каждого раздела

2. **`eaip_full_skeleton/services/ingest/utils/section_template_filler.py`**
   - Функция `fill_section_template()` для заполнения шаблонов данными
   - Построение контекста из ReportData
   - Обработка ошибок и fallback

## Структура разделов ПКМ-690

1. **ВВЕДЕНИЕ** - Цель аудита, нормативная база
2. **ОБЩИЕ СВЕДЕНИЯ О ПРЕДПРИЯТИИ** - Информация о предприятии, процессы
3. **АНАЛИЗ ЭНЕРГОПОТРЕБЛЕНИЯ** - Потребление по ресурсам, удельные показатели
4. **АНАЛИЗ ОБОРУДОВАНИЯ** - Список оборудования, мощность
5. **МЕРОПРИЯТИЯ ПО ЭНЕРГОСБЕРЕЖЕНИЮ** - Рекомендации, экономия
6. **ЭКОНОМИЧЕСКИЙ АНАЛИЗ** - Затраты, эффект от мероприятий
7. **ЗАКЛЮЧЕНИЕ** - Выводы и рекомендации
8. **ПРИЛОЖЕНИЯ** - Дополнительные таблицы и графики

## Маппинг на образцовый отчёт

Каждый раздел ПКМ-690 соответствует одному или нескольким разделам из образцового отчёта:

- Раздел 1 → "Вводная часть"
- Раздел 2 → "Общие сведения о предприятии", "Местоположение и основные параметры", "Описание технологических процессов"
- Раздел 3 → "Анализ объема выпущенной продукции", "Расход электроэнергии на единицу продукции", "Динамика расхода энергии"
- И т.д.

## Требования к данным

Для каждого раздела определены:
- **required_kpis** - минимальные КПИ, необходимые для генерации
- **optional_kpis** - опциональные КПИ для улучшения качества
- **required_tables** - обязательные таблицы
- **optional_tables** - опциональные таблицы
- **allow_empty** - можно ли генерировать без данных (с fallback)
