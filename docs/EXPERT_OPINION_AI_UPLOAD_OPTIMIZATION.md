### 2. ML Engineer: Многоуровневый ИИ-анализ

**Рекомендация:** Использовать многоуровневый подход к ИИ-анализу.

**Уровень 1: Быстрый анализ (для всех файлов)**
- Определение типа документа (акт, отчет, справка, баланс)
- Определение типа ресурса (electricity, gas, water и т.д.)
- Определение типа данных (consumption, production, realization)
- Базовая структура (листы Excel, страницы PDF)

**Уровень 2: Детальный анализ (для сложных файлов)**
- Анализ логики данных (корректность расчетов, соответствие форматам)
- Выявление аномалий (отсутствующие данные, несоответствия)
- Проверка ошибок (дубликаты, некорректные значения)
- Валидация структуры (правильность таблиц, заголовков)

**Уровень 3: Глубокий анализ (опционально, для критических файлов)**
- Семантический анализ содержимого
- Сравнение с эталонными шаблонами
- Генерация рекомендаций по улучшению
- Предсказание проблем обработки

**Реализация:**
```python
def analyze_file_multi_level(file_path: str) -> Dict[str, Any]:
    """
    Многоуровневый анализ файла
    """
    # Уровень 1: Быстрый анализ (обязательно)
    level1 = quick_analysis(file_path)
    
    # Уровень 2: Детальный анализ (если нужно)
    if level1.get("needs_detailed_analysis"):
        level2 = detailed_analysis(file_path, level1)
    
    # Уровень 3: Глубокий анализ (опционально)
    if level2.get("needs_deep_analysis"):
        level3 = deep_analysis(file_path, level1, level2)
    
    return combine_results(level1, level2, level3)
```

## ⚠️ Риски и ограничения

### 1. Стоимость ИИ-запросов
**Риск:** ИИ-анализ для всех файлов может быть дорогим.

**Решение:**
- Использовать DeepSeek (в 200+ раз дешевле OpenAI)
- Кэшировать результаты для одинаковых файлов
- Использовать быстрый анализ для простых файлов
- Детальный анализ только для сложных файлов

### 2. Время обработки
**Риск:** ИИ-анализ может замедлить процесс загрузки.

**Решение:**
- Асинхронная обработка
- Параллельная обработка нескольких файлов
- Оптимизация промптов для быстрого ответа

### 3. Точность ИИ
**Риск:** ИИ может ошибаться в определении типа или выявлении ошибок.

**Решение:**
- Использовать гибридный подход (ИИ + правила)
- Fallback на традиционные методы
- Валидация результатов ИИ
- Возможность ручной корректировки
