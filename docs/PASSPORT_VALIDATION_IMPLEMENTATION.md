- `04_Баланс` - энергетический баланс (обязателен)
- `05_Динамика` - динамика потребления (обязателен)
- И другие...

### 2. Реализация функции проверки готовности данных ✅

**Файл:** `eaip_full_skeleton/services/ingest/utils/readiness_validator.py`

**Добавлено:**
- Функция `_validate_sheets_data()` - валидация данных для каждого листа
- Функция `_prepare_sheet_data()` - подготовка данных для валидации
- Интеграция с `passport_requirements.py`
- Проверка наличия JSON файлов (equipment, envelope, nodes, usage)
- Детальные сообщения об ошибках

**Улучшена функция `validate_generation_readiness()`:**
- Добавлена валидация по листам
- Новые поля в результате: `sheet_validation`, `missing_sheet_data`
- Более точная оценка готовности с учётом требований листов

### 3. Встроена проверка готовности в endpoint генерации ✅

**Файл:** `eaip_full_skeleton/services/ingest/main.py`

**Изменения:**
- Endpoint `/api/generate-passport/{batch_id}` теперь возвращает детальную информацию о недостающих данных
- Новые поля в ответе ошибки:
  - `missing_sheet_data` - список недостающих данных для листов
  - `sheet_validation` - детальная валидация каждого листа
- Генерация блокируется при неготовности данных (HTTP 400)

## 🔧 Использование

### Проверка готовности данных

```python
from utils.readiness_validator import validate_generation_readiness

readiness = validate_generation_readiness(enterprise_id=1)

if not readiness["ready"]:
    print("Недостающие ресурсы:", readiness["missing_resources"])
    print("Недостающие данные для листов:", readiness["missing_sheet_data"])
    print("Детали валидации:", readiness["sheet_validation"])
```

### Генерация паспорта с проверкой

```bash
# Endpoint автоматически проверяет готовность
POST /api/generate-passport/{batch_id}?template_name=new_energy_passport

# При неготовности возвращает HTTP 400 с детальной информацией
```

### Запуск теста эталонного объекта

```bash
# Установить переменную окружения для детального логирования (опционально)
export INGEST_PASSPORT_DEBUG=true

# Запустить тест
python scripts/test_reference_enterprise.py
```

### Режим DEBUG при заполнении

```bash
# Включить детальное логирование
export INGEST_PASSPORT_DEBUG=true

# Запустить заполнение паспорта
python tools/fill_energy_passport.py --template ... --aggregated ...
```
