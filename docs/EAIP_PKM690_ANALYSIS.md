### Шаг A.2 — Этапы энергоаудита (ПКМ-690 vs ТЗ EAIP)

#### 1. Краткое резюме этапов по ПКМ-690

**Для потребителей топливно-энергетических ресурсов (Приложение 1, Глава 4, пункт 13):**

Процесс энергоаудита состоит из четырёх этапов, детализация которых приведена в схеме приложения 1 к Положению. Точные названия и содержание этапов уточняются по схеме.

**Для зданий и сооружений (Приложение 2, Глава 4, пункты 31-39):**

**Этап 1. Подготовка зданий и сооружений к энергоаудиту**

На данном этапе энергоаудитор проводит изучение проектной документации, выполняет обмерные работы, обследует техническое состояние ограждающих конструкций, инженерных систем и оборудования. При отсутствии проектной документации по результатам обмерных работ и обследования разрабатываются технические характеристики объектов.

**Этап 2. Измерения и проверки**

Выполняются замеры и проверки параметров энергопотребления, которые необходимо проводить летом и зимой для учёта сезонных особенностей. Техническое состояние зданий и сооружений проверяется в присутствии заказчика или его представителя.

**Этап 3. Анализ**

Энергоаудитор осуществляет расчёты теплотехнических и энергетических характеристик зданий и сооружений, определяет показатели энергоэффективности по нормативным документам. Методы расчёта определяются соответствующими нормативными документами в области технического регулирования. Не допускается оценка параметров рационального использования ТЭР косвенно (без проведения анализов и измерений).

**Этап 4. Заключительный этап**

Подведение итогов анализа использования топливно-энергетических ресурсов зданий и сооружений. По результатам энергоаудита составляется отчёт об экономии энергоресурсов и повышении энергоэффективности, формируется энергетический паспорт, определяются категории энергетической эффективности, разрабатываются инструкции (план мероприятий) с экономическим обоснованием.

#### 4. Приоритеты для EAIP

**Приоритет 1: Данные по потреблению энергоресурсов (коммерческий учёт)**

- **Что это:** Статистические отчёты об использованных ТЭР на основе показателей средств измерений, данные о потреблении по видам ресурсов и периодам
- **Почему приоритет:** Критично для всех расчётов энергопаспорта (удельные показатели, баланс, динамика). Без этих данных невозможно выполнить требования ПКМ-690 к обоснованным расчётам. Для Навои ТЭС — основа для расчёта потребления по видам энергии
- **Компонент EAIP:** Импорт/загрузка (4.3, 5.1.1), структура хранения (каноническая модель), валидация полноты (5.3), использование в расчётах (4.6, 5.2.2)

**Приоритет 2: Данные измерений и проверок (сезонные измерения)**

- **Что это:** Показания средств измерений, результаты измерений летом и зимой, протоколы проверок технического состояния
- **Почему приоритет:** ПКМ-690 требует сезонные измерения для зданий и сооружений. Не допускается косвенная оценка без измерений. Для Навои ТЭС — архивы SCADA/DCS, измерения параметров (t, p, G, O₂/CO, мощность)
- **Компонент EAIP:** Импорт/загрузка (4.3, 4.4), структура хранения (привязка к сезонам, датам, присутствующим лицам), валидация полноты (проверка наличия летних и зимних измерений), использование в расчётах (4.6)

**Приоритет 3: Данные по оборудованию и технологиям**

- **Что это:** Перечень основного оборудования, режимы работы, технологические схемы производства
- **Почему приоритет:** Критично для потребителей ТЭР (включая Навои ТЭС). Необходимо для понимания структуры потребления, распределения по категориям, расчёта удельных показателей по видам продукции
- **Компонент EAIP:** Импорт/загрузка (4.3, 5.1.1), структура хранения (отдельные сущности для оборудования, режимов, схем), валидация полноты, использование в расчётах (4.6.4 — структура потребления)

**Приоритет 4: Проектная и техническая документация**

- **Что это:** Проектная документация зданий и сооружений, технические документы на оборудование, принципиальные решения инженерных систем
- **Почему приоритет:** Используется на этапе подготовки для изучения объекта, разработки технических характеристик при отсутствии проектной документации. Влияет на корректность расчётов теплотехнических характеристик
- **Компонент EAIP:** Импорт/загрузка (4.3, 5.1.1), структура хранения (привязка к проекту, типу документа), валидация полноты (проверка наличия необходимых документов для этапа подготовки)

**Приоритет 5: Экономические данные (тарифы, стоимость)**

- **Что это:** Тарифы на энергоресурсы, стоимость энергоресурсов для расчёта экономической эффективности мероприятий
- **Почему приоритет:** ПКМ-690 требует экономическое обоснование мероприятий (сроки окупаемости, рентабельность). Без тарифов невозможно рассчитать экономический эффект. Для Навои ТЭС — важно для обоснования мероприятий
- **Компонент EAIP:** Структура хранения (справочник тарифов, привязка к периодам), использование в расчётах (4.5 — модуль рекомендаций, расчёт экономической эффективности)

**Приоритет 6: Результаты обмерных работ и обследований**

- **Что это:** Результаты обмерных работ, обследование технического состояния ограждающих конструкций и инженерных систем
- **Почему приоритет:** Обязательно для зданий и сооружений на этапе подготовки. Используется для разработки технических характеристик при отсутствии проектной документации
- **Компонент EAIP:** Импорт/загрузка (4.3, 4.4), структура хранения (отдельные сущности для результатов обмеров и обследований), валидация полноты (проверка наличия для зданий/сооружений)

**Приоритет 7: Общие сведения о предприятии и объекте**

- **Что это:** Техническое задание, кадастровые документы, информация о зданиях (объёмно-планировочные решения, материалы, площадь окон, отапливаемая площадь)
- **Почему приоритет:** Основа для создания проекта энергоаудита. Необходимо для расчёта удельных показателей на площадь, определения категории энергоэффективности
- **Компонент EAIP:** Импорт/загрузка (4.2.1, 4.3), структура хранения (4.1.1 — справочники), валидация полноты, использование в расчётах (4.6.6 — удельные показатели)

**Приоритет 8: Результаты предыдущих энергоаудитов**

- **Что это:** Формализованные документы по результатам ранее проведённых энергоаудитов
- **Почему приоритет:** Необходимо для периодических и внеочередных энергоаудитов. Используется для анализа динамики, оценки выполнения ранее выданных предложений
- **Компонент EAIP:** Импорт/загрузка (4.3), структура хранения (4.1.3 — архив проектов), использование в расчётах (4.6.7 — динамика показателей)

##### 5.1. План мероприятий в структуре энергопаспорта

**Проблема:**
- ПКМ-690 требует, чтобы план организационно-технических мероприятий был частью энергопаспорта (Приложение 1, Глава 5, пункты 26-27)
- В ТЗ (4.7.3) план мероприятий не упомянут явно в структуре энергопаспорта (Excel)
- План мероприятий описан в модуле рекомендаций (4.5) и в структуре отчёта (4.7.2), но отсутствует в списке разделов паспорта

**Предложение:**

- Добавить в раздел 4.7.3 ТЗ явное упоминание "план мероприятий по энергосбережению" в структуре энергопаспорта
- Уточнить, что план должен включать экономические показатели (стоимость, срок окупаемости, рентабельность) согласно требованиям ПКМ-690

##### 5.2. Вводная часть отчёта: нормативная база и программа энергоаудита

**Проблема:**
- ПКМ-690 требует, чтобы отчёт включал нормативную базу и программу энергоаудита во вводной части
- В ТЗ (4.7.2) упомянуто только "введение" без детализации содержания

**Предложение:**

- Уточнить в разделе 4.7.2 ТЗ структуру вводной части отчёта:
  - Цель энергоаудита
  - Нормативная база (ПКМ-690 и другие нормативные документы)
  - Программа энергоаудита

##### 5.3. Раздел "Общие сведения о предприятии" в отчёте

**Проблема:**
- ПКМ-690 требует детального описания предприятия, включая технологические процессы и производственные показатели
- В ТЗ (4.7.2) упомянуто только "описание предприятия" без детализации структуры

**Предложение:**

- Уточнить в разделе 4.7.2 ТЗ структуру раздела "Общие сведения о предприятии":
  - Информация о предприятии (наименование, ИНН, адрес, отрасль)
  - Описание технологических процессов
  - Основные производственные показатели

##### 5.4. Раздел "Анализ оборудования" в отчёте

**Проблема:**
- ПКМ-690 требует отдельного раздела "Анализ оборудования" в отчёте
- В ТЗ (4.7.2) этот раздел не упомянут явно в структуре отчёта
- Возможно подразумевается в анализе, но нет явного требования

**Предложение:**

- Добавить в раздел 4.7.2 ТЗ явное упоминание раздела "Анализ оборудования" в структуре отчёта:
  - Перечень основного энергопотребляющего оборудования
  - Мощность и режимы работы
  - Техническое состояние
  - Потенциал энергосбережения

##### 5.5. Раздел "Экономический анализ" в отчёте

**Проблема:**
- ПКМ-690 требует экономического обоснования мероприятий (стоимость, срок окупаемости, рентабельность)
- В ТЗ (4.7.2) экономический анализ не упомянут явно как отдельный раздел отчёта
- Возможно подразумевается в рекомендациях, но нет явного требования

**Предложение:**

- Добавить в раздел 4.7.2 ТЗ явное упоминание раздела "Экономический анализ" в структуре отчёта:
  - Затраты на мероприятия
  - Экономический эффект
  - Сроки окупаемости
  - Рентабельность

**Проблема:**
- ПКМ-690 требует, чтобы план мероприятий включал экономические показатели: стоимость, срок окупаемости, рентабельность (Приложение 1, Глава 5, пункты 26-27; Приложение 2, Глава 4, пункты 45-49)

**Предложение:**

- Уточнить в разделе 4.5 ТЗ требования к структуре плана мероприятий:
  - Обязательные поля: наименование мероприятия, ожидаемая экономия, стоимость, срок окупаемости, рентабельность
  - Обоснованность экономических показателей

**Этап 1. Подготовка к энергоаудиту**

- **Входные данные:**
  - Техническое задание (цель и объём энергоаудита)
  - Проектная документация зданий и сооружений (при наличии)
  - Кадастровые документы
  - Технические документы на оборудование, связанное с потреблением ТЭР
- **Основные задачи:**
  - Изучение проектной документации
  - Выполнение обмерных работ (для зданий и сооружений)
  - Обследование технического состояния ограждающих конструкций и инженерных систем
  - Разработка технических характеристик объектов при отсутствии проектной документации
  - Сбор и проверка исходных документов от заказчика
- **Выходные результаты:**
  - Полный пакет необходимых документов и данных
  - Результаты обмерных работ (при выполнении)
  - Технические характеристики объектов
  - Программа энергоаудита, согласованная с заказчиком

**Этап 2. Измерения и проверки**

- **Входные данные:**
  - Результаты этапа подготовки
  - Показания средств измерений
  - Данные коммерческого учёта
- **Основные задачи:**
  - Проведение измерений параметров энергопотребления
  - Сезонные измерения (летом и зимой) для учёта сезонных особенностей объекта
  - Проверка технического состояния зданий, сооружений и оборудования в присутствии заказчика или его представителя
  - Протоколирование измерений и проверок с указанием даты, присутствующих лиц и результатов
- **Выходные результаты:**
  - Протоколы измерений (летние и зимние)
  - Протоколы проверок технического состояния
  - Верифицированные данные по потреблению энергоресурсов

**Этап 3. Анализ**

- **Входные данные:**
  - Верифицированные данные этапов 1 и 2
  - Нормативные показатели
- **Основные задачи:**
  - Расчёты теплотехнических и энергетических характеристик
  - Определение показателей энергоэффективности по нормативным документам
  - Расчёт удельных показателей, структуры потребления, энергетического баланса
  - Выявление аномалий и проблем
- **Выходные результаты:**
  - Результаты всех расчётов по подсистемам модуля логики энергопаспорта (раздел 4.6)
  - Обоснованные показатели энергоэффективности

**Этап 4. Заключительный этап**

- **Входные данные:**
  - Результаты анализа (этап 3)
  - Все данные проекта
- **Основные задачи:**
  - Подведение итогов анализа использования ТЭР
  - Составление отчёта об экономии энергоресурсов и повышении энергоэффективности
  - Формирование энергетического паспорта
  - Разработка плана организационно-технических мероприятий с экономическим обоснованием
  - Согласование плана мероприятий с заказчиком
- **Выходные результаты:**
  - Итоговый энергетический отчёт (Word)
  - Энергетический паспорт (Excel)
  - План мероприятий с экономическими показателями

**Особенности для разных типов объектов:**

- Для потребителей топливно-энергетических ресурсов: акцент на данных коммерческого учёта, технологических схемах, режимах работы оборудования, архивах SCADA/DCS
- Для зданий и сооружений: акцент на сезонных измерениях, обмерных работах, расчёте категории энергоэффективности

**Отслеживание статуса этапов:**

Система должна отслеживать статус каждого этапа (не начат, в работе, завершён) и обеспечивать возможность возврата к любому этапу для внесения изменений.
