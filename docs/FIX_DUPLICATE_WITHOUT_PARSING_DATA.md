# 🔧 Отчет об исправлении обработки дубликатов без данных парсинга

**Дата:** 2025-12-01  
**Проблема:** Файлы определены как дубликаты, но данные парсинга отсутствуют в БД

---

## 🔍 Анализ проблемы

### Симптомы из логов:

1. **Файлы определены как дубликаты:**
   ```
   Найден дубликат загрузки Реализация 2022.xlsx для предприятия Navoiy IES (batch_id=4e3a88cb-bbd7-4f64-9251-620a02e9a9e6)
   ```

2. **Данные парсинга отсутствуют:**
   ```
   raw_json отсутствует для batch_id=ea402b7c-d394-4b32-ad98-cfda1b248ada, создана минимальная структура
   ```

3. **Нет данных электроэнергии:**
   ```
   ⚠️ Нет данных electricity для распределения by_usage
   ⚠️ [DIAG] Нет данных для агрегации после обработки всех загрузок
   ready=False, completeness=0.15, missing=['electricity', 'envelope', 'nodes']
   ```

### Причины:

1. **Файлы были загружены ранее, но данные парсинга не сохранились:**
   - При первой загрузке произошла ошибка при сохранении данных
   - Или файл был загружен, но парсинг не был выполнен

2. **Дубликаты не обрабатываются заново:**
   - Система находит дубликат и сразу возвращает существующую запись
   - Не проверяет, есть ли данные парсинга

3. **Файлы "Реализация" не обрабатываются как акты балансов:**
   - Определяются как дубликаты до обработки
   - Данные по узлам не извлекаются

## ✅ Выполненные исправления

### 1. Добавлена проверка данных парсинга для дубликатов

**Файл:** `eaip_full_skeleton/services/ingest/main.py`

**Изменения:**
- При обнаружении дубликата проверяется наличие данных парсинга
- Если данных нет - старая запись удаляется и файл обрабатывается заново
- Если данные есть - возвращается существующая запись

```python
if existing_upload:
    existing_batch_id = existing_upload["batch_id"]
    
    # Проверяем, есть ли данные парсинга для дубликата
    existing_record = database.get_upload_by_batch(existing_batch_id)
    has_parsing_data = existing_record and existing_record.get("raw_json")
    
    if not has_parsing_data:
        # Если данных парсинга нет, обрабатываем файл заново
        logger.warning(
            f"⚠️ Дубликат найден, но данные парсинга отсутствуют для batch_id={existing_batch_id}. "
            f"Удаляем старую запись и обрабатываем файл заново..."
        )
        # Удаляем старую запись и продолжаем обработку
        deleted = database.delete_upload_by_batch_id(existing_batch_id)
        # Продолжаем обработку (не возвращаемся)
    else:
        # Данные парсинга есть - возвращаем существующую запись
        return {...}
```

### 2. Добавлена функция удаления загрузки

**Файл:** `eaip_full_skeleton/services/ingest/database.py`

**Изменения:**
- Создана функция `delete_upload_by_batch_id()` для удаления загрузки и всех связанных данных
- Удаляет данные из таблиц: `uploads`, `parsed_data`, `uploads_storage`

```python
def delete_upload_by_batch_id(batch_id: str) -> bool:
    """
    Удаляет загрузку и все связанные данные по batch_id.
    """
    with get_connection() as conn, conn:
        # Получаем upload_id
        row = conn.execute(
            "SELECT id FROM uploads WHERE batch_id = ?", (batch_id,)
        ).fetchone()
        
        if not row:
            return False
        
        upload_id = row["id"]
        
        # Удаляем связанные данные
        conn.execute("DELETE FROM parsed_data WHERE upload_id = ?", (upload_id,))
        conn.execute("DELETE FROM uploads_storage WHERE upload_id = ?", (upload_id,))
        
        # Удаляем саму загрузку
        conn.execute("DELETE FROM uploads WHERE batch_id = ?", (batch_id,))
        
        return True
```
