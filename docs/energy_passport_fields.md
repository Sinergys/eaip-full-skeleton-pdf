# Структура энергопаспорта `new_energy_passport.xlsx`

**Шаблон:** `templates/pcm690/new_energy_passport.xlsx`  
**Дата создания документации:** 2025-01-15  
**Версия шаблона:** ПКМ 690 (Постановление Кабинета Министров №690)

## Общая структура

Шаблон состоит из **8 листов**:

1. **Sheet1** - Нормативно-правовая документация
2. **Узел учета** - Узлы учета энергоресурсов
3. **Структура пр 2** - Структура потребления энергоресурсов (квартально)
4. **Баланс** - Баланс энергоресурсов по категориям потребления
5. **Динамика ср** - Динамика потребления и удельных показателей
6. **мазут,уголь 5** - Динамика потребления топлива (мазут, уголь)
7. **Расход на ед.п** - Удельный расход на единицу продукции
8. **Мериаприятия 1** - Энергосберегающие мероприятия

---

## 1. Sheet1 - Нормативно-правовая документация

**Назначение:** Справочная информация о нормативных документах  
**Тип данных:** Текстовый справочник  
**Размер:** 121 строка × 9 столбцов

### Поля:
- Название документа (столбец 2)
- Номер документа (столбец 3)
- Дата принятия (столбец 4)
- Примечание (столбец 9)

### Источник данных:
- Ручной ввод или загрузка из нормативной базы БД

### Заполнение:
- Не заполняется автоматически из данных предприятия
- Может быть заполнен из БД нормативных документов (см. `normative_documents`)

### Единицы измерения:
- Электроэнергия активная: **кВт·ч**

- Тепловая энергия: **Гкал**
- Газ: **тыс. м³** (конвертация из м³: `/1000`)
- Мазут, уголь, нефтепродукты: **тонна**
- Вода: **м³**

## 4. Баланс - Баланс энергоресурсов по категориям

**Назначение:** Сводный баланс потребления по категориям использования  
**Тип данных:** Таблица баланса  
**Размер:** Динамический (зависит от количества кварталов)

### Структура таблицы:

| Столбец | Название | Тип | Единица | Источник |
|---------|----------|-----|---------|----------|
| 1 | Квартал | текст | - | `quarter` (из агрегатора) |
| 2 | Технологические, кВт·ч | число | кВт·ч | `by_usage["technological"]` |
| 3 | Собственные нужды, кВт·ч | число | кВт·ч | `by_usage["own_needs"]` |
| 4 | Производственные, кВт·ч | число | кВт·ч | `by_usage["production"]` |
| 5 | Хоз-бытовые, кВт·ч | число | кВт·ч | `by_usage["household"]` |
| 6 | Итого, кВт·ч | **формула** | кВт·ч | `=SUM(B{row}:E{row})` |

### Источник данных:
- Функция `fill_balans_sheet()` в `fill_energy_passport.py`
- Данные из `agg_data["resources"]["electricity"][quarter]["by_usage"]`

### Формулы:
- **Итого (столбец 6):** `=SUM(B{row}:E{row})`
- **Проверка баланса:** Итого должно равняться "Общее потребление" из листа "Структура пр 2"

### Валидация:
- Сумма категорий (технологические + собственные + производственные + хоз-бытовые) = Итого
- Итого должно совпадать с `quarter_totals["active_kwh"]` из агрегатора

## 5. Динамика ср - Динамика потребления

**Назначение:** Динамика потребления ресурсов и удельных показателей  
**Тип данных:** Таблица временных рядов  
**Размер:** Динамический (по количеству кварталов)

### Структура таблицы:

| Столбец | Название | Тип | Единица | Источник | Формула |
|---------|----------|-----|---------|----------|---------|
| 1 | Год | число | - | `quarter.split("-")[0]` | - |
| 2 | Квартал | текст | - | `quarter.split("-Q")[1]` | - |
| 3 | Электроэнергия, кВт·ч | число | кВт·ч | `quarter_totals["active_kwh"]` | - |
| 4 | Газ, м³ | число | м³ | `quarter_totals["volume_m3"]` | - |
| 5 | Вода, м³ | число | м³ | `quarter_totals["volume_m3"]` | - |
| 6 | Производство, кг | число | кг | `sum(prod_totals.values())` | - |
| 7 | Удельный расход, кВт·ч/кг | **формула** | кВт·ч/кг | - | `=IF(G{row}>0,C{row}/G{row},0)` |

### Источник данных:
- Функция `fill_dinamika_sheet()` в `fill_energy_passport.py`
- Данные из агрегатора по всем ресурсам

### Формулы:
- **Удельный расход (столбец 7):** `=IF(G{row}>0,C{row}/G{row},0)`
  - Где G - столбец "Производство", C - столбец "Электроэнергия"
  - Защита от деления на ноль

### Расчетные поля:
- **Удельный расход электроэнергии:** `Электроэнергия (кВт·ч) / Производство (кг)`
- Единица: **кВт·ч/кг**
- Диапазон ожидаемых значений: 0.1 - 100 кВт·ч/кг (зависит от отрасли)

## Единицы измерения - нормализация

### Электроэнергия
- **Базовая единица:** кВт·ч
- **Конвертации:**
  - МВт·ч = кВт·ч / 1000
  - ГВт·ч = кВт·ч / 1000000

### Тепловая энергия
- **Базовая единица:** Гкал
- **Конвертации:**
  - ГДж = Гкал × 4.1868
  - МВт·ч = Гкал × 1.163

### Газ
- **Базовая единица:** м³
- **Конвертации:**
  - тыс. м³ = м³ / 1000
  - Тепловой эквивалент: 1 м³ ≈ 0.0089 Гкал (примерно)

### Топливо (мазут, уголь)
- **Базовая единица:** тонна
- **Конвертации:**
  - кг = тонна × 1000
  - Тепловой эквивалент: зависит от вида топлива

### Вода
- **Базовая единица:** м³
- **Конвертации:**
  - тыс. м³ = м³ / 1000
  - литр = м³ × 1000

## Проблемные поля (требуют доработки)

### 1. Строка "Общее потребление" в "Структура пр 2"
- **Проблема:** Не всегда правильно ссылается на итоги листа "Баланс"
- **Решение:** Восстановить формулы или заполнять явно из агрегатора

### 2. Удельный расход
- **Проблема:** Защита от деления на ноль может скрывать отсутствие данных
- **Решение:** Добавить проверку наличия данных производства перед расчетом

### 3. Квартальные маппинги
- **Проблема:** Hardcoded маппинг только для 2022 года
- **Решение:** Универсальный маппинг для любых годов (динамический)

### 4. Категории потребления
- **Проблема:** Если `by_usage` отсутствует, используется fallback с пропорциями
- **Решение:** Явно требовать наличие данных или сигнализировать об ошибке

### 5. Срок окупаемости мероприятий
- **Проблема:** Используются примерные тарифы
- **Решение:** Использовать реальные тарифы из данных предприятия или БД

## Примечания

1. **Магические числа:** В коде `fill_energy_passport.py` есть hardcoded номера строк и столбцов. Их следует вынести в конфигурацию.

2. **Валидация:** Перед генерацией паспорта необходимо проверять:
   - Наличие обязательных полей
   - Корректность балансов (суммы = итогам)
   - Наличие данных производства для расчета удельных показателей
   - Не отрицательные значения потребления

3. **Формулы Excel:** Некоторые формулы в шаблоне могут быть потеряны при заполнении. Необходимо сохранять формулы при заполнении.

4. **Единицы измерения:** Все конвертации должны выполняться в едином модуле конвертации единиц (см. `unit_converters.py`).

5. **Связи с нормативной базой:** Правила из БД нормативных документов могут использоваться для валидации и подсказок при заполнении.
