## 🔧 ИСПРАВЛЕНИЯ ЛОГИКИ

### Проблема:
Система неправильно определяла Navoiy IES как химическое предприятие из-за файлов про потребителей ("Навоийазотдан ташкари").

### Решение:
1. **Приоритет названию предприятия**: Если в названии/файлах есть "ТЭС" → энергетика
2. **Учет контекста файлов**:
   - Файлы про само предприятие ("энергопаспорт", "реализация") → вес 2.0
   - Файлы про потребителей ("ташкари", "внешний") → вес 0.5
3. **Фильтрация отраслей потребителей**: Уменьшенный вес для отраслей, упомянутых в файлах про потребителей
