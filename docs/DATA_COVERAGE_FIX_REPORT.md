## 🔍 Выявленные проблемы

### 1. Отсутствие выбора шаблона в UI
- **Проблема:** API поддерживал выбор шаблона через параметр `template_name`, но UI не предоставлял возможность выбрать шаблон
- **Решение:** ✅ Добавлен выпадающий список выбора шаблона в `results.html`

### 2. Неполное заполнение данных
- **Проблема:** Только данные по электроэнергии загружались, остальные ресурсы (gas, water, fuel, coal, heat) не обрабатывались
- **Решение:** ✅ Расширен список инициализации ресурсов в `main.py`

### 3. Неполная поддержка ресурсов в агрегации
- **Проблема:** В `aggregate_from_db_json()` инициализировались только 4 типа ресурсов
- **Решение:** ✅ Добавлена поддержка всех типов ресурсов (fuel, coal, heat)

## 🛠️ Использование

### Проверка доступности данных:
```bash
python hybrid_analysis/debug/check_data_availability.py \
  --data data/aggregated/aggregated_full_resources_2022_2024.json \
  --required-resources "electricity,gas,water,fuel,coal,heat" \
  --output coverage_report.json
```

### Выбор шаблона в UI:
1. Загрузить файлы через `/web/upload`
2. Открыть страницу результатов
3. Выбрать шаблон из выпадающего списка
4. Нажать "📊 Сгенерировать энергопаспорт"
