# Отчет: Поддержка типа данных для файлов "Реализация"

## Дата: 2025-11-30

## Проблема

Пользователь объяснил, что файлы "Реализация" содержат данные о **произведенной и реализованной (проданной потребителю) электроэнергии** для конкретного предприятия. Это важная информация, которая должна быть правильно обработана и сохранена в базе данных с соответствующим типом данных.

## Решение

Добавлена поддержка типа данных (`data_type`) для различения:
- **`consumption`** - потребление электроэнергии (по умолчанию)
- **`production`** - произведенная электроэнергия
- **`realization`** - реализованная (проданная) электроэнергия

## Внесенные изменения

### 1. Обновлена схема базы данных (`database.py`)

- Добавлено поле `data_type TEXT DEFAULT 'consumption'` в таблицу `node_consumption`
- Обновлен UNIQUE constraint: `UNIQUE(enterprise_id, node_name, period, data_type)` - теперь один узел может иметь разные записи для разных типов данных
- Добавлена миграция для существующих БД (ALTER TABLE с обработкой ошибок)
- Обновлена функция `import_node_consumption_to_db` для сохранения `data_type`

### 2. Обновлена логика извлечения данных (`balance_sheet_node_extractor.py`)

- Функция `extract_node_consumption_from_balance_sheet` теперь определяет тип данных на основе имени файла:
  - Файлы с "реализация" → `data_type = "realization"`
  - Файлы с "производство" → `data_type = "production"`
  - Остальные → `data_type = "consumption"` (по умолчанию)
- Обновлены функции извлечения:
  - `_extract_from_excel` - принимает и передает `data_type`
  - `_extract_from_pdf` - принимает и передает `data_type`
  - `_extract_from_word` - принимает и передает `data_type`
- Обновлены функции парсинга:
  - `_parse_node_sheet` - добавляет `data_type` в записи
  - `_parse_ocr_result_for_nodes` - добавляет `data_type` в записи
  - `_parse_node_table_from_word` - добавляет `data_type` в записи
- Обновлена функция валидации `validate_node_consumption_data` для сохранения `data_type`

### 3. Улучшено логирование (`main.py`)

- Добавлено логирование типа данных при извлечении
- Улучшены сообщения в логах для различения типов данных:
  - "потребления"
  - "производства"
  - "реализации (произведенной и проданной)"

## Примеры работы

### Файл "Реализация 2022.xlsx"

1. Система определяет файл как акт баланса по ключевому слову "реализация"
2. Определяет тип данных: `data_type = "realization"`
3. Логирует: `"📊 Определен тип данных: 'realization' (произведенная и реализованная электроэнергия) для файла Реализация 2022.xlsx"`
4. Извлекает данные по узлам с типом `realization`
5. Сохраняет в БД с `data_type = "realization"`
6. Логирует: `"✅ Импортировано N записей данных реализации (произведенной и проданной) по узлам учёта"`

## Преимущества

1. **Разделение данных**: Теперь можно различать потребление, производство и реализацию электроэнергии для одного и того же узла
2. **Корректная классификация**: Файлы "Реализация" правильно идентифицируются и обрабатываются
3. **Гибкость**: Система может обрабатывать различные типы данных по узлам учёта
4. **Прозрачность**: Улучшенное логирование позволяет отслеживать тип обрабатываемых данных
