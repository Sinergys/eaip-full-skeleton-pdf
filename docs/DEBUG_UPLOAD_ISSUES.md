# Диагностика проблем с загрузкой файлов

## Если файл не загружается через веб-интерфейс

### 1. Проверка сервера

```bash
# Проверьте, запущен ли сервер
curl http://localhost:8001/health

# Должен вернуть: {"service": "ingest", "status": "ok"}
```

### 2. Проверка в консоли браузера

1. Откройте веб-интерфейс загрузки
2. Нажмите F12 (открыть консоль разработчика)
3. Попробуйте загрузить файл
4. Смотрите ошибки в консоли (красные сообщения)

### 3. Типичные ошибки

#### "Failed to fetch" или "Ошибка соединения"
- **Причина**: Сервер не запущен или недоступен
- **Решение**: 
  ```bash
  # Запустите сервер
  cd eaip_full_skeleton/services/ingest
  python -m uvicorn main:app --host 0.0.0.0 --port 8001
  ```

#### "HTTP 400: Неподдерживаемый формат"
- **Причина**: Файл не в списке разрешенных форматов
- **Решение**: Используйте .xlsx, .xlsm, .docx, .pdf, .jpg, .png

#### "HTTP 400: Размер файла превышает"
- **Причина**: Файл больше 50 МБ
- **Решение**: Уменьшите размер файла или разделите на части

#### "HTTP 500: Internal Server Error"
- **Причина**: Ошибка на сервере при обработке
- **Решение**: Проверьте логи сервера

### 4. Диагностический скрипт

Запустите скрипт для проверки всех этапов:

```bash
python tools/test_upload_debug.py
```

Он проверит:
- ✅ Базу данных
- ✅ INBOX_DIR
- ✅ Парсинг файла
- ✅ Сохранение в БД

### 5. Ручная проверка через API

```bash
# Проверка здоровья сервера
curl http://localhost:8001/health

# Проверка списка предприятий
curl http://localhost:8001/api/enterprises

# Загрузка файла через curl (пример)
curl -X POST http://localhost:8001/web/upload \
  -F "file=@test.xlsx" \
  -F "enterprise_name=Navoiy IES" \
  -F "resource_type=electricity" \
  -F "system_mode=debug"
```

### 6. Проверка логов сервера

Смотрите логи сервера при загрузке файла. Должны быть сообщения:
- `[UPLOAD] Начало загрузки файла: ...`
- `[VALIDATE] ВАЛИДАЦИЯ ПРОЙДЕНА: ...`
- `✅ Файл загружен успешно`

### 7. Проверка прав доступа

```bash
# Проверьте права на INBOX_DIR
ls -la /data/inbox  # Linux/Mac
# или
dir C:\data\inbox   # Windows

# Должны быть права на запись
```

### 8. Если ничего не помогает

1. Откройте консоль браузера (F12)
2. Скопируйте все ошибки (красные сообщения)
3. Проверьте Network tab - какой запрос падает?
4. Проверьте Response в Network tab - что возвращает сервер?

## Контакты для помощи

Если проблема не решена, предоставьте:
1. Скриншот консоли браузера (F12)
2. Логи сервера
3. Результат `python tools/test_upload_debug.py`
4. Описание: какой файл, какой размер, что происходит
