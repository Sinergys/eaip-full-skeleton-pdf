## 3. Лист `Оборудование`

### 3.1 `unified_energy_audit_template.xlsx`

| Excel | Заголовок | JSON-ключ | Примечание |
| --- | --- | --- | --- |
| `A3` | `№` | `equipment.items[*].order` | Порядковый номер в отчёте. |
| `B3` | `Наименование оборудования` | `...name` | Полное название единицы оборудования. |
| `C3` | `Тип` | `...type` | Класс/тип (конвейер, насос и т.п.). |
| `D3` | `Мощность (кВт)` | `...power_kw` | Использовать float, форматировать с 1-2 знаками. |
| `E3` | `Год выпуска` | `...year` | Целое значение, допускается `""`, если нет данных. |
| `F3` | `Состояние` | `...condition` | Состояние/примечание по исправности. |
| `G3` | `Место установки` | `...location` | Цех/участок. |
| `H3` | `Примечания` | `...notes` | Свободный текст. |

Строки данных начинаются с 4-й строки (т.е. первая запись в `A4:H4`), в шаблоне зарезервировано ~40 строк.

### 3.2 `template_Отчёт бешафар.xlsx`

| Excel | Заголовок | JSON-ключ | Примечание |
| --- | --- | --- | --- |
| `A2` | `№` | `equipment.items[*].order` | Оставляем существующую нумерацию. |
| `B2` | `код` | `...code` | Инвентарный/каталожный номер. |
| `C2` | `оборудование` | `...name` | Название. |
| `D2` | `модель` | `...model` | Марка/тип. |
| `E2` | `кол-во` | `...quantity` | Количество (строка → число). |
| `F2` | `энергопотребитель` | `...energy_consumer` | Привязанный электродвигатель/редуктор. |

Дополнительные колонки `G:J` свободны — можно использовать для расширенного описания из `...notes`.

### 3.3 `template_250314 Отчёт энергоаудит джурабек.xlsx`

Лист содержит сводную таблицу стоимости СЭС:

| Excel | Содержание | JSON-ключ |
| --- | --- | --- |
| `A3` | `Оборудование` | `equipment.summary.equipment_cost` |
| `A4` | `Доставка` | `...delivery_cost` |
| `A5` | `Растаможа 5%` | `...customs_cost` (процент хранить отдельно) |
| `A6` | `НДС 15%` | `...vat_cost` |
| `A7` | `Установка 50%` | `...installation_cost` |
| `A8` | `Итого:` | `...total_cost` |

Колонка `B` — значение с валютой. Рекомендуем хранить `currency` и `amount` отдельно, при записи форматировать (например, `f\"{amount:,.2f} {currency}\"` с заменой запятой/точки под локаль).

### 7.1 Таблица в энергопаспорте (`Equipment`)

`fill_equipment_sheet()` размещает данные в листе `Equipment`:

| Столбец | Источник | Примечание |
| --- | --- | --- |
| `Площадка` | sheet name (`Лист1`, …) | Из JSON `sheets[].sheet`. |
| `Раздел` | `section.title`/`section.name` | Например «1. Цех …». |
| `№` | `item.order` | Порядковый номер. |
| `Оборудование` | `item.name` | Наименование единицы. |
| `Кол-во, шт` | `item.quantity` | Суммируется в итогах. |
| `Мощность ед., кВт` | `item.unit_power_kw` | Берётся из числового значения; исходная строка → `Примечание`. |
| `Мощность суммарная, кВт` | `item.total_power_kw` | Используется для итогов. |
| `Частотный привод` | `item.vfd` → «Да/Нет» | Числится в summary как `vfd_with_frequency_drive`. |
| `Категория энергоэффективности` | `item.energy_efficiency_category` | Категория A-G (опционально, извлекается из колонки 7 в Excel). |
| `Примечание` | `item.unit_power_raw` | Сохраняем текст ТЭНов и пр. |

После каждой секции добавляется строка «Итого по разделу», далее — блок «Сводные показатели» на основе `summary`.
