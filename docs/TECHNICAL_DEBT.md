# Технический долг и план развития

Этот документ содержит список известных технических проблем и задач, которые были временно отложены для фокусировки на более приоритетных исправлениях.

## 1. Некорректное распределение годового потребления электроэнергии по кварталам

- **Файл:** `eaip_full_skeleton/services/ingest/energy_aggregator.py`
- **Проблема:** Текущая логика в `energy_aggregator.py` некорректно обрабатывает случаи, когда в агрегированных данных присутствуют только годовые итоги по категориям потребления, а квартальные данные по электричеству отсутствуют. Функция пытается равномерно распределить годовые суммы, но делает это неполно или с ошибками.
- **Симптом:** Это приводит к тому, что функция `fill_balans_sheet` получает пустые данные по электроэнергии (`resources.electricity`). Как следствие, на листе "Баланс" не генерируются необходимые формулы, что вызывает падение E2E тестов.
- **Задача:** Необходимо пересмотреть и исправить логику в `energy_aggregator.py` для корректного и полного распределения годовых данных по четырем кварталам, создавая или дополняя соответствующие структуры данных.
- **Статус:** **Отложено.** Решено сначала исправить блокирующую ошибку с созданием и заполнением листа "Баланс" в `main.py` и `fill_energy_passport.py`.
