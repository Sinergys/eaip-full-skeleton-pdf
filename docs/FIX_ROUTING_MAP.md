# 🔧 Как обновить routing_map для существующих файлов

## Проблема

Файл "т-3а.jpg" показывает старые результаты routing_map:
- `document_type`: "unknown"
- `resource_type`: "unknown"
- `confidence`: 0.48

Это происходит потому, что файл был загружен **до** улучшений Intelligent Router.

## Решения

### Вариант 1: Перезагрузить файл (рекомендуется)

1. Загрузите файл "т-3а.jpg" заново через веб-интерфейс
2. Intelligent Router автоматически проанализирует его с улучшенными алгоритмами
3. Новый routing_map будет сохранен в БД

### Вариант 2: Переобработать через скрипт

Если файл есть в БД, используйте скрипт:

```powershell
cd C:\eaip
python tools/reprocess_single_file.py <batch_id>
```

Где `<batch_id>` - это batch_id вашего файла.

### Вариант 3: Массовая переобработка

Для всех файлов проекта "Navoiy IES":

```powershell
cd C:\eaip
python tools/reprocess_with_intelligent_router.py --enterprise "Navoiy IES"
```

## Проверка результатов

После переобработки проверьте:

```powershell
python tools/check_navoi_project.py
```

Или проверьте конкретный файл:

```powershell
python tools/test_intelligent_router.py <batch_id>
```

## Ожидаемые результаты

После переобработки файл "т-3а.jpg" должен показать:

```json
{
  "document_type": "meter_readings",
  "resource_type": "electricity",  // если в OCR-тексте есть "квтч"
  "data_type": "meter_readings",
  "confidence": 0.7+  // выше благодаря улучшениям
}
```

## Если файл не найден в БД

Если скрипт говорит "файл не найден в БД", это означает:
- Файл был удален из БД
- Или используется другая БД

В этом случае **перезагрузите файл** через веб-интерфейс - это самый простой способ.

## Важно

- Новые загрузки автоматически используют улучшенный Router
- Старые файлы нужно переобработать или перезагрузить
- Router работает автоматически при каждой новой загрузке
