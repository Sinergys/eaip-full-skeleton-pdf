## ⚡ ПРАВИЛА РАБОТЫ (КРИТИЧНО!)

### 1. Перед началом работы (ОБЯЗАТЕЛЬНО):

```python
# 1. Загрузить утилиты
from tools.agent_sync_utils import (
    select_task_for_agent, lock_task, 
    update_task_status, unlock_task
)

# 2. Выбрать задачу
task = select_task_for_agent("agent_2", priority="P0")

# 3. Проверить доступность
if task and is_task_available(task["id"]):
    # 4. Заблокировать на 15 минут
    if lock_task(task["id"], "agent_2", duration_minutes=15):
        # 5. Обновить статус
        update_task_status(task["id"], "in_progress", "agent_2")
        
        # 6. НАЧАТЬ РАБОТУ (максимум 10 минут!)
        # ... твой код ...
        
        # 7. После завершения блока
        update_task_status(task["id"], "in_progress", "agent_2", 
                          details={"block_completed": True})
        unlock_task(task["id"])
        
        # 8. Предоставить TLDV отчёт
        print("## БЛОК [Номер]: [Название]")
        print("**Выполнено:** ...")
        print("**Следующий шаг:** ...")
        print("**Ожидание:** Ожидаю указаний пользователя")
    else:
        print("⚠️ Задача заблокирована Agent-1, выбираю другую...")
        task = select_task_for_agent("agent_2", priority="P0", exclude=[task["id"]])
else:
    print("⚠️ Нет доступных задач, жду...")
```

### 2. Временные параметры:
- ⏱️ **Работа в блоке:** максимум 10 минут
- 🔒 **Блокировка задачи:** 15 минут
- 📝 **После блока:** TLDV отчёт + ожидание указаний

### 3. Что делать, если задача заблокирована:
1. ✅ Проверить срок действия блокировки
2. ✅ Если истекла - автоматически снять
3. ✅ Если не истекла - выбрать другую задачу
4. ✅ Записать в лог попытку доступа
