# Анализ использования ИИ для классификации файлов "Реализация"

## Дата: 2025-11-30

## Проблема

Пользователь справедливо указал, что согласно ТЗ система должна использовать ИИ для определения, распознавания и понимания загруженных файлов.

## Текущее состояние

### ✅ Что реализовано:

1. **Модуль AI классификации** (`ai_content_classifier.py`):
   - ✅ Поддержка DeepSeek, OpenAI, Anthropic
   - ✅ Анализ содержимого файлов (Excel, PDF)
   - ✅ Определение типа ресурса с уверенностью
   - ✅ Интеграция в `ResourceClassifier`

2. **Интеграция в процесс загрузки**:
   - ✅ `ResourceClassifier.classify()` использует ИИ, если правила не определили тип
   - ✅ Приоритет: правила → ИИ → имя файла → "other"

### ⚠️ Проблема с файлами "Реализация":

**Текущая ситуация:**
- Файлы "Реализация" определяются правилами как `electricity` (из-за ключевых слов "реализация", "реал", "баланс" в `required_data_matrix.py`)
- ИИ **не вызывается**, так как правила уже определили тип
- Система не различает "Реализация" (реализованная энергия) от обычного файла с электроэнергией

**Согласно ТЗ:**
- ИИ должен использоваться для **определения и распознавания** загруженных файлов
- ИИ должен **понимать** содержимое файла, а не только ключевые слова

## Рекомендации

### 1. Использовать ИИ для уточнения типа файла "Реализация"

**Проблема:** Файлы "Реализация" классифицируются как `electricity`, но это не совсем точно:
- "Реализация" = произведенная и реализованная (проданная) электроэнергия
- Это специфический тип данных, который нужно отличать от обычного потребления

**Решение:**
- Использовать ИИ для анализа содержимого файла "Реализация"
- ИИ должен определить:
  - Это акт баланса? (да/нет)
  - Это данные по реализации? (да/нет)
  - Какие листы содержат данные? ("Реал 04", "Баланс 04" и т.д.)
  - Какой тип данных: `consumption`, `production`, `realization`?

### 2. Улучшить промпт для ИИ классификатора

**Текущий промпт** (`ai_content_classifier.py`):
- Определяет только тип ресурса (electricity, gas, water и т.д.)
- Не определяет подтип данных (consumption, production, realization)

**Нужно добавить:**
- Определение типа данных: `consumption`, `production`, `realization`
- Определение типа документа: акт баланса, отчет, справка и т.д.
- Анализ структуры листов для Excel файлов

### 3. Использовать ИИ для определения структуры листов "Баланс"

**Проблема:** Листы "Баланс 04" и "Баланс 00" имеют разную структуру, и алгоритм поиска колонок не всегда работает.

**Решение:**
- Использовать ИИ для анализа структуры листа "Баланс"
- ИИ должен определить:
  - Где находится заголовок таблицы?
  - Какие колонки содержат названия узлов?
  - Какие колонки содержат активную/реактивную энергию?
  - Какие колонки содержат стоимость?
