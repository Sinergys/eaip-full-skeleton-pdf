**Дата:** 2025-12-01

---

## 🎯 Главная идея

**Импорт = один раз загрузить документ, использовать много раз**

---

## 📥 ШАГ 1: Импорт документа (один раз)

### Что происходит сейчас:

1. **Пользователь загружает файл** (PDF, Word, Excel)
   ```
   ПКМ_690.pdf → Загрузка
   ```

2. **Система вычисляет "отпечаток" файла** (хеш)
   ```
   Файл → SHA1 хеш → "a1b2c3d4..."
   ```

3. **Парсинг файла** (извлечение текста)
   ```
   PDF → Текст: "Формула расчета: Q = A * B..."
   ```

4. **AI извлекает правила**
   ```
   Текст → AI → Правила:
   - Формула: Q = A * B
   - Норматив: 0.15 кВт·ч/м²
   ```

5. **Сохранение в базу данных**
   ```
   БД:
   ├─ Документ (название, тип, путь)
   ├─ Правила (формулы, нормативы)
   └─ Связи (какое правило к какому полю относится)
   ```

### ⚠️ Проблема сейчас:

- **Нет проверки на дубликаты** — можно загрузить один файл несколько раз
- **Не сохраняется полный текст** — после импорта нельзя получить оригинальный текст
- **Тратится время** — каждый раз парсится и анализируется заново


2. **Система ищет в базе данных**
   ```
   БД → Найти правила для поля "Удельный расход электроэнергии"
   → Найдено: 0.15 кВт·ч/м² (из ПКМ №690)
   ```

3. **Применение в расчетах**
   ```
   Фактическое значение: 0.18 кВт·ч/м²
   Норматив: 0.15 кВт·ч/м²
   → Превышение на 20% ⚠️
   ```

### 1. Импорт (один раз):

```

    │       (не загружаем повторно)
    │

             ├─ Парсинг
             ├─ AI-анализ
             ├─ Сохранение в БД:
             │  ├─ Метаданные
             │  ├─ Полный текст (NEW!)
             │  ├─ Правила
             │  └─ Связи
             └─ Готово!
```

### 2. Использование (много раз):

```
Нужен норматив? → БД → Найти правила → Применить
                    ↑

```

### 3. Повторное использование текста:

```
Нужен текст документа? → БД → Получить сохраненный текст
                          ↑

```
