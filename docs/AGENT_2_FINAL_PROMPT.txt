⚡ КАК НАЧАТЬ РАБОТУ (ШАГ ЗА ШАГОМ):
═══════════════════════════════════════════════════════════════

```python
# ШАГ 1: Импорт утилит
from tools.unified_tasks_manager import (
    load_tasks, get_available_tasks_unified,
    lock_task_unified, unlock_task_unified,
    update_task, add_solution, add_execution
)
from tools.agent_sync_utils import (
    lock_task, unlock_task, update_task_status
)

# ШАГ 2: Загрузить единый файл задач
tasks_data = load_tasks()
print(f"Всего задач: {tasks_data['metadata']['total_tasks']}")

# ШАГ 3: Выбрать доступную задачу P0
available = get_available_tasks_unified(priority="P0")
if available:
    task = available[0]
    task_id = task["id"]
    task_name = task["name"]
    
    print(f"Выбрана задача: {task_id} - {task_name}")
    
    # ШАГ 4: Заблокировать в едином файле (15 минут)
    if lock_task_unified(task_id, "agent_2", duration_minutes=15):
        # ШАГ 5: Также заблокировать в системе синхронизации
        lock_task(task_id, "agent_2", duration_minutes=15)
        update_task_status(task_id, "in_progress", "agent_2")
        
        # ШАГ 6: Обновить статус в едином файле
        update_task(task_id, {"status": "in_progress"}, "agent_2")
        
        print(f"✅ Задача {task_id} заблокирована, начинаю работу...")
        
        # ШАГ 7: РАБОТАТЬ (максимум 10 минут!)
        # ... твой код выполнения задачи ...
        
        # ШАГ 8: После блока - добавить выполнение в единый файл
        add_execution(task_id, {
            "block_number": 1,
            "status": "in_progress",
            "completed": [
                "Что сделано в блоке 1",
                "Какие файлы изменены",
                "Какие функции реализованы"
            ],
            "next_step": "Следующий шаг в блоке 2",
            "files_changed": ["path/to/file1.py", "path/to/file2.py"],
            "time_spent_minutes": 10
        }, "agent_2")
        
        # ШАГ 9: Снять блокировки
        unlock_task_unified(task_id, "agent_2")
        unlock_task(task_id)
        
        print(f"✅ Блок 1 завершён, блокировки сняты")
        
        # ШАГ 10: TLDV отчёт
        print("""
        ## БЛОК 1: [Название задачи]
        
        **Выполнено:**
        - [Что сделано в блоке]
        - [Какие файлы изменены]
        - [Какие функции реализованы]
        
        **Следующий шаг:**
        - [Что нужно сделать в следующем блоке]
        
        **Ожидание:** Ожидаю указаний пользователя для продолжения.
        """)
    else:
        print(f"⚠️ Задача {task_id} недоступна (заблокирована Agent-1)")
        # Выбрать другую задачу
        available = get_available_tasks_unified(priority="P0", exclude=[task_id])
else:
    print("⚠️ Нет доступных задач P0, проверяю P1...")
    available = get_available_tasks_unified(priority="P1")
```

📝 ВАЖНЫЕ ПРАВИЛА (КРИТИЧНО!):
═══════════════════════════════════════════════════════════════

1. ⭐ ВСЕГДА работай с ЕДИНЫМ файлом задач:
   - Читай задачи из `AGENT_TASKS_UNIFIED.json`
   - Фиксируй решения через `add_solution()`
   - Фиксируй выполнение через `add_execution()`
   - Обновляй статус через `update_task()`

2. 🔒 БЛОКИРОВКИ (двойная блокировка):
   - Блокируй в едином файле: `lock_task_unified()`
   - Блокируй в системе синхронизации: `lock_task()`
   - ВСЕГДА снимай обе блокировки после работы

3. ⏱️ ВРЕМЯ РАБОТЫ:
   - Максимум 10 минут в блоке
   - Блокировка на 15 минут
   - После блока - TLDV отчёт + ожидание указаний

4. 📊 ПРИОРИТЕТЫ:
   - P0 (критично) - выполняй первыми
   - P1 (важно) - выполняй вторыми
   - P2 (рекомендуется) - выполняй последними

5. 📝 ФИКСАЦИЯ РЕШЕНИЙ:
   - Когда принимаешь решение - используй `add_solution()`
   - Указывай: подход, детали, файлы, риски

6. ✅ ФИКСАЦИЯ ВЫПОЛНЕНИЯ:
   - После каждого блока - используй `add_execution()`
   - Указывай: что сделано, какие файлы изменены, время
