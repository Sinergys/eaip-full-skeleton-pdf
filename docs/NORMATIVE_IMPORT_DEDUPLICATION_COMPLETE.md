## 🎯 Что реализовано

### 1. ✅ Дедупликация нормативных документов

**Проблема:** Документ можно было импортировать несколько раз, создавая дубликаты.

**Решение:**
- Проверка по `file_hash` перед импортом
- Если документ уже существует → возвращается существующий ID
- Сообщение пользователю: "Документ уже был импортирован ранее"

**Код:**
```python
# normative_importer.py
existing_doc = database.find_normative_document_by_hash(file_hash)
if existing_doc:
    return {
        "status": "duplicate",
        "document_id": existing_doc["id"],
        "message": f"Документ уже был импортирован ранее (ID={existing_doc['id']})"
    }
```

### 2. ✅ Сохранение полного текста в БД

**Проблема:** После импорта нельзя было получить оригинальный текст документа.

**Решение:**
- Добавлены колонки в таблицу `normative_documents`:
  - `full_text TEXT` — полный текст документа
  - `parsed_data_json TEXT` — результат парсинга (JSON)
- Текст сохраняется при импорте
- Доступен через API

**Схема БД:**
```sql
ALTER TABLE normative_documents 
ADD COLUMN full_text TEXT;           -- Полный текст
ADD COLUMN parsed_data_json TEXT;    -- Результат парсинга
```

### 3. ✅ API для получения текста

**Новые endpoints:**
- `GET /api/normative/documents/{document_id}` — получить документ (метаданные)
- `GET /api/normative/documents/{document_id}/text` — получить полный текст

**Пример использования:**
```bash
# Получить метаданные
curl http://localhost:8001/api/normative/documents/1

# Получить полный текст
curl http://localhost:8001/api/normative/documents/1/text
```
