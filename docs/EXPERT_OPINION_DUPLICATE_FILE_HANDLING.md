# 🎓 ЭКСПЕРТНОЕ ЗАКЛЮЧЕНИЕ: Обработка повторных загрузок файлов

## 📋 ВОПРОС

Как должна работать система при повторной загрузке файлов? Какие сценарии нужно учитывать?

## 🔍 АНАЛИЗ СЦЕНАРИЕВ

### Сценарий 1: Повторная загрузка одного файла
**Ситуация:** Пользователь загружает тот же файл повторно
**Цель:** Обновить анализ с новым Intelligent Router

### Сценарий 2: Массовая загрузка пакета файлов
**Ситуация:** Пользователь загружает пакет файлов (новые + старые)
**Цель:** Обработать все файлы, включая те, что уже были загружены

### Сценарий 3: Исправление ошибок
**Ситуация:** Файл был обработан с ошибками, нужно переобработать
**Цель:** Принудительная переобработка

### Сценарий 4: Обновление данных
**Ситуация:** Файл обновлен (новые данные), но имя/размер совпадают
**Цель:** Переобработать с новыми данными

### Сценарий 5: Дубликат с актуальными данными
**Ситуация:** Файл уже обработан и данные актуальны
**Цель:** Не тратить ресурсы на повторную обработку

### 💻 Эксперт по Backend/Архитектуре

**Рекомендации:**

1. **Параметр запроса `force_reprocess`:**
   ```python
   @app.post("/upload")
   async def upload_file(
       file: UploadFile,
       force_reprocess: bool = False,  # Новый параметр
       ...
   ):
   ```

2. **Параметр запроса `reprocess_mode`:**
   ```python
   reprocess_mode: str = "auto"  # auto | always | never
   ```
   - `auto` - автоматически решать (по routing_map)
   - `always` - всегда переобрабатывать
   - `never` - никогда не переобрабатывать

3. **Batch режим:**
   ```python
   @app.post("/upload/batch")
   async def upload_batch(
       files: List[UploadFile],
       reprocess_existing: bool = True,  # Переобработать существующие
       ...
   ):
   ```

4. **Версионирование Router:**
   - Сохранять версию Router в routing_map
   - При обновлении Router автоматически переобрабатывать старые файлы

**Оценка:** ⭐⭐⭐⭐⭐ (5/5)

### 🧠 Эксперт по ML/AI

**Рекомендации:**

1. **Умная проверка актуальности:**
   - Сравнивать версию Router
   - Проверять confidence (если < 0.7 - переобработать)
   - Проверять дату последнего обновления (если > 30 дней - переобработать)

2. **Анализ изменений:**
   - Сравнивать hash файла
   - Если hash изменился - файл обновлен, переобработать
   - Если hash тот же - проверять актуальность анализа

3. **Приоритеты обработки:**
   - Новые файлы - высокий приоритет
   - Переобработка - средний приоритет
   - Дубликаты с актуальными данными - низкий приоритет

**Оценка:** ⭐⭐⭐⭐☆ (4/5)
