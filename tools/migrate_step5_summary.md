# 📊 Статус Шага 5: Миграция данных

## Проблема

Ошибка кодировки при подключении psycopg2 к PostgreSQL:
```
UnicodeDecodeError: 'utf-8' codec can't decode byte 0xc2 in position 61
```

## Анализ

Это известная проблема psycopg2 на Windows - баг при чтении переменных окружения.

## Решения

### ✅ Вариант 1: Миграция через Docker exec (рекомендуется)

Обходим проблему полностью:
1. Экспортируем данные через Python (SQLite работает нормально)
2. Импортируем через Docker exec (PostgreSQL работает нормально)

**Преимущества:**
- ✅ Работает на любом Windows
- ✅ Не требует исправления системы
- ✅ Надежно

### Вариант 2: Исправить системную локаль

Требует изменения настроек Windows (может потребоваться перезагрузка).

### Вариант 3: Использовать чистую среду

Создать новый venv с чистыми настройками.

## Рекомендация

**Использовать вариант 1** - это то, что используют продвинутые программисты для обхода проблем Windows.
