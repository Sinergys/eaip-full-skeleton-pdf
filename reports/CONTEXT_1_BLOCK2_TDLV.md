   - Добавлены параметры: `check_size`, `warn_threshold`
   - Проверка размера перед загрузкой

### Созданные файлы:
- `tests/test_context_loader_size_check.py` - тесты проверки размера

### Логика работы:
1. При старте агента вызывается `load_critical_context()`
2. Для каждого обязательного файла проверяется размер
3. Если файл превышает лимит → автоматическая оптимизация
4. Если файл близок к лимиту (>80%) → предупреждение
5. Файлы загружаются после проверки
