## 🔧 ТЕХНИЧЕСКИЕ ДЕТАЛИ

### Созданные файлы:
1. **`tools/file_size_monitor.py`** - основная утилита мониторинга (350+ строк)
2. **`docs/file_size_history.json`** - история размеров файлов
3. **`reports/file_size_monitoring/`** - директория для отчётов

### Функции мониторинга:

1. **`record_file_sizes()`**
   - Записывает текущие размеры всех контекстных файлов
   - Сохраняет в историю с временной меткой
   - Ограничивает историю последними 100 записями

2. **`analyze_growth(period_days)`**
   - Анализирует рост файлов за указанный период
   - Рассчитывает изменение размера и процента
   - Определяет тренд (рост/падение/стабильность)

3. **`check_alerts()`**
   - Проверяет условия для алертов
   - Критические: превышение лимита
   - Предупреждения: приближение к лимиту, быстрый рост
   - Сохраняет алерты в истории

4. **`get_disk_usage_metrics()`**
   - Получает метрики использования диска
   - Размеры по категориям файлов
   - Процент использования диска

5. **`generate_report()`**
   - Генерирует полный отчёт о размерах файлов
   - Включает все метрики и анализ
   - Сохраняет в JSON формате
