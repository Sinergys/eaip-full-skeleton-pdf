## ВАРИАНТЫ ЛОГИКИ

### Вариант 1: МАКСИМУМ (текущая реализация)

**Логика:** Используется максимальное значение между headers и rows

```python
expected_cols = max(headers_cols, max_cols_in_rows)
```

**Преимущества:**
- ✅ Сохраняет максимум данных
- ✅ Гибко обрабатывает разные случаи
- ✅ Не теряет информацию из rows

**Недостатки:**
- ⚠️ Может дополнять headers пустыми значениями
- ⚠️ Может не соответствовать ожиданиям (headers игнорируются)

### Вариант 2: HEADERS ПРИОРИТЕТНЫ

**Логика:** Если есть headers, используем их количество как приоритетное

```python
if headers_cols > 0:
    expected_cols = headers_cols  # Headers приоритетны
else:
    expected_cols = max_cols_in_rows
```

**Преимущества:**
- ✅ Соответствует ожиданиям (headers используются)
- ✅ Логически понятно (headers определяют структуру)

**Недостатки:**
- ❌ **ПОТЕРЯ ДАННЫХ:** обрезает rows до headers
- ❌ Менее гибкий (не учитывает максимум в rows)
