## 💡 РЕШЕНИЯ

### Решение 1: Улучшение предобработки для светлых изображений

**Проблема:** Светлые, неконтрастные изображения

**Решение:**
1. **Адаптивная гистограмма:**
   - Растяжение гистограммы для повышения контраста
   - Нормализация яркости

2. **Локальная адаптивная бинаризация:**
   - Использование `cv2.adaptiveThreshold` вместо глобальной бинаризации
   - Учет локальных особенностей изображения

3. **Усиление контраста:**
   - CLAHE (Contrast Limited Adaptive Histogram Equalization)
   - Гамма-коррекция для светлых изображений

4. **Удаление фона:**
   - Детекция и удаление светлого фона
   - Изоляция текста

**Реализация:**
```python
def enhance_light_image(image):
    """Улучшение светлых, неконтрастных изображений"""
    # 1. Конвертация в grayscale
    gray = cv2.cvtColor(image, cv2.COLOR_RGB2GRAY)
    
    # 2. CLAHE для локального усиления контраста
    clahe = cv2.createCLAHE(clipLimit=2.0, tileGridSize=(8,8))
    enhanced = clahe.apply(gray)
    
    # 3. Адаптивная бинаризация
    binary = cv2.adaptiveThreshold(
        enhanced, 255, cv2.ADAPTIVE_THRESH_GAUSSIAN_C,
        cv2.THRESH_BINARY, 11, 2
    )
    
    # 4. Гамма-коррекция для светлых изображений
    gamma = 1.5  # Увеличиваем контраст
    inv_gamma = 1.0 / gamma
    table = np.array([((i / 255.0) ** inv_gamma) * 255
                      for i in np.arange(0, 256)]).astype("uint8")
    corrected = cv2.LUT(binary, table)
    
    return corrected
```

**Приоритет:** Высокий (P1)

### Решение 2: Улучшение парсера JSON для больших таблиц

**Проблема:** Ошибка парсинга JSON для таблиц с 10 столбцами и 33 строками

**Решение:**
1. **Улучшенная обработка вложенных структур:**
   - Рекурсивная обработка массивов в JSON
   - Обработка вложенных объектов в строках таблиц

2. **Более агрессивная очистка:**
   - Удаление проблемных символов перед парсингом
   - Исправление незакрытых скобок/кавычек

3. **Специальная обработка для таблиц:**
   - Извлечение таблиц отдельно от основного JSON
   - Парсинг таблиц по частям (по строкам)

**Реализация:**
```python
def parse_large_table_json(json_str: str) -> dict:
    """Специальный парсер для больших таблиц"""
    # 1. Извлекаем секцию таблиц отдельно
    tables_match = re.search(r'"tables"\s*:\s*\[(.*?)\]', json_str, re.DOTALL)
    if tables_match:
        tables_str = tables_match.group(1)
        # Парсим таблицы построчно
        tables = parse_table_rows(tables_str)
        # Заменяем в исходном JSON
        json_str = json_str.replace(tables_match.group(0), f'"tables": {json.dumps(tables)}')
    
    # 2. Стандартный парсинг
    return json.loads(json_str)
```

**Приоритет:** Высокий (P1)
