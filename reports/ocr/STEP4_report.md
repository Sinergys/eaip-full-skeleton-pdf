## ПРОБЛЕМЫ И РЕШЕНИЯ

### Проблема 1: Большой размер файлов
- **Описание:** Изначально выбран файл "ЗЭП НТЭС Готово_compressed.pdf" (31 MB), обработка занимала часы
- **Решение:** Выбраны мелкие файлы (< 0.5 MB) для быстрой обработки
- **Статус:** ✅ Решено

### Проблема 2: Непонятное сообщение о конвертации
- **Описание:** Сообщение "Конвертация PDF в изображения" было неясным для сканированных PDF
- **Решение:** Изменено на "Извлечение страниц из PDF" с пояснением необходимости для Gemini Vision API
- **Статус:** ✅ Решено

### Проблема 3: Медленное извлечение страниц
- **Описание:** Использовался DPI=300, что замедляло обработку
- **Решение:** Снижен DPI до 200 (достаточно для OCR, быстрее обработка)
- **Статус:** ✅ Решено

### Проблема 4: Ошибки парсинга JSON от Gemini
- **Описание:** 2 файла (файл 3 и файл 5, страница 2) имели проблемы с парсингом JSON:
  - "Unterminated string starting at position 16721"
  - "Invalid control character"
  - "Expecting ',' delimiter"
- **Решение:** Реализован частичный парсинг - текст извлекается, но таблицы могут быть потеряны
- **Статус:** ⚠️ Частично решено (требуется улучшение `fix_json_strings()` из ШАГ 1)
- **Влияние:** Файл 3: потеряны таблицы (0 таблиц вместо ожидаемых), confidence=0.50
