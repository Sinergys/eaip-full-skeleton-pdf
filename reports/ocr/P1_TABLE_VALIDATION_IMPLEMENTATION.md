## ВЫПОЛНЕННЫЕ ИЗМЕНЕНИЯ

### 1. Создан модуль валидации таблиц

**Файл:** `eaip_full_skeleton/services/ingest/utils/table_validator.py`

**Функции:**

#### `validate_table_structure(table: dict) -> dict`
Валидирует структуру одной таблицы и исправляет ошибки:

**Проверки:**
1. ✅ Все строки должны иметь одинаковое количество столбцов
2. ✅ Headers должны соответствовать количеству столбцов
3. ✅ Удаление пустых строк
4. ✅ Нормализация пустых значений (None → '', пробелы → '')
5. ✅ Проверка типов данных (rows и headers должны быть списками)
6. ✅ Минимальные требования (таблица не должна быть пустой)

**Возвращает:**
```python
{
    'rows': [...],           # Валидированные строки
    'headers': [...],        # Валидированные заголовки
    'row_count': int,        # Количество строк
    'col_count': int,        # Количество столбцов
    'validated': bool,       # Прошла ли валидацию
    'errors': [...],         # Список ошибок
    'warnings': [...],       # Список предупреждений
    'location': str,         # Местоположение таблицы
    'confidence': float      # Уровень уверенности
}
```

#### `validate_tables_list(tables: list) -> list`
Валидирует список таблиц, возвращает только валидированные.

#### `get_table_statistics(table: dict) -> dict`
Вычисляет статистику по таблице:
- Количество строк и столбцов
- Количество непустых ячеек
- Количество числовых ячеек
- Процент заполненности
- Процент числовых значений

### 2. Интеграция в Gemini Vision OCR

**Файл:** `eaip_full_skeleton/services/ingest/utils/gemini_vision_ocr.py` (строки 521-536)

**Изменения:**

- ✅ Добавление флага `tables_validated` в результат
- ✅ Логирование статистики валидации
- ✅ Сохранение исходных таблиц при ошибке валидации

**Код:**
```python
# Валидируем структуру таблиц
if result.get('tables'):
    try:
        from utils.table_validator import validate_tables_list
        validated_tables = validate_tables_list(result['tables'])
        result['tables'] = validated_tables
        result['tables_validated'] = True
        result['tables_count'] = len(validated_tables)
        
        # Логируем статистику валидации
        invalid_count = len(result.get('tables', [])) - len(validated_tables)
        if invalid_count > 0:
            logger.warning(f"Валидация таблиц: {invalid_count} таблиц не прошли валидацию")
        if validated_tables:
            logger.info(f"Валидация таблиц: {len(validated_tables)} таблиц успешно валидированы")
    except Exception as e:
        logger.warning(f"Ошибка валидации таблиц: {e}, используем исходные таблицы")
        result['tables_validated'] = False
```

## ПРИМЕРЫ РАБОТЫ

### Пример 1: Исправление разного количества столбцов

**Входные данные:**
```python
{
    'rows': [
        ['№', 'Наименование', 'Количество'],
        ['1', 'Товар 1'],  # Не хватает столбца
        ['2', 'Товар 2', '5', 'Лишний']  # Лишний столбец
    ],
    'headers': ['№', 'Наименование', 'Количество']
}
```

**Результат:**
```python
{
    'rows': [
        ['№', 'Наименование', 'Количество'],
        ['1', 'Товар 1', ''],  # Дополнено
        ['2', 'Товар 2', '5']  # Обрезано
    ],
    'headers': ['№', 'Наименование', 'Количество'],
    'validated': True,
    'warnings': ['Строка 1 дополнена до 3 столбцов', 'Строка 2 обрезана до 3 столбцов']
}
```

### Пример 2: Автоматическое создание headers

**Входные данные:**
```python
{
    'rows': [
        ['1', 'Товар 1', '10'],
        ['2', 'Товар 2', '5']
    ],
    'headers': []
}
```

**Результат:**
```python
{
    'rows': [
        ['1', 'Товар 1', '10'],
        ['2', 'Товар 2', '5']
    ],
    'headers': ['Столбец 1', 'Столбец 2', 'Столбец 3'],
    'validated': True,
    'warnings': ['Headers созданы автоматически: 3 столбцов']
}
```

### Пример 3: Удаление пустых строк

**Входные данные:**
```python
{
    'rows': [
        ['1', 'Товар 1', '10'],
        ['', '', ''],  # Пустая строка
        ['   ', '   ', '   '],  # Строка с пробелами
        ['2', 'Товар 2', '5']
    ],
    'headers': ['№', 'Наименование', 'Количество']
}
```

**Результат:**
```python
{
    'rows': [
        ['1', 'Товар 1', '10'],
        ['2', 'Товар 2', '5']
    ],
    'headers': ['№', 'Наименование', 'Количество'],
    'row_count': 2,  # Только 2 строки с данными
    'validated': True
}
```
