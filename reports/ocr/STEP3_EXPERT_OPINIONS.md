# МНЕНИЕ ЭКСПЕРТОВ: НУЖЕН ЛИ ШАГ ИЗВЛЕЧЕНИЯ ТАБЛИЦЫ?

**Дата:** 2025-11-29  
**Вопрос:** Нужен ли шаг извлечения таблицы из Excel для корректного сравнения в ШАГЕ 3?

---

## 👥 РОЛИ ЭКСПЕРТОВ

### 1. 📊 DATA SCIENTIST (Анализ данных и метрик)

**Мнение:** ✅ **ДА, нужен шаг извлечения**

**Аргументы:**
- **Корректность метрик:** Текущее сравнение дает ложные метрики (57 различий из-за заголовков, а не ошибок OCR)
- **Статистическая значимость:** Невозможно оценить реальное качество без нормализации данных
- **Baseline для улучшений:** Нужны точные метрики "до/после" для оценки эффективности ШАГОВ 1-2

**Рекомендация:**
```
1. Извлечь только таблицу (34 строки данных)
2. Сравнить ячейка-к-ячейке
3. Вычислить точные метрики:
   - Accuracy по ячейкам
   - Precision/Recall для числовых значений
   - F1-score для текстовых полей
```

**Оценка времени:** 10-15 минут  
**Приоритет:** Высокий (для точных метрик)

---

### 2. 💻 SOFTWARE ENGINEER (Архитектура и качество кода)

**Мнение:** ⚠️ **УСЛОВНО НУЖЕН**

**Аргументы:**
- **Архитектура:** ШАГ 3 уже выполнен, цель достигнута (сравнение проведено)
- **Технический долг:** Извлечение таблицы - это дополнительная функция, которая может быть полезна в будущем
- **Принцип YAGNI:** "You Aren't Gonna Need It" - если цель ШАГА 3 достигнута, можно не делать

**Рекомендация:**
```
Если цель ШАГА 3 - "сравнить результаты", то:
- ✅ Цель достигнута (сравнение проведено)
- ✅ Можно переходить к следующему шагу

Если цель - "получить точные метрики", то:
- ✅ Нужно извлечение таблицы
```

**Оценка времени:** 10-15 минут (если делать)  
**Приоритет:** Средний (зависит от цели)

---

### 3. 🤖 ML ENGINEER (Машинное обучение и OCR)

**Мнение:** ✅ **ДА, нужен шаг извлечения**

**Аргументы:**
- **Оценка качества модели:** Confidence 95% - это хорошо, но нужны метрики на уровне данных
- **Обучение модели:** Если в будущем будем дообучать модель, нужны точные ground truth данные
- **Валидация улучшений:** ШАГИ 1-2 улучшили confidence с 0.50 до 0.95, но нужно проверить качество данных

**Рекомендация:**
```
1. Извлечь таблицу из Excel (ground truth)
2. Сравнить с автоматическим распознаванием
3. Вычислить метрики:
   - Character Error Rate (CER)
   - Word Error Rate (WER)
   - Table structure accuracy
4. Сохранить для будущего обучения
```

**Оценка времени:** 15-20 минут  
**Приоритет:** Высокий (для валидации модели)

---

### 4. 🧪 QA ENGINEER (Тестирование и качество)

**Мнение:** ✅ **ДА, нужен шаг извлечения**

**Аргументы:**
- **Валидация тестов:** Текущее сравнение не валидно (сравниваются разные структуры)
- **Регрессионное тестирование:** Нужны точные метрики для отслеживания регрессий
- **Отчетность:** Для отчетов нужны точные цифры, а не "57 различий (из-за заголовков)"

**Рекомендация:**
```
1. Создать тестовый набор (ground truth таблица)
2. Автоматизировать сравнение
3. Установить пороги качества:
   - Accuracy > 95% для числовых значений
   - Accuracy > 90% для текстовых значений
4. Интегрировать в CI/CD
```

**Оценка времени:** 20-30 минут (с автоматизацией)  
**Приоритет:** Высокий (для валидации качества)

## 🎯 ФИНАЛЬНАЯ РЕКОМЕНДАЦИЯ

### Консенсус экспертов: ✅ **ДА, НУЖЕН ШАГ ИЗВЛЕЧЕНИЯ**

**Причины:**
1. **Точные метрики** - для оценки качества OCR
2. **Валидация улучшений** - подтверждение эффективности ШАГОВ 1-2
3. **Будущее использование** - данные для обучения/дообучения модели
4. **Отчетность** - точные цифры для отчетов

**Но с оговоркой:**
- Если цель ШАГА 3 - просто "проверить, что работает" → можно пропустить
- Если цель - "получить точные метрики" → нужно сделать

---

## 💡 ПРЕДЛОЖЕНИЕ

### Компромиссное решение:

1. **Сделать быстрое извлечение** (5-10 минут):
   - Автоматически найти начало таблицы в Excel
   - Извлечь только данные таблицы
   - Сравнить с автоматическим распознаванием

2. **Получить ключевые метрики:**
   - Accuracy по ячейкам (сколько % правильно)
   - Количество критических ошибок
   - Примеры ошибок для анализа

3. **Если метрики хорошие (>95%)** → переходим к следующему шагу
4. **Если метрики плохие (<90%)** → анализируем ошибки и улучшаем

---

## 📋 ПЛАН ДЕЙСТВИЙ

### Вариант 1: Полное извлечение (рекомендуется экспертами)

**Время:** 15-20 минут  
**Результат:** Точные метрики качества

1. Создать скрипт для автоматического поиска начала таблицы
2. Извлечь только данные таблицы из Excel
3. Сравнить ячейка-к-ячейке
4. Вычислить метрики (Accuracy, CER, WER)
5. Создать отчет с точными цифрами

### Вариант 2: Быстрое извлечение (компромисс)

**Время:** 5-10 минут  
**Результат:** Основные метрики

1. Вручную указать начало таблицы (строка с заголовками)
2. Извлечь данные
3. Сравнить
4. Получить основные метрики

### Вариант 3: Пропустить (если цель достигнута)

**Время:** 0 минут  
**Результат:** Текущие результаты достаточны

1. Использовать текущее сравнение как есть
2. Перейти к следующему шагу

## 🎬 РЕШЕНИЕ

- Даст точные метрики для оценки качества
- Подтвердит эффективность ШАГОВ 1-2
- Займет всего 15-20 минут
- Данные будут полезны в будущем

**Но:** Если время критично, можно сделать **Вариант 2** (быстрое извлечение)
