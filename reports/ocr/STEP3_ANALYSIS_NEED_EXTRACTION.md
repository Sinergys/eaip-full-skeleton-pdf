# АНАЛИЗ: НУЖЕН ЛИ ШАГ ИЗВЛЕЧЕНИЯ ТАБЛИЦЫ?

**Дата:** 2025-11-29  
**Вопрос:** Нужен ли шаг извлечения таблицы из Excel для корректного сравнения?

---

## ТЕКУЩАЯ СИТУАЦИЯ

### Что мы имеем:

1. **Автоматическое распознавание:**
   - Таблица: 34 строки (1 заголовок + 33 данных)
   - 10 столбцов
   - Только данные таблицы

2. **Ручное распознавание (Excel):**
   - Вариант 1: 57 строк (включая заголовки документа, метаданные)
   - Вариант 2: 125 строк (весь текст документа в одной колонке)
   - Содержат не только таблицу, но и весь документ

### Проблема:

**Сравнение некорректно**, потому что сравниваются:
- Автоматическое: только таблица (34 строки)
- Ручное: весь документ (57-125 строк)

---

## ВАРИАНТЫ РЕШЕНИЯ

### Вариант 1: Извлечение таблицы (рекомендуется) ✅

**Что делать:**
1. Найти начало таблицы в Excel (строка с заголовками: №, Наименование, ...)
2. Извлечь только строки таблицы (после заголовков)
3. Сравнить нормализованные данные

**Преимущества:**
- ✅ Корректное сравнение одинаковых структур
- ✅ Реальные расхождения в данных таблицы
- ✅ Понятные метрики качества

**Недостатки:**
- ⚠️ Требует дополнительный шаг обработки

---

### Вариант 2: Сравнение "как есть" (текущее)

**Что делать:**
- Сравнивать Excel файлы как есть (со всеми заголовками)

**Преимущества:**
- ✅ Быстро (уже сделано)
- ✅ Показывает общую структуру

**Недостатки:**
- ❌ Некорректное сравнение (разные структуры)
- ❌ Не показывает реальные расхождения в данных таблицы
- ❌ Много ложных различий (заголовки документа)

---

### Вариант 3: Ручное указание начала таблицы

**Что делать:**
- Пользователь указывает, с какой строки начинается таблица
- Скрипт извлекает только эту часть

**Преимущества:**
- ✅ Точное извлечение
- ✅ Быстро

**Недостатки:**
- ⚠️ Требует ручного указания

---

## РЕКОМЕНДАЦИЯ

### Для ШАГА 3 (сравнение):

**ДА, нужен шаг извлечения**, потому что:
1. Без него сравнение некорректно (57 различий из-за заголовков документа)
2. Нужны реальные метрики качества распознавания таблицы
3. Это займет 5-10 минут, но даст точные результаты

### Для дальнейшей работы:

**Зависит от цели:**
- Если цель - улучшить OCR → **ДА, нужен** (чтобы понять реальные ошибки)
- Если цель - просто проверить работу → можно обойтись текущим сравнением

---

## ЧТО ДЕЛАТЬ ДАЛЬШЕ?

### Если нужен шаг извлечения:

1. Создать скрипт для автоматического поиска начала таблицы
2. Извлечь только данные таблицы из Excel
3. Повторить сравнение с нормализованными данными
4. Получить точные метрики качества

**Время:** 10-15 минут

### Если не нужен:

1. Использовать текущие результаты как есть
2. Перейти к следующему шагу (ШАГ 4: улучшения на основе сравнения)
