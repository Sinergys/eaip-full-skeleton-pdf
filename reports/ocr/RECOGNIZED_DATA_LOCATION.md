## 🔍 КАК НАЙТИ ДАННЫЕ В JSON

### В `extended_batch_results_20251129_211339.json`:

1. Откройте файл в текстовом редакторе
2. Найдите `"file_name": "акт выполненых работ май.PDF"`
3. В разделе `"pages"` → `"tables"` → `"rows"` находятся все строки таблицы
4. В разделе `"pages"` → `"tables"` → `"headers"` находятся заголовки

## 📊 БЫСТРЫЙ ДОСТУП К ДАННЫМ

```python
import json

# Загрузить результаты
with open('reports/ocr/extended_batch_results_20251129_211339.json', encoding='utf-8') as f:
    data = json.load(f)

# Получить таблицу

headers = table['headers']
```
