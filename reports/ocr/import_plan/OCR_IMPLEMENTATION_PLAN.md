## ТЕХНИЧЕСКИЕ ДЕТАЛИ

### Используемые модули:
- `extract_with_gemini_vision()` - OCR через Gemini Vision API
- `aggregate_from_db_json()` - агрегация данных
- `postprocess_tables_numbers()` - постобработка чисел
- `postprocess_tables_id_codes()` - постобработка ID кодов
- `validate_tables_list()` - валидация таблиц

### Ключевые слова для поиска таблиц:
- Электроэнергия: "электроэнергия", "электричество", "энергия", "кВт·ч", "кВтч"
- Газ: "газ", "м³", "м3", "кубометр"
- Вода: "вода", "водоснабжение", "м³", "м3"
- Тепло: "тепло", "теплоэнергия", "Гкал", "ГДж"

### Формат преобразования:
```python
# Из OCR таблицы:
ocr_table = {
    "headers": ["Месяц", "Потребление", "Стоимость"],
    "rows": [["Январь", "1000", "150000"], ...]
}

# В формат агрегатора:
aggregator_data = {
    "resources": {
        "electricity": {
            "monthly": {
                "01": 1000.0,
                "02": 1200.0,
                ...
            },
            "annual": 12000.0
        }
    }
}
```
