**Операции:**
1. Создание таблицы `aggregated_data` в БД (5 мин)
2. Создание индексов для быстрого поиска (5 мин)

**Входные данные:**
- Структура данных из БЛОКА 1

**Выходные данные:**
- Таблица `aggregated_data` создана
- Индексы созданы

**Структура таблицы:**
```sql
CREATE TABLE IF NOT EXISTS aggregated_data (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    batch_id TEXT NOT NULL,
    enterprise_id INTEGER NOT NULL,
    resource_type TEXT NOT NULL,  -- electricity, gas, water, heat, fuel
    data_period TEXT NOT NULL,     -- year, quarter, month
    period_value TEXT NOT NULL,    -- 2024, Q1, 01
    aggregated_json TEXT NOT NULL,
    created_at TEXT NOT NULL,
    updated_at TEXT NOT NULL,
    FOREIGN KEY (enterprise_id) REFERENCES enterprises(id)
);
```

## ПРОЦЕСС ВЫПОЛНЕНИЯ

### Шаг 1: Инициализация
1. PM создаёт файлы документирования
2. PM проверяет готовность к выполнению
3. PM запрашивает подтверждение у пользователя

### Шаг 2: Выполнение блока
1. Пользователь даёт команду: "Выполнить БЛОК N"
2. PM фиксирует команду в логе
3. Выполняется блок
4. При сбоях - PM выводит вопросы и предложения
5. PM формирует TDLV отчёт
6. PM обновляет статус блока

### Шаг 3: После каждого блока
1. PM формирует краткий TDLV отчёт
2. PM обновляет `blocks_status.json`
3. PM ждёт команды пользователя для следующего блока
