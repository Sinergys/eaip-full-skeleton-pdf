## ИСПРАВЛЕННЫЕ ПРОБЛЕМЫ

### Проблема 1: Логика определения количества столбцов

**Было:** Использовалось максимальное значение между headers и rows  
**Стало:** Приоритет headers, но если rows имеют больше - используется максимальное

**Исправление:**
```python
# Если есть headers, используем их количество (но не меньше максимального в rows)
if headers_cols > 0:
    expected_cols = max(headers_cols, max_cols_in_rows)
else:
    expected_cols = max_cols_in_rows
```

### Проблема 2: Тест `test_table_with_mismatched_columns`

**Было:** Ожидалось 3 столбца, получали 4  
**Стало:** Исправлена логика определения количества столбцов
