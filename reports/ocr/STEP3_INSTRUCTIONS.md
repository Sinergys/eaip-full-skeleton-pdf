# ШАГ 3: ИНСТРУКЦИИ ПО СРАВНЕНИЮ РЕЗУЛЬТАТОВ

**Дата:** 2025-11-29  
**Статус:** В процессе выполнения

---

## ЦЕЛЬ

Сравнить результаты автоматического распознавания с вашими 2 вариантами ручного распознавания для выявления расхождений и определения областей для улучшения.

---

## ЧТО НУЖНО ОТ ВАС

### Вариант 1: JSON файлы (рекомендуется)

Если у вас есть результаты в формате JSON, предоставьте файлы со следующей структурой:

```json
{
  "tables": [
    {
      "rows": [
        ["№", "Колонка 1", "Колонка 2", ...],
        ["1", "Значение 1", "Значение 2", ...],
        ["2", "Значение 3", "Значение 4", ...],
        ...
      ],
      "headers": ["№", "Колонка 1", "Колонка 2", ...]
    }
  ],
  "text": "Полный текст документа..."
}
```

**Где сохранить:**
- `reports/ocr/manual_recognition_variant1.json`
- `reports/ocr/manual_recognition_variant2.json`

---

### Вариант 2: Excel файлы

Если результаты в Excel, я могу создать скрипт для конвертации в JSON.

**Требования:**
- Таблица должна быть на первом листе
- Первая строка - заголовки
- Остальные строки - данные

---

### Вариант 3: Текстовое описание

Если результаты в другом формате, опишите:
1. **Структура таблицы:**
   - Количество строк (включая заголовок)
   - Количество столбцов
   - Названия столбцов

2. **Основные расхождения:**
   - Какие ячейки распознаны неправильно?
   - Какие данные пропущены?
   - Какие строки отсутствуют?

3. **Примеры ошибок:**
   - Конкретные примеры неправильно распознанных значений

---

## КАК ЗАПУСТИТЬ СРАВНЕНИЕ

### Способ 1: Автоматический (если есть JSON файлы)

```bash
python tools/compare_recognition_results.py
```

Скрипт попросит указать путь к файлу с ручными результатами.

---

### Способ 2: Интерактивный

1. Запустите скрипт:
   ```bash
   python tools/compare_recognition_results.py
   ```

2. Введите путь к файлу с ручными результатами

3. Получите отчет в:
   - `reports/ocr/step3_comparison_report.json`
   - `reports/ocr/step3_comparison_report.md`

---

## ЧТО БУДЕТ В ОТЧЕТЕ

### 1. Сводка
- Confidence автоматического распознавания
- Количество таблиц (авто vs ручное)
- Общее количество различий

### 2. Критические различия
- Несоответствие количества строк/столбцов
- Пропущенные строки
- Лишние строки

### 3. Детальное сравнение
- Различия в каждой ячейке
- Сходство значений (процент)
- Примеры неправильно распознанных данных

### 4. Рекомендации
- Конкретные предложения по улучшению алгоритмов
- Приоритетные области для доработки
