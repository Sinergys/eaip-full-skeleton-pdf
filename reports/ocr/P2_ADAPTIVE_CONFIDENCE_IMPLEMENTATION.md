## ВЫПОЛНЕННЫЕ ИЗМЕНЕНИЯ

### 1. Добавлена конфигурация адаптивной обработки

**Файл:** `config/ocr.yml` (строки 30-36)

**Параметры:**
```yaml
adaptive_processing:
  enabled: true              # Включить адаптивную обработку
  min_confidence: 0.70       # Минимальный порог confidence для повторной попытки
  max_retry_attempts: 1      # Максимальное количество повторных попыток
  enhance_image: true        # Улучшать изображение перед повторной попыткой
  save_enhanced_images: false # Сохранять улучшенные изображения (для отладки)
```

### 2. Реализована функция `_adaptive_confidence_retry()`

**Файл:** `eaip_full_skeleton/services/ingest/utils/gemini_vision_ocr.py` (строки 119-200)

**Логика:**
1. Проверяет confidence результата
2. Если confidence < min_confidence (0.70):
   - Улучшает изображение через `preprocess_image_for_ocr()`
   - Повторяет обработку с улучшенным изображением
   - Сравнивает результаты и выбирает лучший
3. Логирует улучшение confidence

**Ключевые особенности:**
- ✅ Использует улучшенную предобработку изображений
- ✅ Выбирает лучший результат (по confidence)
- ✅ Логирует улучшение confidence
- ✅ Сохраняет метаданные о повторной попытке
- ✅ Удаляет временные файлы (если не включено сохранение)

### 3. Интеграция в основной процесс

**Файл:** `eaip_full_skeleton/services/ingest/utils/gemini_vision_ocr.py` (строки 545-548)

**Изменение:**
```python
# Проверяем confidence и добавляем validation_flag при необходимости
result = _check_confidence(result, image_path, page_num=page_num)

# Адаптивная обработка: повторная попытка при низком confidence
result = _adaptive_confidence_retry(result, image_path, page_num)

return result
```

## КОНФИГУРАЦИЯ

### Параметры адаптивной обработки

| Параметр | Значение по умолчанию | Описание |
|----------|----------------------|----------|
| `enabled` | `true` | Включить/выключить адаптивную обработку |
| `min_confidence` | `0.70` | Минимальный порог для повторной попытки |
| `max_retry_attempts` | `1` | Количество дополнительных попыток |
| `enhance_image` | `true` | Улучшать изображение перед повторной попыткой |
| `save_enhanced_images` | `false` | Сохранять улучшенные изображения для отладки |

### Рекомендации по настройке

**Для быстрой обработки:**
```yaml
adaptive_processing:
  enabled: false  # Отключить для ускорения
```

**Для максимального качества:**
```yaml
adaptive_processing:
  enabled: true
  min_confidence: 0.60  # Более низкий порог (больше повторных попыток)
  max_retry_attempts: 2  # Больше попыток
```

**Для отладки:**
```yaml
adaptive_processing:
  enabled: true
  save_enhanced_images: true  # Сохранять улучшенные изображения
```
