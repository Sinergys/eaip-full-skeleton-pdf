### 1. Проверка типов (mypy) - 7 ошибок

**Файл:** `services/reports/energy_passport/data_collector.py`

#### Ошибка 1-5: Несовместимые типы аргументов (строки 232-236)

**Проблема:** При создании объекта `ElectricityProductData` передаются значения типа `object` вместо ожидаемых типов.

**Местоположение:**
```python
# Строка 232
product_name=product_name,  # Ожидается str, получен object

# Строка 233
norm_kw=default["norm"],  # Ожидается float, получен object

# Строка 234
fact_2022_kw=fact_2022,  # Ожидается float, получен object

# Строка 235
fact_2023_kw=fact_2023,  # Ожидается float, получен object

# Строка 236
fact_2024_kw=fact_2024,  # Ожидается float, получен object
```

**Причина:**
- `default` имеет тип `Dict[str, Any]`, поэтому `default["norm"]` имеет тип `Any` (интерпретируется как `object`)
- `fact_2022`, `fact_2023`, `fact_2024` также имеют тип `object` из-за неявного типа

**Риск:**
- Во время выполнения может быть передано значение неправильного типа
- Может привести к ошибкам при использовании этих значений

**Рекомендация:**
Добавить явное приведение типов или аннотации:
```python
product_name: str = default["name"]
norm_kw: float = float(default["norm"])
fact_2022_kw: float = float(default["fact_2022"])
fact_2023_kw: float = float(default["fact_2023"])
fact_2024_kw: float = float(default["fact_2024"])
```

---

#### Ошибка 6-7: Отсутствуют аннотации типов (строки 251-252)

**Проблема:** Переменные `monthly` и `quarterly` не имеют аннотаций типов.

**Местоположение:**
```python
# Строка 251
monthly = {}  # Нужна аннотация типа

# Строка 252
quarterly = {}  # Нужна аннотация типа
```

**Причина:**
- mypy не может определить тип пустого словаря `{}`
- Нужна явная аннотация типа

**Риск:**
- Низкий, но снижает качество типизации кода
- Ухудшает поддержку IDE (автодополнение)

**Рекомендация:**
Добавить аннотации типов:
```python
monthly: Dict[int, Dict[int, float]] = {}
quarterly: Dict[int, Dict[int, float]] = {}
```
