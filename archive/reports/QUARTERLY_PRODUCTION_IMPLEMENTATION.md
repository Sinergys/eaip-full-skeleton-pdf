### 1. Создан модуль `quarterly_production.py`

**Путь:** `services/reports/energy_passport/quarterly_production.py`

**Функции:**

1. **`MONTH_TO_QUARTER`** - маппинг месяцев к кварталам

## 📋 Использование

### Автоматическое использование

При генерации энергопаспорта через `generate_energy_passport()` квартальные таблицы заполняются автоматически, если в `aggregated_data` есть данные по производству.

### Ручное использование

```python
from services.reports.energy_passport.quarterly_production import (
    extract_monthly_production_from_aggregated,
    write_quarter_tables_to_sheet,
)
from openpyxl import load_workbook

# Загружаем данные
with open("data/aggregated/aggregated_full_resources_2022_2024.json") as f:
    aggregated_data = json.load(f)

# Извлекаем месячные данные
monthly_production = extract_monthly_production_from_aggregated(aggregated_data)

# Открываем Excel
wb = load_workbook("template.xlsx")
ws = wb.create_sheet("Объемы по кварталам")

# Записываем таблицы
write_quarter_tables_to_sheet(
    ws,
    monthly_production,
    years=[2022, 2023, 2024],
    start_row=1,
    start_col=1,
)

wb.save("output.xlsx")
```

## 🔍 Проверка результата

После генерации паспорта проверьте:

1. **Лист "Объемы по кварталам"** должен содержать:
   - Заголовок с названиями продуктов
   - Данные по всем кварталам для всех лет
   - Колонку "ИТОГО" с суммами

2. **Проверка сумм:**
   - Квартальная сумма = сумма 3 месяцев
   - ИТОГО = сумма всех 5 продуктов

## ⚙️ Настройки

### Изменение названий продуктов

Отредактируйте `PRODUCT_COLUMNS` в `quarterly_production.py`:

```python
PRODUCT_COLUMNS = [
    "Труба ХВС",
    "Канал труба",
    "Канал фитинг",
    "Фит ХВС и ГВС",
    "Топ. пол",
]
```

### Добавление новых продуктов

1. Добавьте название в `PRODUCT_COLUMNS`
2. Добавьте маппинг в `PRODUCT_NAME_MAPPING`
3. Обновите тесты

## 📝 Логирование

Модуль использует стандартный Python logging:
- `INFO` - основные операции (извлечение данных, запись таблиц)
- `DEBUG` - детальная информация (обработка каждого месяца, продукта)
- `WARNING` - отсутствие данных или ошибки
