**Статус:** НЕ ВЫПОЛНЕНО (критическое замечание)

**Проблема:** 
- ❌ **Отсутствует копирование шаблона** перед загрузкой
- ❌ Шаблон загружается напрямую через `load_workbook(template_path, data_only=False)` без копирования
- ⚠️ Это нарушает требование ТЗ: "генерация паспорта должна ВСЕГДА начинаться с КОПИРОВАНИЯ этого эталонного файла"

**Текущая реализация:**
```python
# eaip_full_skeleton/services/ingest/main.py:1689
workbook = load_workbook(template_path, data_only=False)
```

**Требуемое исправление:**
```python
import shutil
# Копируем шаблон во временное расположение
temp_template = output_dir / f"{batch_id}_template_copy.xlsx"
shutil.copyfile(template_path, temp_template)
workbook = load_workbook(temp_template, data_only=False)
```

**Файлы для исправления:**
- `eaip_full_skeleton/services/ingest/main.py` (строка 1689)
