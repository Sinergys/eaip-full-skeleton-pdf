### 3. Исправлен расчет газа в `fill_struktura_pr2()`
**Проблема:** E32 (2023 Q1 газ) = 14.0819 вместо 14.819

**Решение:**
- Добавлен расчет газа из помесячных данных (суммирование месяцев)
- Гарантировано, что квартальные значения = сумме помесячных
- Значения записываются в тысячах м³ (деление на 1000)

**Код:**
```python
# Суммируем помесячные данные по газу
gas_m3_from_months = 0.0
for month in gas_months:
    values = month.get("values", {})
    month_gas = values.get("volume_m3", 0) or values.get("gas_m3", 0) or 0
    if month_gas:
        gas_m3_from_months += float(month_gas)

# Используем данные из месячных, если они есть
if gas_m3_from_months > 0:
    gas_m3 = gas_m3_from_months

# ВАЖНО: Газ в шаблоне должен быть в тысячах м³
gas_m3_thousands = gas_m3 / 1000.0
_safe_set_cell_value(ws, row, col_gas, gas_m3_thousands)
```

### 4. Реализована функция `fill_electricity_by_product()`
**Файл:** `tools/fill_energy_passport.py`

Заполняет таблицу электроэнергии по 5 видам продукции:
1. Трубы ХВС (норма: 630 кВт)
2. Фитинги ХВС (норма: 2100 кВт)
3. Канализационные трубы (норма: 750 кВт)
4. Канализационные фитинги (норма: 2100 кВт)
5. Трубы тёплого пола (норма: 670 кВт)

Для каждого вида заполняет:
- Норма (кВт)
- Факт по годам (2022, 2023, 2024)
- Перерасход (%) = (Факт/Норма - 1) * 100

### 5. Реализована функция `fill_gas_specific_consumption()`
**Файл:** `tools/fill_energy_passport.py`

Заполняет удельный расход газа:
- **На 1 м² здания:** `Gas_year / Area_m2` (м³/(м²·год))
- **На условную единицу:** `Gas_year / Production_units` (м³/усл.ед.)

Рассчитывает отклонения:
- Абсолютное: `Факт - Норма`
- В процентах: `(Факт / Норма - 1) * 100`
