## 📊 ИСПОЛЬЗУЕМЫЕ API ENDPOINTS

1. `GET /api/enterprises/{enterprise_id}/generation-readiness`
   - Возвращает полную информацию о готовности
   - Используется для отображения детального чек-листа

2. `GET /api/enterprises/{enterprise_id}/upload-checklist`
   - Возвращает чек-лист файлов
   - Используется для отображения списка файлов

3. `POST /api/generate-passport/{batch_id}`
   - Генерация паспорта
   - Проверяет готовность на сервере (уже реализовано)
