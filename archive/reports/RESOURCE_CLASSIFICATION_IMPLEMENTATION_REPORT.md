### ✅ Шаг 2: Улучшен content_analyzer.py

**Файл:** `eaip_full_skeleton/services/ingest/utils/content_analyzer.py`

**Добавлено:**

1. **Анализ единиц измерения (высокий приоритет):**
   - `UNIT_PATTERNS` - словарь единиц измерения для каждого типа ресурса
   - Поиск единиц в ячейках с коэффициентом ×5 (очень высокий приоритет)
   - Поддержка: кВт·ч, м³, Гкал, тонн, л и т.д.

2. **Анализ структуры данных:**
   - Функция `_analyze_data_structure()` для определения временных рядов
   - Определение структуры оборудования (секции с номерами)
   - Определение структуры узлов учета (многострочные заголовки)
   - Определение структуры расчета теплопотерь (разделы, конструкции)

3. **Улучшенный анализ Excel:**
   - Анализ увеличен до 15 строк (было 10)
   - Приоритеты: единицы измерения (×5) > листы (×3) > заголовки (×2) > текст (×1)

4. **Новая логика приоритетов:**
   - Приоритет содержимого над именем файла
   - `get_resource_with_content_analysis()` теперь возвращает содержимое в первую очередь

### ✅ Шаг 3: Изменен порядок обработки в main.py

**Файл:** `eaip_full_skeleton/services/ingest/main.py`

**Критические изменения:**

#### **До:**
```python
# Определение типа ДО парсинга
detected_type = get_resource_with_content_analysis(safe_filename, None)
```

#### **После:**
```python
# 1. Сохраняем тип пользователя (если указан)
user_provided_type = resource_type if ... else None

# 2. Парсим файл
parsing_result = parse_file(dst, batch_id=batch_id)

# 3. Определяем тип ПОСЛЕ парсинга на основе содержимого
detected_resource_type = ResourceClassifier.classify(
    filename=safe_filename,
    raw_json=raw_json_for_analysis,
    user_provided_type=user_provided_type
)
```

**Результат:**
- ✅ Тип определяется после парсинга
- ✅ Используется анализ содержимого
- ✅ Валидируется тип, указанный пользователем
- ✅ Логируется несоответствие типа и содержимого

### ✅ Шаг 5: Обновлены специализированные парсеры

2. `utils/building_envelope_parser.py` - `is_envelope_file()`

**Изменения:**
- ✅ Все функции теперь принимают `raw_json` для анализа содержимого
- ✅ Используют `ResourceClassifier` вместо проверки только имени файла
- ✅ Fallback на старую логику при недоступности классификатора

**Пример:**
```python
# Было:
def is_equipment_file(filename: str) -> bool:
    return "oborudovanie" in filename.lower()

# Стало:
def is_equipment_file(filename: str, raw_json: Optional[Dict] = None) -> bool:
    detected_type = ResourceClassifier.classify(filename, raw_json)
    return detected_type == "equipment"
```
