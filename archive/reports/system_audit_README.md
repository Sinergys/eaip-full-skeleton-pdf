# 🔍 System Audit для Ollama

Скрипт комплексной диагностики системы Windows для оценки возможности запуска и оптимизации работы [Ollama](https://ollama.ai) (локальной LLM платформы).

## 📋 Описание

Скрипт собирает детальную информацию о системе и формирует отчет для оценки:
- **Процессор (CPU):** модель, ядра, частота, виртуализация
- **Оперативная память (RAM):** объем, скорость, использование
- **Графические процессоры (GPU):** модель, VRAM, драйверы
- **Дисковая подсистема:** объем, свободное пространство, файловые системы
- **Процессы:** топ-10 по CPU и памяти
- **Сетевые интерфейсы:** активные адаптеры и их характеристики
- **Зависимости:** установленные версии .NET Framework

Автоматически запрашивает права администратора для полного доступа к системной информации.

## 🚀 Быстрый старт

### Базовое использование

```powershell
# Запуск с автоматическим повышением прав
.\system_audit.ps1
```

### Параметры

```powershell
# Запуск без повышения прав (для тестирования)
.\system_audit.ps1 -SkipElevation

# Запуск без повышения прав и без открытия отчета (для автоматизации)
.\system_audit.ps1 -SkipElevation -SkipReportViewer
```

## 📊 Выходные данные

Скрипт создает файл `system_audit.txt` в текущей директории с полным отчетом о системе в кодировке UTF-8.

### Структура отчета

```
=== ОТЧЕТ АУДИТА СИСТЕМЫ ДЛЯ OLLAMA ===
Время создания: [дата и время]

=== ОСНОВНАЯ ИНФОРМАЦИЯ О СИСТЕМЕ ===
- Имя компьютера
- Производитель и модель
- Время работы системы

=== ПРОЦЕССОР (CPU) ===
- Модель и архитектура
- Количество ядер и логических процессоров
- Частота (текущая и максимальная)
- Поддержка виртуализации

=== ОПЕРАТИВНАЯ ПАМЯТЬ (RAM) ===
- Количество слотов
- Общий объем и скорость
- Доступная и используемая память

=== ГРАФИЧЕСКИЕ ПРОЦЕССОРЫ (GPU) ===
- Модель каждого GPU
- Объем VRAM
- Версия драйвера

=== ДИСКОВАЯ ПОДСИСТЕМА ===
- Объем и свободное пространство каждого диска
- Тип файловой системы

=== ТОП-10 ПРОЦЕССОВ ===
- По использованию CPU
- По использованию памяти

=== СЕТЕВЫЕ ИНТЕРФЕЙСЫ ===
- Активные адаптеры
- Состояние и скорость

=== ЗАВИСИМОСТИ ===
- Установленные версии .NET Framework

=== ЗАКЛЮЧЕНИЕ И ПЕРВОНАЧАЛЬНАЯ ОЦЕНКА ===
- Оценка возможности запуска Ollama
- Рекомендации по использованию GPU/CPU
```

## 🎯 Оценка системы для Ollama

Скрипт автоматически оценивает систему на основе собранных данных:

### Оценка по RAM

- **≥16 GB:** ✅ Отлично! Система имеет достаточно памяти для запуска большинства моделей Ollama
- **≥8 GB:** ⚠ Система может запускать небольшие и средние модели Ollama (3B-7B параметров)
- **<8 GB:** ⚠ ОЗУ ограничено. Рекомендуется использовать только маленькие модели (1B-3B параметров)

### Оценка GPU

- **Дискретная видеокарта (≥2GB VRAM):** ✅ Обнаружена дискретная видеокарта. Это значительно ускорит работу Ollama
- **Интегрированная/отсутствует:** ⚠ Дискретная видеокарта не обнаружена. Ollama будет работать на CPU

## ⚙️ Требования

- **PowerShell:** 5.1+ или PowerShell Core 7+
- **Права:** Рекомендуется запуск с правами администратора для полного доступа к данным

## 🔧 Технические детали

### Используемые технологии

- **WMI/CIM:** `Win32_ComputerSystem`, `Win32_OperatingSystem`, `Win32_Processor`, `Win32_PhysicalMemory`, `Win32_VideoController`, `Win32_LogicalDisk`
- **PowerShell cmdlets:** `Get-Process`, `Get-NetAdapter` (с fallback на WMI)
- **Реестр Windows:** Проверка версий .NET Framework

### Обработка ошибок

Скрипт включает обработку ошибок для:
- Отсутствующих данных (null-проверки)
- Недоступных WMI классов
- Отсутствия модулей PowerShell (fallback-механизмы)
- Ошибок доступа к реестру

### Кодировка

Все данные сохраняются в UTF-8 для корректного отображения кириллицы.
